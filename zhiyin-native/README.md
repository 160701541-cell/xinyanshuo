# 知音 v0.4：10.24㎡虚拟出租屋（Android原生 2.5D 测试版）

## 起点与产品原则
- 玩家有独立住所；知音租住临河巷单间，面积3.2m×3.2m（10.24㎡）。
- 知音的主业是**咖啡馆兼职店员**，每完成每日第一次工作班次获得64模拟币；个人爱好才是唱歌、电子琴、阅读。她需要买食材、吃饭、洗漱、睡觉，并负担每周160模拟币房租。
- 城区拥有玩家住所及清音、墨染、阿禾、阿澈等居民**不同住所与兴趣/职业档案**，社区地图可拖动与双指缩放。重复社交受时间冷却限制，熟悉度关系逐步发展；亲密关系不是点击即可自动成立。
- 新房间为 **Android Canvas 程序化等轴测2.5D**：地板纹理、双面墙、可见窗景、书架、衣柜、床铺、厨房台面、水池、灯具、电子琴、书桌、沙发、绿植、玄关，基本均有触控热点。
- 主场景支持**拖动相机与双指缩放**，家具点击执行活动，无大弹窗确认；非模态的简洁聊天框保留主场景。
- 房租/工资/食材/餐食/清洁/休息/练习/熟悉度均有持久数据，事件写入SQLite。JSON档案备份含生活与社区关系数据。
- 当前音乐训练**只是角色爱好模拟**；还未接入真正AI歌唱、音准纠错和自由对话模型。

## 签名与数据安全（重要）
- v0.1–v0.3 的GitHub构建默认使用临时debug签名；由于缺失其旧版私钥，**v0.4使用新的、从此固定的实验包名 `com.xinyanshuo.zhiyin.companion`，可与旧版并存**，无需立刻卸载或破坏旧版数据。先在旧版「记忆 → 导出JSON」，直接安装新版，然后在新版「记忆 → 恢复JSON」；确认数据恢复成功后，再自行卸载旧版。v0.3导出支持生活状态；v0.1/0.2导出仅有原文、角色和剧本等，不能恢复当时生活状态。
- 从v0.4测试版开始，CI用可复现的公开**LAB TEST CERTIFICATE**，可保持此测试通道后续构建同证书。此证书**完全不安全/人人能复制**，正式使用前必须迁移到受保护的私钥（GitHub Actions Secrets或更安全的签名服务）。不要在此公开签名的测试安装包中存储敏感隐私资料或使用真实隐私对话。
- 正式生产签名切换到私有密钥时仍可能需要一次显式签名迁移。已写入项目高风险项。

## 尚未完成
- 居民目前只有职业、爱好、住宅和社会关系数据，尚未拥有人人可见的物理身体与完整自主生活动画。
- 10㎡程序绘制小屋虽然可拖动缩放，**还不是商业化品质的授权资产纹理/骨骼动画**；需接入成套授权的高质量2.5D人物与室内物件素材。
- 出门换场通过独立社区地图，尚不是同一个3D世界连续空间。
- 打工、房租、关系是有限规则的模拟，未提供真实AI决策模型；后台离线最多两小时阶段回放，超过会明确标记限制。
- 未实现真正的实时AI歌唱、教唱纠错、多人NPC演剧本杀和持久本地AI模型。
- **验收状态：仅Gradle打包编译成功后可标CI通过；Android手机实机仍待用户验收。**
