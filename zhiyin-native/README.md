# 《知音》Android v0.2 — 场景优先的虚拟搭档（原生）
包名 `com.xinyanshuo.zhiyin`，独立于《苍岚》和 WorldBox。使用原生 Java + Android SDK Canvas + SQLite。没有 WebView/浏览器壳。

## 已实现
- **入口主场景**：启动即进入知音的虚拟房间；动态程序绘制的少女角色、眼睛眨动/头发呼吸/步行动画、昼夜窗景、床、厨房、钢琴、书桌、浴室门和绿植。
- **离线生活**：LifeEngine 每秒刷新目标和状态；角色自主选择读书、练歌、弹琴、做饭、吃饭、洗漱、写日记、打扫、浇花、伸展、休息/睡眠。根据真实本地时钟、精力、饥饿、清洁和心情优先级调度。活动位置之间真实移动，行为不是用户点一下才运行。
- **状态持续**：SharedPreferences 持久化角色需求/行动，休眠再打开根据实际经过时间推进，单次离线补算最多24小时（超过时保留最后状态并计算一日衰减，而非宣称模拟了全部离线经历）。
- **交互**：点击角色聊天、点击家具邀请活动，顶部点击打开角色状态，角落菜单进入原生工作台（角色工厂/剧本/音乐/长期记忆）。
- **记忆**：SQLite保存场景事件、对话、原始历史，角色可见范围；保留v0.1的检索和JSON备份恢复。
- **语音**：系统TTS读台词；不是AI歌声；录音与伴奏页面沿用v0.1。

## 诚实界限
这是一套独立于大语言模型的**规则驱动日常模拟**，不是完整生活智能体；尚不具备自由三维寻路、真正的物品库存/烹饪制作、生成式AI聊天、音频实时对唱、感情理解、NPC社会关系网络或后台长期运行服务。
角色美术为**可替换的程序绘制临时造型**，不是授权资产包人物或骨骼动画。
SQLite记录原文；摘要和语义向量检索尚未完成。
没有用户设备实机测试，不能标记安卓实机验收通过。

## 发布与质量
Github Actions工作流：`.github/workflows/zhiyin-native-apk.yml`。
Gradle assembleDebug 生成debug测试APK。versionCode=2，使用GitHub Actions测试签名，每次runner签名可能变化。若已有APK签名不一致，无法覆盖安装；卸载会删除未备份的本地数据。升级前请在旧版本「记忆」页面导出JSON，然后恢复到新版本。
