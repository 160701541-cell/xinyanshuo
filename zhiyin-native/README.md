# 《知音》Android v0.3 — 虚拟角色日常生活行为（原生 APK）
专用包名 `com.xinyanshuo.zhiyin`，GitHub 独立分支 `zhiyin/native-android-prototype`；未变更《苍岚》主分支。Android原生 Java/Canvas/SQLite，无 WebView/HTML。

## 核心体验
- **启动直达房间**：可见的少女虚拟形象，在床、窗边、书桌、钢琴、厨房、盆栽之间移动。眨眼、呼吸、步行动画，昼夜窗景，生活动作具备道具差异。
- **能自行生活**：不等玩家点按钮；饱腹/精力/清洁/社交/心情驱动日常任务；按本地时间安排睡眠、休息、读书、弹琴、练歌、写日记、打扫、浇花、工作和买菜。
- **多阶段任务**：做饭=取食材→清洗→切菜→烹饪→装盘；吃饭=摆餐具→进食→收拾；洗漱、睡觉、阅读、练唱、弹琴、浇花、工作都有独立阶段与计时。每个完成的任务会改变可验证数据。
- **物资闭环**：食材入库/做饭消耗/餐食库存/进食消耗/碗碟变脏/打扫归零；空仓时先购物，无钱时接音乐编曲委托赚取金币，不再凭空生成餐食。金币是模拟币，不与现实支付关联。
- **音乐习惯与学习数值**：练习次数、音乐熟练度，阅读页数跨启动保留。这些是游戏内模拟数值，不意味着真的分析了用户歌声。
- **生活记录**：活动阶段及结果按批次写入SQLite原始事件表，可从菜单查看完整历史和关键词检索。
- **语音输入**：原生Android系统语音识别入口（设备必须安装支持的识别服务，可能联网），文本可编辑、确认发送；系统TTS语音朗读，未实现真正实时AI语音聊天。
- **互动**：点角色聊天，点家具邀请她参与日常活动，顶部可查状态和任务进度，右下菜单可查日志、调度状态和现有记忆/音乐/剧本工作台。
- **记忆备份 v0.3**：用户导出JSON时同时包含SQLite历史、角色卡、剧本和当前生活状态；恢复旧版v0.1/v0.2备份仍兼容，但旧版导出的文件本身不包含生活状态。

## 尚未实现（不得冒称已实现）
- **不是接入大模型的独立AI**：现在的动作选择、日常关系、文字对话均由明确规则驱动，无无限对话理解/真正自己做决定。
- **不是完整模拟世界**：未实现NPC复杂社交、拿取真实实体、家居物理、路径网格、天气季节、实时生活物理、不在前台时持续运行的Android后台服务。
- **不是专业歌唱伴侣**：目前B段音频靠手动导入，未接唱歌模型、实时和声、音乐跟拍、声学纠错。
- **美术是占位**：角色由原生Canvas程序绘制，需后续接入授权成品角色和完整动画。
- **离线不是无限运行**：回到应用后有限回算，最多补算两小时，最多720个阶段；事件标为系统模拟，不冒充真实时间发生的自主行动。

## 安装和数据保护
Debug构建由GitHub Actions构建机临时证书签名，不保证与上一版证书一致，因此Android可能提示**无法覆盖安装**。如需卸载旧版，必须先在旧版「记忆」页面导出JSON保存。v0.2旧备份仅覆盖聊天/剧本/角色，不包含v0.2生活状态（该缺口在v0.3修复）。卸载未备份的数据会丢失。正式长期项目必须改用**持久且安全保存的签名密钥**，才能持续覆盖升级。
**仅确认：Github Actions编译和APK产出。仍未完成Android实机启动/动画/音频操作测试。**
