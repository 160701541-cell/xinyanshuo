工具：`tools/artcheck.py`（6 条量化指标，`--kind=char|ui|vfx`），退出码 0 = 全过。

## 七项纪律 → 落地位置

| 纪律 | 落地 |
| --- | --- |
| 1 主题（青绿山水/朱砂印/金线） | 调色板常量集中于 `rig/rig3.gd` 顶部；UI 用绢纸+金线+朱砂印（`ui/hud.gd`） |
| 2 色彩（60/30/10、阴影 #2A2B3A、高光 #FFF3DC） | 检查器指标 ③ 调色板 ΔE、② 点缀色面积、⑥ 主色归属；主光/环境按 4200K/8000K 配比 |
| 3 形状（三层、上尖下宽、C 形弧、描边只给近景） | `_loft()` 超椭圆放样（躯干/裙/袖）；`rig/sso.gdshader` 屏幕空间恒定 1.3px 描边；`arc()` 两端收尖 |
| 4 材质（布 .85/丝 .55/金 .38+金属 .7/玉 .15） | `rig/toon.gdshader` + `_mat()` 按颜色查表给 roughness/metallic |

| 7 禁止项（十不） | 检查器 ④ 纯黑/纯白、② 点缀面积、③ 调色板偏差；描边恒宽由 shader 保证 |

## 审计发现的两类“检查器自身错误”（已修）

1. 用 S>0.6 判“高饱和”，把主袍青碧（S=0.67）本身判成违规 → 改为按点缀色（朱砂/金/玉）面积。
2. 点缀色按“主体”算，线状特效虚高到 50% → 改为按全画面算（对齐纪律原文“画面中”）。
3. 特效不能用中位数算 ΔL（深底上的光）→ `--kind=vfx` 取最亮 25% 核心像素。
4. Label3D 字形描边产生纯黑像素污染 ④ 项 → 标签改 PIL 后期。
