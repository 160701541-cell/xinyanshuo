# 《九域·青岚界》制作规划 v1

> 目标：横屏手游（1920×1080），三层场景 + 数据生成器。一次规划，分里程碑交付，不返工。

## 0. 屏幕与交互
- 方向：**横屏 1920×1080**（竖屏放不下 36 峰）
- 安全区：左右各 64 px，上 96 px，下 140 px
- 输入：点击（触屏等价鼠标左键）
- 帧率目标：软渲染 30 fps（lavapipe），单帧 ≤ 33 ms

## 1. 世界数据（唯一事实来源）
`/root/game/data/world.json`
```
world: { size_km: 316, seed, regions[], rivers[] }
sect:  { id, name, tier, seed, center_km, domain_km2, peaks[], buildings[] }
peak:  { id, name, tier(0主/1内门/2外门), x_km, y_km, height_m, radius_m, master, disciples }
```
- 势力：100 个（已完成，见 /root/world/sects.json，迁移进来）
- 单宗规模：**36 峰 = 1 主峰 + 5 内门峰 + 30 外门峰**
- 控制区 400 km²，核心建筑区 1.2 km²，弟子 30,000
- 编制：宗主 1 / 太上长老 3 / 峰主 36 / 长老 12 / 执事 200 / 内外门弟子

## 2. 三层场景（LOD 分层，不是缩放）
| 层 | 视野 | 几何 | 目标面数 | 内容 |
|---|---|---|---|---|
| L0 宗主界 | 12×9 km | 低模地形 4 m 网格 | ≤ 80k | 36 峰剪影、云海、主路、山门 |
| L1 峰界 | 800×800 m | 体素 1 m | ≤ 250k | 峰体、峰上 5–12 座建筑、石阶 |
| L2 建筑界 | 60×60 m | 体素 0.25 m | ≤ 150k | 现行高质量单体建筑 + 室内 |
转场：L0 点峰 → 相机推近 + 黑屏 0.35 s → L1；L1 点建筑 → 黑屏 → L2。

## 3. 生成器（一个 seed 出全部）
- `gen_world.gd`：世界地形 + 100 势力落点（已用 Python 版验证，迁到 GDScript 由游戏内生成）
- `gen_sect.gd`：sect.seed → 36 峰坐标/高度/半径（主峰居中最高，前山半腰放山门）
- `gen_peak.gd`：peak.seed → 峰上建筑布局（类型/朝向/台阶）
- `gen_building.gd`：building.type + seed → 体素几何（复用现有 `_hall/_roof_fly/_pagoda/_shop`）
- 原则：**同一 seed 必得同一结果**，所有随机数走 `RandomNumberGenerator(seed)`

## 4. UI 框架（横屏）
- 顶栏（96 px）：宗门名 + 灵石/声望/丹方/弟子，半透明墨底
- 底部导航（140 px）：宗门 · 弟子 · 世界 · 丹房 · 设置
- 主页 = 场景优先，**不放文字列表**；经营/详情走弹出抽屉（左滑入 720 px 宽）
- 世界页：316 km 地图（现有 world-map.png 重绘为游戏内程序图），可点 100 势力
- 弟子页：卡片网格（3 列），点击开详情
- 无一中国风以外的装饰；配色：墨 #0f1116 / 金 #d9b46a / 玉 #6fc7b5

## 5. 里程碑与验收
- **M0 骨架**：横屏跑通、目录、world.json、UI 空壳可切 5 页。验收：截 5 张页面图。
- **M1 宗主界**：36 峰地形 + 峰名标注 + 点峰高亮 + 进入 L1。验收：全屏截图 + 点击进峰录像。
- **M2 峰界**：单峰体素地形 + 5 座建筑 + 石阶。验收：两座不同峰各一张图。
- **M3 建筑界**：主殿/山门/塔/殿内，转场黑屏。验收：进殿录像。
- **M4 经营**：升级/招募/炼丹三套数值闭环。验收：改数值后画面与列表同步。
- **M5 打磨**：雾/云海/阴影/浮尘、人物巡逻、音乐开关。

## 6. 性能与风险
- 软渲染瓶颈在**像素填充**：1920×1080 全屏后处理（glow/SSAO）成本高 → L0 关 glow，L2 才开
- 体素上限 120 万；超了就用 1 m 体素降级
- 每个里程碑先出图再继续，避免"做完才发现方向错"
