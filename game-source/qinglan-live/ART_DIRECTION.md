# 《青岚》美术方向 v1

一句话：**水墨的骨，工笔的皮，琉璃的光。**
空间用青绿山水的气韵，形体用工笔重彩的克制，材质和光用琉璃玉石的通透。
不做西方奇幻，不做赛博霓虹，不做"灰扑扑的写实"。

---

## 1. 主题

三个母题，所有画面都要能指回其中一个：

| 母题 | 指什么 | 落地 |
| --- | --- | --- |
| 青绿山水 | 山、远、雾、留白 | 远景只用大块色阶，不加细节 |
| 朱砂印 | 人间、契约、血气、警示 | 全画面 ≤5% 面积，只出现在关键点 |
| 金线 | 品阶、神性、界限 | 描边、法阵、法宝轮廓 |

情绪三段：**静**（山雾松）→ **动**（剑气法术）→ **壮**（法相天门）。
写法上永远先给"静"的底，再让"动"破开它。全画面都在动等于没有动。

## 2. 色彩

### 主色板

| 名称 | HEX | 用途 | 面积 |
| --- | --- | --- | --- |
| 青碧（主袍） | `#2E8B8B` | 主角衣物 | 20% |
| 深青（暗部） | `#1B5E63` | 衣褶、山体暗面 | 15% |
| 天青（远山） | `#6E93A8` | 远景、雾 | 25% |
| 宣纸白 | `#EFE9DC` | 内衫、云、UI 底 | 20% |
| 墨 | `#14161A` | 描边、文字、发 | 12% |
| 朱砂 | `#C0392B` | 腰带、印章、危险态 | 3% |
| 金 | `#E8B33B` | 镶边、品阶、法宝 | 3% |
| 玉 | `#57C7A3` | 灵光、生机、治疗 | 2% |

### 纪律

- **60 / 30 / 10**：60% 低饱和环境，30% 主体，10% 高饱和点缀。
- 画面中饱和度最高的一撮像素**面积不超过 5%**，且只能属于法术、品阶、眼睛。
- 阴影不用纯黑，用冷紫灰 `#2A2B3A`；高光不用纯白，用暖米 `#FFF3DC`。
- 肤色走 `#E8C4A8`，阴影 `#B98A72`。不粉、不亮、不塑料。
- **硬指标**：主体轮廓与背景的明度差（L\* 差）≥ 25%，不够就加轮廓光，不许靠"加大对比度滤镜"糊。

## 3. 形状

分三层，各管各的：

| 层 | 面数预算 | 做法 |
| --- | --- | --- |
| 远（山、天） | 剪影 | 只做边缘线和 3–5 级色阶，零细节 |
| 中（建筑、树） | 8–15 面 | 几何归纳，靠朝向分色，不靠贴图 |
| 近（角色、道具） | 圆润体块 | 主形圆，配件硬；细节靠"分件"不靠"细分" |

- 形状语言：**上尖下宽**（发髻、肩线、裙摆），**C 形弧**（袖、飘带、剑光）。
- 角色比例 7.5 头身，肩宽 2.2 头，裙摆 3 头。头略小于写实，显仙气。
- 体块不许直接堆直角箱子，至少给一个倒角或锥度。
- **描边只给近景角色和 UI 图标**，1.5–2 px 屏幕空间恒定粗细；颜色 `#1A1B22` 不用纯黑；远景一律不描边——描边是"糊"的主要来源。

## 4. 材质

| 材质 | roughness | metalness | 备注 |
| --- | --- | --- | --- |
| 布（外袍） | 0.85 | 0.0 | 加 3% 法线噪声做织纹 |
| 丝（内衫、袖口） | 0.55 | 0.0 | 用渐变代替各向异性 |
| 金饰 | 0.25 | 1.0 | 只做小面积 |
| 玉 | 0.15 | 0.0 | 加次表面近似，透一点 |
| 山石 | 0.90 | 0.0 | 法线噪声 0.35，不贴图 |
| 水面 | 0.05 | 0.0 | 屏幕空间反射 + 细法线 |

统一：所有材质叠一层公共"纸纹"噪声（强度 0.03），让 3D 和 2D 界面不脱节。

## 5. 光彩

- 光源三层：主光暖 4200K、-40° 高角；天光冷 8000K、强度 0.3；轮廓光在战斗时切成品阶色。
- **只有三样东西允许发光**：法术、法宝、眼睛。衣服、头发、地面一律不发光。
- 发光结构三层：核心（白 1.0）→ 中层（品阶色）→ 外圈加色壳（半径 1.6×）。
- 品阶色：凡 `无` / 灵 `#57C7A3` / 宝 `#4A7BF7` / 仙 `#E8B33B` / 神 `#8B5CF6`。
- 全屏 bloom 强度不超过 0.6，禁止彩色泛光铺满。

## 6. UI 风格

- 载体隐喻：**卷轴 + 玉简**。面板是绢/纸，边框金线 1 px，按钮是印章。
- 字体最多三种：标题楷/宋（有笔锋）、正文黑体、数字等宽。
- 布局：外框留白 ≥ 24 px；面板内阴影 8%；不使用圆角 > 8 px（走"纸边"而不是"卡片"）。
- 动效：出现＝展开卷轴 0.25s ease-out；强调＝朱砂印章落下 0.15s（缩放 1.15→1.0）。
- 状态色：常态墨 `#14161A`，悬停金 `#E8B33B`，禁用 30% 透明，危险朱砂 `#C0392B`。
- 数值条改成"刻度尺"（天干地支式短刻线），不用圆角进度条。

## 7. 禁止项

1. 禁止"糊"：两米内相邻物体明度差 < 10% 就不许同色。
2. 禁止方块人、纸箱堆叠、拖鞋当靴子。
3. 禁止纯黑阴影 + 纯白高光。
4. 禁止布料塑料高光（roughness < 0.2 的布）。
5. 禁止全屏泛光、彩虹渐变、赛博霓虹。
6. 禁止把小图放大当原画，禁止贴图拉伸。
7. 禁止描边粗细随距离变化（要么恒定屏幕空间，要么不描）。
8. 禁止超过三种字体、超过两套圆角。
9. 禁止 UI 遮挡画面中心 1/3。
10. 禁止把元素堆满：每屏留白 ≥ 25%。
