# 《苍岚·人生世界》图形工艺硬门禁 rev207：高色度、真实PBR纹理、细密像素

## 用户反复反馈的现状与视觉目标
- 实际rev205 Godot1280×720截图：主城周围大面积淡灰绿与浅米色，草地像单色无纹理光斑，近景缺少密集的小像素信息；天空与雾冲淡青绿和材质差异。此结论由真实截图人工目视得出，不把自动测试绿灯当成美术合格。
- 禁止再用统一几种低饱和色刷满世界；不是把所有物体强制调成高亮荧光。要求材质有**明确颜色族、亮暗层次、磨损及细小纹理**，阳面饱满暖亮、阴面深青蓝。
- 参照细密像素HD-2D观感：地面和建筑表面**每米数十到数百个可辨色块/纹理texel**，远处使用mipmaps避免闪烁；不让整个画面缩到320×180造成大马赛克，清晰UI继续保持原生分辨率。
- 地表：青草中低亮度深绿、墨绿、翠绿、松绿；岩石青灰/炭灰，岩层有细粒；泥土赭棕与深棕，路面暖灰棕；避免泥土与草都是同一淡米色。水体青蓝，天空纯蓝到浅青但不灰紫。朝阳金黄，背光青冷。
- 建筑：维持开源Quaternius整体模型、原法线、UV、PBR贴图。用**源自Quaternius开源仓库并记录blob SHA1的原始瓷瓦、木构、白泥墙BaseColor+Normal+Roughness/ORM**，512²（像素间距细致）移动贴图减少PCK空间。不能直接用一个纯色遮掉贴图或者把房屋外形重新拼出来。
- 角色/动物：保留原始CC0 UV、骨骼、材质/法线/动作；仅非破坏式提高色彩与纹理过滤质量，皮肤不套草地贴图。法术五行保留独立高色度特效。

## 实施门禁（代码级）
1. 内建 `Environment.adjustment_enabled=true`、`adjustment_saturation≈1.28`、`adjustment_contrast≈1.08`、`adjustment_brightness≤1.0`；削减泛白的雾密度、散射与泛光，让近处不灰白。
2. `StandardMaterial3D` 保留vendor已有 Albedo/Normal/Roughness；缺失时只在识别的建筑材质使用有真实来源的墙/瓦/木PBR三通道，不得覆写动物或服饰的贴图。
3. 地面实际可挖可走网格绑定GPU world-space细密纹理shader（非平面背景）并保留原vertex-biome颜色及碰撞；每平方米约数千个texel；源像素采用无过度模糊的nearest-with-mipmaps方式采样，超过远景过滤后不能闪烁。
4. 正式高清纹理从GitHub本仓库内的授权Quaternius原图打包为小尺寸PBR原生png，PNG及不可变SHA256清单加入PCK；所有精简变体均可追溯原blob SHA1；不得使用未确认许可外部素材。
5. 原APK176 Godot 4.4.1真场景/GLB/色彩对比截图，测试需至少证明材料纹理绑定、UV/世界坐标映射、画面饱和度、色彩层级、地面碰撞不变、GPU花销和1280×720原生UI没有被像素化；审美审查仍由用户决定。
6. 仅rev206以及此后版本完成真引擎QA与签名/HTTPS公网上传并手机实测后，才能声明热更新完成。
