## 2026-10-20 · v0.5：API 与手机本地模型引擎

### 真实实现
- Android 版本更新为 versionCode 5、versionName 0.5.0，保留 v0.4 独立包名 `com.xinyanshuo.zhiyin.companion` 及同一公开测试签名。原则上可直接覆盖 v0.4 而不清除数据；安卓实机未验证不写通过。
- 新增原生 `AiSettingsActivity`：手机 GGUF 模型（默认离线）与兼容 OpenAI Chat Completions 的 HTTPS API 二选一；可手动填写完整端点路径、模型名称与密钥。
- 新增原生 `AiGateway`：AndroidKeyStore AES/GCM 加密保存API密钥（不在JSON记忆备份里）；经 HTTPS 发送 JSON `messages` 给 API；严格超时、错误提示，不回退到假AI固定话术。
- 通过 `llama.cpp` 原生 C++ JNI（上游固定 commit `1ba568c5ad5c6c718984bd2bf4e7c71485b706f9`）将 **arm64 GGUF CPU 推理核心真正编入APK**。`lib/arm64-v8a/libzhiyin_llm.so` 在已验签APK内为约13.8MB，JNI `load/generate/unload/lastError` 符号经静态检查存在。无外部Termux或浏览器壳依赖。
- 可在APP内联网下载 Apache-2.0 Qwen3-0.6B Q4_K_M GGUF（约484MB，Hugging Face）或从安卓文件管理器导入 GGUF；校验文件大小与 GGUF 头后复制到私有存储；模型不捆绑在APK中。离线推理本身不需要 API/账号。
- 玩家给知音发送的消息写入SQLite事件历史，异步调用用户选择的真实模型通道，成功回复写回原文；拼入角色设定与近期角色可见历史，独立角色私有记忆不会直接跨角色共享。失败时明确显示错误。
- 原有2.5D生活场景、房租经济、社区关系、音乐录音与剧本功能继续保留。当前AI仅在知音聊天入口调用；其他NPC的自由AI对话与模型驱动行动计划未接入。

### 不得隐瞒的限制
- **API费用由实际服务方计费**，不是把 ChatGPT Plus 额度转成 API。API 模式会把当前问题、有限历史和角色卡发往用户配置的服务；仅本地模式保证生成文本不走外部聊天API。
- 本地模型约484MB需要自行下载，低端设备可能运行慢或内存不足；没有配置模型时不得显示预录假回答。
- 真正歌声合成、实时多人角色自主AI、完整语音双工、图片模型与高品质室内素材仍未实现；AI仅文本对话。
- **实验测试签名是公开可复现的，不安全，不能用于正式上架/敏感私密数据**，P0正式签名体系仍未完成。
