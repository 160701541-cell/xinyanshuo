- **AI生活计划选项**：AI引擎设置新增可选开关（默认关）；用户确认开启后，前台每15分钟至多请求一次模型选择业余活动（API模式会产生真实费用）；生存需求、吃饭/打工/房租优先，模型仅可建议白名单中的读书、练歌、弹琴、写日记、浇花等行为。结构化JSON需校验，模型未返回有效行动则记录原因而不执行。候选计划进入持久化任务队列，在当前任务完成后按需执行，2小时过期。
- **本地模型回复稳定性**：推理生成上限160→256，增加Qwen3非思考提示，识别未输出正文的异常；模型文件覆盖替换时比较更新时间和大小，重新装入新GGUF模型。
- **API安全**：停止自动跨域HTTP重定向，降低密钥被错误转发风险。
- **角色职责不变**：知音有咖啡馆兼职收入与每周房租，音乐纯属个人爱好；其他居民仍未实现可见实体/完整物理生活，本轮实现的是角色人格化AI聊天，不是全部自主生态。
- **记忆约束**：所有原始对话仍保留SQLite；进入模型的历史为有限筛选窗口，仍未实现高质量语义长期召回；不得声称无限上下文或无损AI摘要。
- **隐私与成本**：本地GGUF在手机推理；选择云端API才发送必要的角色卡和上下文。自主计划开关默认为关闭，避免未经同意产生调用费用。

- 新增原生 `AiGateway`：AndroidKeyStore AES/GCM 加密保存API密钥（不在JSON记忆备份里）；经 HTTPS 发送 JSON `messages` 给 API；严格超时、错误提示，不回退到假AI固定话术。
