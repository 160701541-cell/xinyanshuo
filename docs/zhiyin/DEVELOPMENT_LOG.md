# 《知音》独立原生安卓开发日志

## 2026-10-20 · v0.4：2.5D场景与社会生活原型
- **发布位置**：`zhiyin-native/`，隔离开发分支 `zhiyin/native-android-prototype`；与《苍岚》主分支、WorldBox均不混用。当前未创建专属GitHub新仓库；本项目是独立包名的隔离开发目录。
- **最新测试包**：`com.xinyanshuo.zhiyin.companion`，versionCode 4，versionName 0.4.0，Android 8.0以上，原生 Java/Canvas/SQLite。
- **已实装**：等轴测2.5D 3.2m×3.2m（10.24㎡）房间；双指缩放、单指平移、多个家具触摸；夜间吊灯，人物走动、表情、睡眠与对应活动道具。
- **已实装**：咖啡馆兼职工作与每日一次工资64模拟币；固定每周租金160；食材采购、处理、餐食、碗碟与打扫；音乐纯爱好，不凭空产生收入；存款/债务/结算结果保存到生活数据。
- **已实装**：居民各自独立住所档案（玩家住梧桐街），NPC职业、兴趣、人格与熟悉度；社区2.5D地图平移缩放；社交冷却，长期记录。
- **已实装**：原生浮动聊天条，系统语音识别入口，TTS朗读（不是AI歌声），SQLite原文保存与JSON档案备份，包括生活数据及社交数据。
- **签名解决策略**：v0.4更换新包名避免破坏旧版已安装的用户数据，可并存迁移。CI实验APK采用公开可复现的测试签名，签名一致性可以通过多次构建校验。**该密钥公开、不可用于正式发布或存放敏感私人内容**；需要在正式发布前使用私有签名凭证迁移生产包，用户可能再次经历一次明确迁移。
- **QA**：源代码已进入GitHub Actions Gradle构建流程。仅CI编译及APK签名验证可评定通过，手机真机显示、触摸手势、音频和动画需要用户测试才可验收。

## P0 未完成
1. 首屏人物造型依然是程序绘制占位，未满足商用级2.5D人物/完整骨骼动画/面部表情、材质纹理要求。
2. 未实现真正本地LLM聊天/个性化认知/语音交互打断，仍是规则回复。
3. 各NPC尚未拥有彼此独立、可视、可持续的生活实体；当前除知音之外主要是居民档案和社交原型。
4. 真正AI歌唱合成、双向A/B唱段、智能教学纠错尚未落地。
5. 正式签名与安全更新/密钥保管未实现，公开实验签名不可用于发布。
6. 安卓设备上的完整触摸、画面、性能、迁移与隐私实测未验收。
