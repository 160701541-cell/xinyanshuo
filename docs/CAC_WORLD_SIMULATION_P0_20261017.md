## P0 首批可验收目标
1. 自然资源账本：每个资源节点有稳定ID、坐标、初始储量、剩余量、资源种类、再生规则和上次模拟时间；矿石有限，森林受种子/生长/环境约束，农田按季节和水肥产出。禁止无上限周期刷新。
2. NPC状态：身份、家庭、职业、饥饿/精力、目标、记忆与任务锁；离线AI未安装时使用可解释规则自主运转，不得阻断生产。
3. 物资守恒：采集扣自然节点，运输进入个人背包，加工扣原料并产出加工品，仓库/工地转移为原子操作；中断时不复制资源。
4. 建造：真实地块与蓝图需求，材料到场、工人到场、分阶段计时才可出现建筑构件；失败/死亡/饥饿/缺料中断并可存档恢复。
5. QA：固定随机种子模拟至少1000个时间步；检查物资守恒、资源不负、同一任务不重复执行、断档恢复一致、没有无成本建筑。通过Godot引擎和原版主场景兼容审计后才可签发PCK。
