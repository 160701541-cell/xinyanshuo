# 《苍岚·人生世界》正式视觉验收基线（2026-10-18）

> 用户提供的 2026-10-18 横屏手机截图是不合格原型，不得标注“画质达标”“实机达到概念图”。此前生成的华丽森林战斗图是**概念参考**，不是 Godot 实机截图，也不是 WorldXAI 已输出的成果。

## 全局禁止事项

* 新增正式资源**禁止明显低模几何、单色棱柱发型/圆筒肢体/彩色桶型资源道具**。已有 CC0 低模只可作为临时构建/距离降级资源；杂役与凡人也要求完整发型、材质和动作，低模不等于可无限降低质量。
* 场景**不允许用更小的 Kenney 树伪装密林**；植被按现实相对尺寸布置；近景树冠遮挡人物/交互区、树高低于成年人均直接退回。
* 灵植不能与随机背景草复用外观。必须有独立轮廓、叶序、色相或异色纹理、收获状态和近距交互高亮；灵物的稀有性不代表所有灵物满屏常亮霓虹。
* 不准把世界生成图、AI 概念图冒充原版 Godot 引擎实拍；WorldXAI 图片只用于美术参考，必须核对纹理授权、各视角一致性和实际导入到游戏的截图。
* 取消“逐帧外观像原型就放行”的习惯：Godot CI 技术绿灯≠审美合格≠手机帧率合格。

## WorldXAI 资产到游戏的可追溯链

1. **标定**：用用户给的高品质修仙场景图定统一色板、真实人体尺度、光源方向；不以低模测试帧作为目标图。
2. **WorldXAI 生图**：按人物正/侧/背三视图、发型及服饰拆分；树冠/树干/树根、灵草生长阶段分组。若没有可调用的 WorldXAI 账号/API，则登记为阻塞，不虚构生图结果。
3. **一致性比对**：将目标 2D 参考图与后续引擎捕获在相近机位、时间、曝光下对照：主体占屏比、植物高度分布、主色明度/饱和度、树冠遮挡、灵草背景差异、面部可读性。
4. **3D 化**：正式人形需合法商用高精角色资源/重建并进行骨骼蒙皮和动画绑定。**单张生图不能自动变成高精 3D 人物**；导入实际 GLB/PBR/LOD 后才能算游戏资产。
5. **质量闸门**：独立 Godot 4.4.1 parse → 原版 Main 真正运行 → 正脸/三视/森林/战斗多机位捕图 → 人工视觉审查 → Android 原签名 PCK → 官网 RSA+SHA256+Range 206 → 用户 Android 实机 FPS/触屏/温度验收。任何失败停发。
