## 2. 修仙与凡人炼体双轨
- 灵修路线：感气/炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫（具体境界文案按自有世界规则延展）；需要灵根契合、功法、资源、突破与寿元制约。宗门外的人可作散修。
- 体修路线：锻皮 → 炼筋 → 淬骨 → 换血 → 通脉 → 先天 → 宗师 → 大宗师 → 陆地神仙（非灵修等价境界，胜负取决于实战/克制和代价）。无灵根者可循此路；有灵根亦可体法双修，成本更高。
- 旁门：制符（符纸/朱砂/兽血/阵纹/法力封印）、御兽（驯养/契约/食物与兽栏/感应）、灵植（播种/土壤/灵气/照料/虫害）、丹道、炼器、阵法、傀儡、炼虫、医修、卜算、商修、剑修、音修、鬼修等；**不是点职业自动获得成品，材料须来自同一库存/世界来源，术业有学习和失败代价**。
- 功法资质由根性、灵气环境、悟性、师承、功法传授、财力、寿命与随机际遇共同决定。可修炼、闭关、突破失败、受伤甚至死亡；不让NPC无限刷级。

## 3. 矿脉妖兽共栖与繁育
- 有灵矿/高灵压处，通常吸引灵兽、护矿妖兽或人族散修。矿品/灵气/荒野安全度决定妖兽密度，不是每个矿洞保证同级妖王。矿兽有种族、性别、年龄、寿命、家族/兽群、食物、领地、攻击性、灵性、属性、境界与修为。
- 妖兽路线：启灵 → 聚灵 → 凝丹 → 化形 → 妖婴 → 妖尊 → 更高劫数（不与人族一一机械等同）。机缘/功法/灵脉可提高修炼效率，但受能量预算和境界瓶颈限制。
- 生殖依赖成熟雌雄、食物与区域容纳量；子代继承部分血脉；人/兽都要经历真实成长，出生幼兽不是瞬间高阶战力。狩猎降低群落数量和繁殖能力；生态能恢复但不无限凭空重生。
- **rev207候选**沿用可商用Quaternius真实3D动画狼、狐、鹿、牛，实际站位调整到rev206真实四条灵石矿旁，保留其物理碰撞、HP/MP、受击/敌意/战利品；原世界时间驱动四个统计兽群的修炼、繁育、衰亡。可见的是四个首领，其余统计个体的实体生成、幼兽动作、繁殖动画、育幼行为仍是后续工作，不得以统计数字冒充可见动物。

## 4. 绿色覆盖：地表不能秃，也不能无条件刷新物资
- **植物永远不能“整个物种归零”**：每个合适生境有活种子库、孢子、地下根茎、林冠与多年龄段草木。采摘使叶/花/成熟药材的 **可采单位** 临时为0，不代表植株、根茎、种群被删；有雨水、土壤、灵气、风、水、动物传播的条件才再生，荒地可进行自然演替。
- 植物分：草本、灌木、藤本、乔木、蕨类、地衣、苔藓、灵草、灵木、菌芝、药圃农作物；季节、日照、水位、坡度、土层、灵气浓度决定密度、颜色、外观、收获。
- 除建筑基座、石砖道路、河湖、陡岩及正在使用的施工地以外，所有适合生长的土地应有低植被与自然杂物覆盖，森林区域应密集多层、草地饱满深绿。不能用屏幕单色纹理和一堆NPC卡位冒充植物。
