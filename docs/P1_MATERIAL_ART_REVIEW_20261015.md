# P1 青灰瓦、白墙材质：技术QA通过 ≠ 美术验收通过
**复核时间**：2026-10-15。**对象**：新生成器提交93dc977，对256px原始Albedo 3倍放大观察；本次不是Godot画面，更不是Android截图。

## 人眼复核结论：ART FAIL
- **青瓦**：能读出冷青灰色基调，但整体是规则的柔和暗亮竖带，缺屋脊、瓦当、滴水、瓦片层间阴影、近景瓦缝、各片明暗变体。3倍放大看起来较模糊，**不能作为国风成品屋顶**。真实几何与纹理必须分层制作，不能拿这张法线图冒充瓦面实体。
- **灰泥**：颜色进入米白灰区间，但层次过分光滑均匀；尚无砂眼、纤维、墙根含水风化、角部修补及与真实石基/木构的关系；不能满足“白墙细节可观察”的近景标准。
- 两者同一渲染场景、同一日照、移动端纹理压缩下的颜色保真仍**未测试**，仅2D贴图检测不能证明神韵或视觉完成度。
- 生成器正常输出6张图，独立PNG/CRC/哈希/接缝/法线/粗糙度、12项变异QA真实通过，这些属于**资产数据完整性通过**，不等于美术通过。
- 仍不满足场景审美：1名工匠/真实动画未通过、景观与建筑结构不完整，已知巨大蓝色几何面片和室内镜头穿顶未排除。

## 下次制作的前置条件与验收
1. 先按用户国风2D参考及当前Godot真实图固定10米院落构图、调色板、正房构件图、屋脊和瓦纹尺度；做单体结构与瓦片实物网格，不是无限往同一种噪声图上堆特效。
2. 增加近景艺术处理过的标准白灰泥/青瓦材质（包含适当UV密度与材质变体），导入现有主游戏相同Terrain3D日光场景；每一项有合法来源与性能预算。
3. 同一机位1280x720输出参考/旧Godot/新Godot三联图、Android实际图；记录Commit、渲染器、GPU、纹理压缩、画质档、时刻。任何一张没有真实引擎来源都不能作为通过证据。
4. 人工审视第一眼必须读到古代院落、落地墙基、屋顶青瓦、自然地形和有生命的劳动人物；不合格明确FAIL，不允许打勾推进大城建设。
5. 技术自动QA只充当下限，最终美术人工批准是**独立条件**。当前 **S=PASS，U=PASS，I=BLOCKED，V=BLOCKED，D=BLOCKED，R=BLOCKED，A=FAIL**。
