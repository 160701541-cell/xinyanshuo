## 0. 核心目标
建设以古代架空社会为核心、隐含修仙世界的Android Godot 4.4+原生3D开放世界。NPC有独立身份、职业、家庭、记忆、财产、目标与生命历程；资源先于任务存在，采集、搬运、加工、施工均发生在真实世界。玩家可做凡人、商人、官员、将军、宗主、修士或反派。世界不围绕玩家转，离线仍可推进。

**总体验验收**：原游戏内更新后，玩家在漂亮统一的国风3D村庄里看见NPC醒来、进食、上工、砍树、搬运、加工、分阶段建屋；树木会耗尽/再生，田地按季节产出，NPC有生老病死；玩家能参与和改变这一切。旧存档保留，操作舒适，安卓性能达标。

## 3. 美术质量标准
**画风**：国风风格化3D、自然青绿、青灰瓦、深褐木、暖白墙、石阶、河谷、竹林、薄雾、暖阳冷影；统一材质粗糙度、纹理比例、模型比例。**拒绝**杂乱素材拼接、荧光草地、塑料瓦片、漂浮房屋、纸片人和T-pose。
- 建筑：中式院落、正房厢房、月洞门、实体门窗与室内、地基贴地、施工/损毁构件可见。
- 人物：仅上架真正带骨骼/动画的授权成品，脚步接地、携物挂点、转向自然。
- 环境：四季生长、昼夜灯笼自动开关、天气、天空、雾、阴影、远景层次。
- 视觉验收：晨午昏夜×近中远×第一/第三人称，另有室内/雨雪/施工/火灾；必须Godot真实帧缓冲截图，概念图仅供参考。

## 4. 权威模拟合同
- `resource_id`、`entity_id`稳定不复用；资源节点有坐标、初始量、剩余量、生态条件、上次模拟tick。
- 采集扣自然节点加背包；运输扣背包加仓库；加工扣输入加产出/废料；施工扣工地材料加阶段进度。全部用`txn_id`和幂等键原子提交，不能重复发物。
- NPC行为优先满足食物、水、睡眠、安全、就业、家庭、社会、修炼；模型只可申请白名单动作，规则门再次验证职业、产权、库存、时间、位置和任务占用。
- 建造状态：`PROPOSED→LAND_CHECK→FUNDED→MATERIAL_RESERVED→FOUNDATION→FRAME→WALLS→ROOF→INTERIOR→INSPECTED→ACTIVE`，允许暂停、失败、维修、拆除；缺料/缺工/灾害必须中断。
- 近景精确NPC与实体，中景低频模拟，远景聚合经济；存档/离线恢复与固定种子重放保持一致。

## 5. 修仙世界合同
- 参考传统凡人流的稀缺机缘和修炼代价，创作原创世界，不直接复制小说剧情/角色/专有设定。
- 建议境界：炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、渡劫/飞升；具体寿元、突破概率、资源消耗另建平衡表。
- 灵根隐藏需检测；无灵根可习武、经商、从军、入仕；魔修/邪修/鬼修有合理立场。
- 功法有来源、契合、残篇、心境和副作用；炼丹需真实灵植/火候/药性，炼器需真实矿石/器胚，阵法需阵基/灵石。
- 妖兽有领地、食物链、繁殖和稀有度；凡俗村庄不频繁刷新妖兽。宗门有师徒、贡献、资源、派系、传承；秘境有开启周期、竞争和真实死亡风险。

## 2026-10-17 生态/地质新规则（正式需求，非全部实现）
- **生态账本**：砍到一棵资源树真正耗尽才得到一颗可追踪的种子，种子必须先随工人回仓或被玩家携带，再用于落地播种；已产种树桩不能重复刷种，树苗要有年龄、体积和成活率并受水、土、季节、生境、密度影响。rev182仅实现简化的种子→幼苗→幼树→成熟树。
- **石层复露**：建筑和仓库保护区内不得凭空长矿/穿模；矿脉的地上“石子→石块→石堆”由有限地下储层缓慢露出，开采物必须与仓储、背包和施工消耗守恒。rev182初步每48游戏小时转出地下1单位（仅简化演示），后续季节/水动力/风化、回填、采空塌陷与河谷剖面需要统一地质系统。
- **真正造山**：石堆不会无限自行叠成喜马拉雅山；需地壳板块碰撞，数百万年持续构造抬升与流水冰川侵蚀、沉积、区域应力，地质时钟不等同村民寿命时钟。大世界用分块高度场、场数据和多级LOD记录从丘陵→山地→高山→山脉连续演进，保存海拔和地貌物料流，建筑地基需随地形变化有受力/沉降风险。rev182只提供**独立地质年代测试规则和远处高度缩尺地形示意**，不能称完成真实喜马拉雅尺度开放地图。
- **手机实际画面**：rev181两张用户真机图确认NPC劳动仓储/施工信息可显示，但人物看不见且约29–30FPS、Draw超预算。rev182已在原APK176引入Quaternius角色Mesh AABB身高规范化、3D岗位ID名字、NPC跟随摄像机、SubViewport 2倍缩小渲染；**手机rev182身高可见性和稳定FPS仍须用户实机再次验收**，头less Godot通过不足以冒充通过。
- **原版更新事实（2026-10-17）**：原APK176固定RSA rev182正式Git提交`5e75dcb`及外部CDN完整HTTPS 206独立验证run`38973719482`/job`117217970466`通过；不需要安装独立测试APK。版本可能日后变化，每次读取`android-preview/latest.json`和相应签名日志。旧存档未动，但rev182原机保存连续性待证。
