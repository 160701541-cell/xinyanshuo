- 使用 WorldX/Kolors V3 输出的 1024×1024 原始 PNG，进行**不调用图像生成API的多边形区域拆分**。
- 本轮产出 12 个带 alpha 通道的**可见部分裁剪候选**：主屋顶、檐口、正房门廊、左右侧建筑、院门、庭院铺地、庭院石雕、前景左右树、背景左右。
