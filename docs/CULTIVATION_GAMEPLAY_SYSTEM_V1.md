# 苍岚·人生世界｜修仙玩法系统总设计 v0.1（独立模块）
> 2026-10-17；负责人：玩法/系统。状态：SPEC_ONLY；未接入Godot、未通过CI、未发布。与另一会话的3D美术、地形、NPC工程分工隔离。参考《凡人修仙传》的凡人求道、资源稀缺、境界递进与修真社会结构；**不复制原作专有角色、宗门、功法、法宝名称或剧情**。

## 1. 设计支柱
1. **凡人世界先成立**：默认玩家只是普通人，修仙是隐藏机会；灵根需在合适地点检测，不能在开局面板直接显示。无灵根可走武道、工匠、商贾、文道等路径，仍能影响修真世界。
2. **无主角特权**：修士会衰老、受伤、陨落；灵根好也不保证破境。NPC与玩家使用相同基础资源、风险和寿元规则。敌人会逃跑、结盟、伏击、议价。
3. **修炼不是挂机加数字**：功法适配、灵气环境、资源、心境、经脉负荷、时间与瓶颈共同决定进展；破境有准备、失败和后果。
4. **修仙嵌入实体世界**：丹药必须消耗真实药材与炉具，灵田有土地/水/季节，法器有材料与工序，宗门有地契、成员、仓储和财政；严禁生成“幽灵库存”。
5. **可选正邪，不以标签代替因果**：魔修、鬼修、正道均有可解释的成本、伦理选择、声望和业力后果。

## 3. 灵根、体质与修炼
- 五行灵根（金木水火土）及变异属性（风雷冰等）为**权重向量**，不简单分“废/天才”；相生相克影响功法效率、法术威力、炼丹炼器偏好。角色创建随机结果可锁定存档，检测前不展示。
- 体质与灵根分离：经脉容量、神识、肉身强度、毒抗、悟性、寿元；天赋有代价，不给永久无条件加成。
- 每个功法定义：ID、流派、属性、适用境界、前置功法、修炼地点、周天时间、资源消耗、风险、招式解锁、传承来源；功法可残缺、误传、抄录、交易、失窃。
- 修炼流程：选择功法→检查师承/秘籍→计算灵气浓度与相性→按游戏时间运行周天→消耗真实灵石/丹药（如选用）→积累修为与经脉负荷→瓶颈准备→渡劫或闭关突破→记入事件日志。
- 闭关不是世界暂停：NPC、宗门、市场、战争和灵田继续推进；外敌入侵、灵气枯竭、走火入魔可打断。

## 4. 物品与生产树
**类别**：灵石（下中上极品、储能衰减）、灵药/灵植（种子/苗/成熟/枯萎/药性年份）、丹药、符箓、阵旗阵盘、矿石、器胚、法器、灵器、法宝、传承玉简、妖兽材料、功法秘籍、宗门令牌。
- 灵植实例有基因/药龄/地块ID/灵气吸收/水肥/病害/采收记录；稀有药材可人工驯化但有退化风险。
- 丹药配方明确原料、批次、炉具、火候、药性冲突、炼制时间、失败产物及丹毒累积；不得靠菜单直接把草变丹。
- 武器谱系：凡铁兵刃→符文兵器→低阶法器→灵器→本命法宝；剑、刀、枪、印、鼎、幡、针、飞舟各有距离、重量、灵力消耗、耐久、控制与克制。
- 法宝有唯一实例ID、器灵（可选）、祭炼归属、维修记录、损毁状态；死亡不保证掉落，取决于现场、储物法器与NPC行为。
- 交易有价格波动、地域供需、拍卖、鉴定、赝品、税费与宗门贡献；稀缺资源不能无限商店刷新。

## 5. 妖兽、灵植与生态
- 妖兽不是随机刷怪点：每个物种定义生境、食性、昼夜、领地、繁殖、迁徙、成长、灵智、危险等级、材料掉落条件。高阶妖兽通常远离凡人聚落；越界有真实生态/事件原因。
- 妖兽成长：幼体→成体→成熟→衰老；血脉、进化与化形需要资源和风险。灵宠契约有忠诚、饥饿、恐惧和背叛，不是永久听话。
- 灵脉影响植物、矿藏、妖兽与宗门选址；过度采掘造成灵脉衰退、生态失衡和势力争夺。
- 首批物种候选：青脊山狼、雾角鹿、岩甲蜥、赤羽隼、寒潭鳞蛇、腐木灵蛾；均为原创设计占位，未制作美术/AI。

## 6. 门派、家族与势力
- 门派由**可持久化实体**构成：山门地块、建筑、仓库、灵田、灵脉产权、财政、功法库、贡献账本、成员与职务。
- 职位：杂役、外门、内门、亲传、执事、长老、掌门；权限来自任命/声望/实力/制度，不由境界自动发放。
- 玩法：入门考核、师徒授艺、任务贡献、藏经阁借阅、炼丹房排队、灵田租种、外出历练、争夺灵脉、宗门外交、叛门与继承。
- 玩家可创宗立派，但需合法或武力取得土地、募集人员、维持粮食/灵石/安全；宗门倒闭或被灭后产权与债务要有结算。
- NPC各有欲望和知识边界，不会凭空知道玩家秘密；门派斗争由资源、理念、关系与事件推动。

## 7. 秘境与探索
- 秘境是独立空间或封锁地理区域，带入口坐标、开放条件、持续时间、危险等级、资源生态、阵法机关、探索记录和退出规则。
- 类型：废弃洞府、古战场、灵药谷、地火窟、妖兽巢、破碎小界；随机种子决定布局，但入口和已发现内容要稳定存档。
- 机制：地图未知、神识探查、阵法破解、环境伤害、竞争修士、负重撤离、物品鉴定；死亡有真实后果。秘境资源耗尽后不会瞬间刷新。
- “机缘”由世界事件和可追溯生成种子触发；强者可以先一步取走宝物，玩家不是唯一探索者。

## 8. 战斗与死亡
- 每次攻击判定：感知→目标意图→施法准备→消耗法力/符箓/耐久→距离与遮挡→护盾/五行克制→伤势与环境→仇恨/逃跑。
- 高境界优势来自速度、法力、神识、装备与经验，不直接按等级判定秒杀。可通过陷阱、阵法、偷袭、地形和人数影响结果。
- 受伤按部位/经脉/神魂分类，恢复有药物与时间成本；失败可逃生、被俘、重伤、修为跌落或死亡。世界不因玩家死亡停止。
- 复活、夺舍、转世为极罕见高风险后期机制，绝非免费读档功能。

## 9. 首个可玩闭环（MVP）
**村中凡人→听闻修士→寻找检测→接触一门低阶功法→采集灵草→炼制低阶药剂→学习御物→遭遇一只低阶妖兽→出售材料换灵石→加入小宗门或拒绝入门。**
必须接入既有公开3D工程的真实时间、NPC身份、WorldState与物品树；不另造一套与原世界平行的“修仙背包”。先用无美术的测试数据验证交易、修炼、库存守恒与存档，随后才制作视觉/UI。
