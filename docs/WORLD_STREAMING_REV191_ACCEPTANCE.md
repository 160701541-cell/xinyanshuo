# 《苍岚·人生世界》无限世界与修仙环境工程合同（rev191起执行）

## 玩家目标与边界：Minecraft规模 ≠ 方块画风
- 产品要求是**可持续探索、确定性生成、真实可改造、具完整经济与NPC生活的超大修仙世界**，不只是把92米的地面放大或加一圈装饰山。世界地理不应有玩家可见的方盒截面、矩形海沟、无尽平面和镜头飞过后的渲染空洞。
- 2026-10-17手机截图暴露：中央浅青平面与周围绿色低模区以直立方形边缘分割，河岸/开挖地块异常，草像短胡茬，建筑像脚手架，玩家NPC不显形。视为P0真机拒收。参考图片是目标气质（仙侠山水、植被草甸、飞檐青瓦、清爽HUD），不可把AI概念图冒充引擎素材或手机实机图。
- **当下真实实现仍是92m×92m可挖地层+636m左右的不可编辑远景LOD**，玩家行走仍限制在起始场景附近。严格禁止把旧版静态远景命名“无限世界”或宣称Minecraft式chunk stream已实现。rev191首个增量只修地面接缝与草甸体块。

## 工程目标：按区块可无限延展（未来阶段，不可跳步伪交付）
1. **世界分区**：逻辑坐标使用整数区块坐标 `(chunk_x,chunk_z)` + 区块内局部米制位置。首版设定32m×32m/区块、地形顶点网格1m/2m，视觉LOD分别按近中远切换；随机种子+地貌/海拔/纬度/雨量确定世界，**相同seed与区块坐标在不同手机生成相同高度、河道、材料、植被候选与城址**。远景不参与NPC精确模拟时可以分级缓存，但禁止无中生有的永久资源。
2. **加载**：主角周围3×3块完整地形、外两环中LOD，超远处背景HLOD/大地形；每帧有三角面数和内存上限，拆分创建/回收以避免停顿。摄像机自由飞行与地图上帝视角加载范围分离，不因为相机离开就传送/创建NPC。
3. **物理**：角色所在区块及相邻区块按同一height公式与地形挖掘增量生成碰撞体，边缘顶点共享；寻路与高差/桥、梯、路关系真实。水和岸坡使用统一高度/湿度场与河道mask，不可让渲染water卡片覆盖悬空白地。
4. **改造/存档**：基础seed静态可再生，只有玩家/NPC造成的挖掘、开矿、树木死亡、生长、种植、建筑施工、建筑住户及经济库存写入逐chunk delta，键 `world_id:cx:cz:entity_id`；流式卸载不得重置或复制已经采集过的木材、石头、钱、NPC财产。保存具有模式版本/校验/原子写入以保护原存档。
5. **NPC模拟**：NPC身份不可随区块加载生灭；远距采用摘要作息/产销tick，进近处恢复实体具体状态，库存/位置/身份ID不变。住房/宗门/田地实际由蓝图→材料→仓库→NPC施工阶段构成，室内允许玩家和NPC进入，床位和门碰撞可玩。
6. **美术分层**：基础地表颜色/材质随坡度、湿度、海拔、温度、冲刷及开挖深度自然过渡；真实草甸由10+片外弯宽叶簇、聚集草群/地被/小花/灌丛组成，水里/施工地/坡度太陡/路面禁生。近中远LOD区分，**同一草簇模型不应该散成一地牙签**。宗门书院用可溯源的CC0模块件与合法材质搭屋檐、斗拱、屋顶、门窗、台基、室内，不能凭图片贴出整栋房子。
7. **画质预算**：一加Ace 5 Pro保持用户三档极致/高档/普通手动选择，屏幕刷新率上限与性能实测不得编造；大量草/远景使用MultiMesh与LOD而非每根草独立draw；画质先正确再做性能。
8. **发布合同**：只在原APK176签名PCK热更新；每批先GDScript parse→原APK176 Main功能→真实Godot两视角截帧→RSA签名→HTTPS公钥/字节/Range→用户手机截图。新增流式引擎需要原生依赖时必须先审计APK再判断是否需要覆盖安装。
