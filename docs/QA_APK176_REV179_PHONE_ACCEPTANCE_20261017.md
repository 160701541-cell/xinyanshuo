## 从实机证据得到的研发优先级（须进入原APK176签名热更新）

1. **P0 交付链**：用户截图证明原版手机已出现rev179叠加的真实3D画面；此前RSA签署、Pages及原引擎兼容发布链已证明工作。后续不重复换APK。回到原游戏、重启是否保持、历史存档是否保持，仍需补充实测。
2. **P1 场景观感**：停止继续扩大光秃秃的展示地面/堆静态树石。转为可玩的200m×200m统一国风村庄切片，现成许可可商用的模块化中式建筑件、地表纹理、植物、石阶、道路、光照雾与比例基准；树、石仅是具库存和生长/采集状态的世界实体外观。
3. **P1 性能**：从`Draw 417/200`、`Triangles 277931/150000`进入实际摄像头统计、LOD、遮挡剔除、多实例绘制、拆开旧世界与预览叠加的GPU成本；以实机连续90秒、温控、真实驱动型号为验收门槛。不能因瞬时90FPS就认定合格。
4. **P0/P1 玩法闭环**：现成带脚部运动动画的人形NPC → ID/职业/需求 → 实体树石库存 → 砍伐/采矿/搬运 → 分阶段施工；本地AI在客户端原生组件具备、玩家游戏内下载模型后才可启用，AI不能凭空增物资。
5. **P1 操作**：最终场景应是可走、可看、可交互的3D世界，不应停留在自动旋转预览间。左摇杆与右侧视角无冲突；新开发需老存档和返回按钮回归。
