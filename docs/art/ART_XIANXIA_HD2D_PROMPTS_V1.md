# 苍岚 · 修仙 2.5D 美术提示词系统 v1

> 目的：用一套**固定前缀 + 可变场景**的提示词，让 10 张不同场景看起来是**同一个世界**，
> 同时从生成端就杜绝三种已翻车的结果：整幅偏黄、整幅压暗、单色糊成一片。
> 旧批次（plate01–plate15）全部作废，不入库、不参与调色、不作为参考图喂模型。

## 0. 三条硬性判据（生成后先用脚本量，不靠肉眼）

| 判据 | 阈值 | 治的是 |
|---|---|---|
| 单一色相占比 | ≤ 45% | 「整体都是黄的」 |
| 可辨色相数（占比 ≥5%） | ≥ 4 | 「全是一个颜色渲染」 |
| 中位亮度 L（0–255） | 95–135 | 「又太暗了」 |
| 暗部（L<40）面积占比 | ≤ 18% | 暗部糊死、细节消失 |
| 拉普拉斯方差 | ≥ 200 | 「没有细节」 |
| 四张场景的色相直方图 L1 距离 | ≤ 0.25 | 「风格不统一」 |

任何一项不过 → 只改**单条**可变段重跑该张，不许全局调色一刀切。

## 1. 美术定调（这一段的词才是风格本身）

修仙世界的视觉，不是「武侠土黄滤镜」，也不是「仙侠网游满屏金光」。
定调三句：

1. **材质可信**：石是青灰砂岩带凿痕，木是深赭老木带铁钉与包浆，瓦是青灰筒瓦带苔痕与釉光，铜器带氧化斑。
   近景能看清颗粒与木纹，中景能看清瓦当与斗拱，远景收成剪影与雾。
2. **冷暖分家**：天光冷青、主光暖白、灯笼/法器暖金。一个场景至少三种光各管一片区域，
   冷部不许被暖光吃掉，暖部不许糊成一团黄。
3. **中间调画面**：大白天的场景就该亮，夜景靠**局部光**和不压死的暗部来暗，而不是把整幅曝光拉低。

## 2. 四段式提示词模板（固定三段 + 可变一段）

### LENS（固定）
```
35毫米等效焦距，机位高度1.6米，视线水平，向下俯角3到8度，一点透视，
地平线位于画面上三分之一处，前景空地从画面底边一直延伸到中景，纵深自然收拢，
画面下方三分之一是干净可站人的平地
```

### STYLE（固定）
```
游戏实机渲染画面，第三人称RPG场景，虚幻引擎5品质，物理基础渲染，
真实材质与微小表面细节：石面凿痕与颗粒、老木纹与铁钉、筒瓦苔痕与釉光、铜器氧化斑，
全局光照与软阴影，三层光：冷青天光、暖白主光、局部暖金灯火，
中远景体积雾，只在远景轻微景深，画面整体中间调，亮部通透，暗部保留材质不死黑
```

### PALETTE（固定，这是「不许单色」的机制）
```
配色必须同时出现五种以上色相并各占可辨比例：
黛青与石青（瓦顶、远山、冷部阴影）约三成，
青灰石板（地面、台阶、墙体）约两成半，
苔绿与竹青（植被、苔痕）约一成半，
朱砂与丹漆（立柱、门扇、幡旗、灯笼）约一成，
月白与雾白（云气、炊烟、衣料）约一成，
暖金（灯火、法器、水面反光）不超过一成；
每个色相都要有受光面、过渡面、阴影面三个层次，
不允许整幅被单一黄色或单一色调覆盖，不允许整体压暗，不允许灰蒙蒙
```

### SUBJECT（可变，每场景一句，含光位/材质锚点/禁止项）
见第 4 节。

### NEG（固定）
```
不要手绘，不要厚涂，不要插画，不要水彩，不要油画笔触，不要赛璐璐平涂，
不要像素风，不要低模，不要卡通描边，不要俯视，不要鸟瞰，不要航拍，不要鱼眼，
不要整幅金黄，不要单一色调，不要整体压暗，不要过曝，不要模糊，
画面中不要出现任何人物、动物与生物，
不要文字、招牌字、对联、印章、水印、边框，不要拼贴多格，不要未完成草图
```

## 3. 一致性锚（写进每一张的 SUBJECT 尾部，保证是同一个宗门）

```
材质锚：青灰筒瓦带苔痕，深赭老木带铁钉与包浆，青灰砂岩带凿痕，素纸灯笼不写字，铜器带氧化斑
```

这四样在十张图里都以同样描述出现，是「看起来同一个世界」的抓手，比调色更可靠。

## 4. 十个场景的 SUBJECT

1. **山门石阶·清晨**（%day-feature）
   晨光从左上斜射，青石牌坊与九级台阶正中一点透视，台阶两侧石灯，远处云海与黛色山脊，
   地面有薄雾贴地、石板缝里苔痕清晰。
2. **坊市长街·正午**
   正午顶光偏左，两侧木构店铺挑檐与素纸灯笼，街边竹筐木桶与布棚（无字），
   青石板路面有水洼反光，街口一株老槐，远处山影与薄雾，朱红柱与青灰瓦形成冷暖对比。
3. **宗门正殿广场·黄昏**
   低角度暖光从侧后打亮瓦垄与檐口，正殿重檐、朱红立柱、空白石匾，九级踏跺通向殿门，
   两侧青瓦院墙与石灯，地面斑驳树影与落叶，暗部保留石材纹理。
4. **竹林小径·午后**
   竹叶缝隙漏下斜射阳光形成体积光柱，土石小径向纵深收拢，两侧翠竹与蕨草，
   地面光斑与浅雾，竹青与月白为主，点缀暖金。
5. **客栈大堂·白天**（室内）
   纸窗透进天光在青砖地上打出窗棂光斑，长条木柜台与酒坛架，方桌条凳，
   木梁悬挂素纸灯笼（不写字），室内不暗，暗部保留木纹。
6. **丹房·室内**
   窗棂光柱与浮尘，青铜丹炉腾起青白烟气与炉口幽青火光，木架陶罐与药材筐，
   铜绿、窑火红、青灰三色对冲，室内整体偏亮但不刺眼。
7. **崖顶观星台·夜**
   靛蓝夜空与银河，石台与铜制浑天仪反月光，崖下云海翻涌，
   以月白与青蓝为主，暖金只留一盏孤灯，暗部可见岩石肌理（不是纯黑）。
8. **渡口木栈桥·晨雾**
   贴水雾气，木栈桥与系船桩伸向水面，青绿水面倒影与竹筏，远岸黛山与薄雾，
   水青、木褐、月白为主，冷调但明亮。
9. **药圃梯田·上午**
   层叠石砌梯田与灵草（发微光但不夸张），赭石土色与苔绿植被，远处宗门檐角，
   阳光斜射在田垄上，绿色层次分明不糊成一片。
10. **地下洞窟灵脉·夜**
    岩壁凿痕与钟乳，灵脉流水发青碧荧光照亮近处，洞顶裂缝漏下一束天光，
    青碧、岩褐、月白三色，暗部有反射光不死黑。

## 5. 生成参数

- 尺寸：优先 `1152x648`（16:9）；若 SiliconFlow 拒收，退 `1024x1024` 再按**构图线**裁 16:9（不裁掉地平线与脚下空地）。
- 模型：`Kwai-Kolors/Kolors`（现有链路）；每张只发一次请求，不重试。
- 去水印：右下角 AI 水印仍用邻域补丁抹除，但**只抹水印区**，不动整幅。

## 6. 验收流程

1. 先跑 4 张基线：山门、坊市、正殿、竹林。
2. 脚本量第 0 节六项判据。
3. 全过 → 扩到 10 张；单项不过 → 只改那一条 SUBJECT 重跑。
4. 全过之后才进 Godot 组装，组装时**不做全局调色**，只允许按场景微调。
