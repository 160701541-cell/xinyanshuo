# CAC-0006 — 首份真实图集的来源级审计（2026-10-16）

## 证据来源与范围
- 从用户历史素材库检索出《苍岚》古风村落素材库源图，原始分辨率 **1536×1024**，实际分析来源SHA256：`4e98eae746f1bb0e217e364292a47ba012ebc40c81f0b0a18d19c8513a027f5d`。
- 本次实际运行了 `tools/asset_factory/atlas_reality_audit.py` 对应的本地程序，以现有 `atlas_layout.json` 同等20格配置逐格裁切，并使用 `--flatten-ambiguous-alpha` **明确只为诊断保留RGB色彩**、再进行保守纯色背景连通域清底。
- 来源图的RGBA透明通道极值为 **2—252**，整张图完全没有alpha=0或alpha=255像素，不能据此声称透明背景，也不能把RGB转化理解成抠图成功。必须保留来源图和SHA。
- 每格得到的候选裁切原生尺寸约 **278—279×145**，低于原生512px高清物件母版目标。512px图标若由该裁切插值产生仍非高清母版。

## 实际执行结果
- 真实图集 **20格裁切成功**（仅原始组合图候选）。
- 在自愿显式RGB诊断转换后，保守清底只产生 **5项候选**（灯笼、酒坛、推车、货摊、竹林），**15项被机器阻断**，原因是四角背景不一致或边缘疑似裁断/背景不一致。
- 对真实源图与20个实际裁切画面进行视觉复核发现：同一格混入标题字样及多个状态物件，不能直接算作一件独立可用高清素材；这5项自动候选仍不合格。
- **视觉通过0/20，入游戏批准0/20，Android更新0。** 本次实际检测反证了“展示拼版有20类物件就有20张合格PNG”的说法。
- 可复核本地审计结果SHA256（`real_atlas_audit.json`）：`94808454449490f65e428edda29ddd44afd23c57fe63bd792a6096384e8b724d`。用户对话内交付审计ZIP，未将未授权、低质或未获批准图片批量上传正式仓库。
- 源图为用户既有历史素材，**非本轮新AI生图**；本次5张结果仅为独立化诊断候选，不能充当新合格素材库存。

## 可复现审计命令
```sh
python tools/asset_factory/atlas_reality_audit.py \
 --image ORIGINAL_ATLAS.png \
 --layout tools/asset_factory/atlas_layout.json \
 --out ./verified_real_atlas --flatten-ambiguous-alpha
```
若拒绝部分候选则退出码非0，这是**预期的严审行为**，不是可以忽略的失败。不可在自动部署中把该命令的退出码强行忽略。

## 对工业化流程的技术修正
1. 演示图鉴与真正可投产的独立图标/精灵必须分库存管理，图鉴只作为风格参考。
2. 源图优先生成单物件、单状态、统一机位、完整无字构图；避免先制作文本、图鉴边框、组合状态再强行裁切。
3. 资产需保留**原生高清母版**；简单插值放大不能改变低清事实。
4. 复杂植被、头发及边缘光晕需要高级透明分割加人工修边；背景颜色不一致时保持BLOCKED。
5. 资源审核通过再接入Godot，并用实际引擎帧图、碰撞、排序和Android性能验证。
