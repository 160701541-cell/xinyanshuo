# 苍岚·人生世界：材料是工具，NPC才是世界建造者（研发主线）
**生效：2026-10-17。用户否决了WorldX四面建筑成品图及HD2D大场景图。**

## 1. 用户只让我们做“材料”
WorldX只进入**独立原材料外观工厂**，按材质ID导出可无缝平铺的纹理、后续法线/粗糙度的可审查候选（不假冒已有PBR贴图）。首批材料：木纹、青灰石、瓦片、灰泥，继续扩至土、砖、布、竹、金属、草、砂、泥、植物叶片等。记录来源、可复用的物理尺寸、颜色标准、风格参考、SHA256、授权和人工QA。材料能够被重复用于无数具体物体、季节及建筑阶段。

**不要再用 WorldX 一次生成整栋房子、院落、四角建筑贴纸、所谓“4个面=3D”。** WorldX 上游目前主要生成俯视地图和角色，材质工厂需要基于WorldX代码扩展材质生成器，不得虚称WorldX原生支持建模/PBR。

## 2. NPC怎么建造世界
真实游戏NPC而非美术工厂决定施工；每个人有实体ID、年龄、职业、个人精力/饥饿、居所、财产与库存，并在世界时间中活动。

因果闭环：
```
人口增长/住房紧缺/经济需求/安全问题
  → NPC判断要不要建设；获得图纸/掌握技术、找资金和工人
  → 选址（地形、道路、水源、所有权、邻居、法律、环境）
  → 砍树/开采/挖泥土（有限实体资源）
  → 樵夫/采石工/农民运输入库（玩家不在世界也运作）
  → 木匠加工木材→梁柱，石匠切石+调灰泥，陶工烧制青瓦
  → 建筑工从仓库领取具体批次→走到工地→交付，不能远程瞬移
  → 工地依序：地基→木构→墙体→屋顶，每一段耗材和人工时间
  → 真正3D结构组件+材质+碰撞；门窗交互；归属/仓储/劳动成本入账
  → 新民居增加住房供给、新工坊增加生产能力；NPC的下一步需求由此改变
```

生病、饥饿、没有工人、材料枯竭、运输受阻、财政不足都必须中断或推迟项目；一个NPC可以在路上改变主意，缺材料不允许造墙。需求依据家庭、邻里、职业、村镇税负动态决策，而不是每隔一小时随机刷建筑。

## 3. 已写入的第一版代码（只作为3D游戏核心源码，非原版手机热更新）
- `game-source/godot3d/scripts/worldbox_life_sim.gd`：真实仓库支持4种加工材料——`timber`（木构）、`cut_stone`（石材）、`mortar`（灰泥）、`roof_tile`（瓦）。
- `game-source/godot3d/scripts/npc_building_system.gd`：玩家无需按“生成房屋”。NPC根据村镇工坊缺口规划一座作坊；木匠、石匠、陶工需抵达生产区、消耗原材料并生产半成品。具体建筑工携带批次材料走到3D工地、交付后做工，逐阶段显示真实3D地基、梁柱、墙、瓦屋顶。没有运到料或NPC未抵达，不会变成房子。
- `game-source/godot3d/scripts/world_main.gd`：从80名真实独立NPC中分配建造职业；显示工程进展和对应施工ID。
- `game-source/godot3d/scripts/autonomous_village_director.gd`：删除旧“仓库运了一次货就立即生成一栋房”的错误功能。其原有砍树/搬运/采石/种田继续保留。
- `game-source/godot3d/tests/npc_material_construction_smoke.gd`：原始材料、三种加工、承运工实际领取与运抵、地基/木架/墙/瓦四阶段、成本扣除、建筑生产力增长、项目快照测试。
- 测试中的“模拟抵达”是将实体坐标移到目的地，**不代表已经通过真实NavMesh避障实机QA**；3D引擎角色目前只会直线导航，这是接下来必须修复的真实限制。

## 4. 下一批不可省略事项
- 加入图纸/知识解锁（真实材料树不靠硬编码种类堆砌），经济账本/工人工资/合约/土地权限/建筑选址。
- 建筑工地阶段碰撞与铺设动画，工人挖坑、扎架、铺瓦动作；工程延误、倒塌、损坏和修缮。
- NPC家庭、婚育、死亡、职业变迁；在无玩家情况下依据食住生产周期不断发展。能查“是谁什么时候建了这座房、用了什么材料、所有者是谁”。
- 流式世界永久保存玩家已建结构和所有施工数据，加载后保持同一ID，不能每次打开变回预设村子。
- 导航须支持寻路/障碍回避/楼梯/门/桥；手机性能、异步调度、离线快进需有数量上限和QA。
- 当前安装的APK176仍为另一套项目入口：`game-source/godot3d/`技术演进必须经过**原APK场景兼容**才能做下一次公开仓库签名PCK OTA。原版已发布rev178不等于这些新3D代码已热更新到手机。禁止再发布独立APK作为替代。
