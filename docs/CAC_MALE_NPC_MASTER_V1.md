# CAC-MALE-001 | 《苍岚·人生世界》男平民参数化母版 V1

**2026-10-16，男平民母版已经以真实GLB的方式制作，并被接入公开Godot3D工程的模型工厂与NPC角色节点。** 所有模型都只是技术/画风候选，不是假称原版签名APK已更新。使用玩家上传的低多边形古风四人图作设计语言参考，不直接提取或复制图片顶点。

## 本轮真正交付

- **1套共享男平民身体结构**：`tools/male_civilian_master.py` 通过相同身体测量、部件挂点、比例和渲染规则生成角色，而不是五个独立任意人物。
- **5个GLB**：`assets/generated/npc/male_villager_v1.glb`（中性母版，灰青），`male_merchant_v1.glb`（商人，灰蓝），`male_apprentice_v1.glb`（学徒，灰粉），`male_guard_v1.glb`（卫卒，深青），`male_scholar_v1.glb`（书生，灰绿）。
- **真实替换游戏模型**：`npc_agent.gd` 中商贾/学徒/卫卒/书生（索引1/4/6/8）优先实例化对应男母版GLB，资源缺失保留旧职业GLB。农人、医者等未决定性别的居民暂不强制变成男人。NPC身份码和库存归原有 `WorldState`，变化只影响可见服饰/模型。
- **整体工业工厂输出数量**：18建筑 + 10道具 + 10旧角色候选 + 5新男母版 = **43份真正GLB**。运行时不手工复制生成。由 `test_generated_glb.py` 校验准确件数、GLB容器长度/sha256/实体几何/性别母版长度和角色差异，`world_smoke.gd` 验证专业NPC真正加载新母版。

## 视觉方向与用户图形DNA

保留：**短帽/头巾、古代交领、腰带、朴素长衣或围裙、灰蓝/灰青/灰粉/米白、轻低多边形风格**。去除：圆柱桶袖、眼鼻嘴没有信息、贴纸状椭圆围裙、腰脚完全连成一块、五套互不兼容随机身体。

### 尺寸与比例（单位米，Y-up、正面+Z）

- 脚底约Y=0，帽顶约Y=2.45；脸部中心Y=2.107，头宽约0.47。衣摆Y=0.71、腰带Y=1.105、肩部Y≈1.66，袖口Y≈1.02。
- 普通成年男性体型统一：头与颈分别为形体；躯干4截面内收、长衣2~3个截面，袖子由肩到手有两段**真实半径变化的锥体**；鞋底独立于裤腿。
- 交领是前胸三角布面的两层**独立压叠表面**，不是纹理贴纸；腰部围裙有顶部挂点、前垂折线与下缘包边，不是盾牌状椭圆。
- 眼、眉、鼻、嘴、耳是独立低成本形体，保证远景不成为空白脸，不追求当前版本的写实表情。
- 五套保留同一套 `LANDMARKS`（根、髋、脊、胸、颈、头、双肩、肘、腕、膝、踝），供后续真正的Humanoid/Skeleton3D蒙皮转化。**现为挂点，尚无真正骨骼权重，也没有ARKit blendshape和动画重定向**。

## 母版的非随机硬规则

不能改变：骨架挂点、领口左右交叠、布衣分层、男女不同的身型专用母版、手脚与袖口几何关系、实体公共身份码。允许变更：服装主/辅色、帽子轮廓、外层围裙、挂包、护腕、腰带颜色和职业配件。

五种色彩方案都来自低饱和灰蓝灰绿灰粉的审美方向；并不直接取用未经授权的商用材质贴图或任何外网美术图片。Android资源可视候选仍需玩家或美术人工审定。

## 性能与质量事实

- 标准人体候选大约1.7k~1.9k三角面，分层件在导出时合并为单个有vertex colors的glTF mesh，以减少Android draw call；**合并静态部件不等于已做好动画骨架**。
- 由同一母版脚本固定各职业造型，没有调用付费API和云模型生成。GLB本身的多边形硬边以及静态站姿在某些视角仍有手办感，需实际屏幕上测试。
- 候选质量门槛：0非法坐标、独立GLB SHA256、五职业不同哈希、总高约2.45m、真实 Godot 4.4 glTF加载、实例化NPC上可见；美术正式验收和手机性能目前PENDING，**不以源码单元测试代替玩家画风审批**。
