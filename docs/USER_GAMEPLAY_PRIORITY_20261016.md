# 用户方向修订：玩法和内容优先

2026-10-16（北京时间）。本文件记录本轮用户直接指示；涉及美术目标时优先于此前要求高清独栋建筑的记录。

用户原话：
> 不用独立建筑，外面建筑里面场景，现在可以大批量做了，但是物品必须单独做。
> 或者你做成world世界盒子那种也可以啊，主要是游戏玩法和内容。

## 执行约束

- WorldBox式简洁俯视、像素表达是允许的美术选择，不是要求复制其素材，也不代表立刻重写全部游戏。
- 玩法、可交互内容和可持续世界状态优先；高清院落精修及继续拆分单栋建筑不再作为玩法开发的前置门槛。
- 外部建筑可整合进完整外景，内部采用可进入和退出的室内场景。可移动、拾取、交易和交互的物品保持独立资源与独立状态，不能只画在背景中。
- 同一可玩区域须统一比例、视角与视觉语言；保留既有候选图，不直接混用像素与高清素材。

## 下一阶段验收重点

1. 将已有村民和资源状态与实际场景交互对应起来，玩家能观察到工作、资源变化和建造结果。
2. 完成一个可重复的采集—加工—交易—建设循环；动作真实增减物品，失败不扣资源。
3. 验证外景进入室内再返回，独立物品状态与存档保持一致。
4. 后续扩充职业、NPC事件和地区内容，每项有实际游戏状态变化；图像批量生成按这些需求安排。

以上为更新后的优先级和验收目标，不是新增功能已实现声明。保留原正式APK兼容、签名发布和真实手机验收要求，不修改线上更新清单。
