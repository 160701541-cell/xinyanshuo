# 苍岚·WorldX 第一批：高清国风四合院（独立素材）

## 地图生成模板替换（不是直接使用上游默认模板）

将 WorldX `generators/map/prompts/step1-map-generation.md` 的原有硬约束“接近90度俯视”替换为以下约束。保留其地图、区域、元素定位、可行走区与网格计算流水线，但**先做一张建筑试样，不批量运行**。

### 提交给 WorldX 的生成提示词

制作一套用于商业品质中国古风开放世界游戏《苍岚·人生世界》的**独立建筑美术素材**：中国传统北方四合院，正房一座、左右厢房各一座、院墙、院门、青灰色瓦顶、白灰泥墙、深棕色木梁与木门、石砌台基。建筑必须有真实结构和统一比例，屋顶坡度、屋脊、斗拱、屋檐、门槛、柱础合理。画面为**斜俯视约35–45度**，能够同时看到瓦顶、建筑正立面与院内地面，整体为高清2D手绘国漫概念插画，清晰精密线稿，细腻瓦片和木纹，低饱和自然色彩，柔和日光从左上方照射。清晰、可裁剪的轮廓，四周足够留白，单一建筑组合居中，无人物，无文字，无标识，无UI，无水印。透明背景优先；若图像模型不支持真实alpha，请输出纯色背景供后续抠图，不得把伪透明棋盘格当作alpha。宽高比1:1，输出最大可用原始分辨率，不得将小图简单插值放大冒充高清。

**严格负面约束**：pixel art, 8-bit, 16-bit, chibi, Q-version, voxel, Minecraft, western fantasy, 90-degree top-down map, flat floorplan, isometric grid tiles, cartoon plastic, blurry texture, fused geometry, inconsistent perspective, detached roof, floating foundation, text, watermark.

### 后处理要求（第一批）

1. 保存模型原图、生成参数、提示词、许可证和来源。
2. 对图片进行人工/视觉QA：透视一致、房屋结构正确、瓦顶可分层、无虚假透明、无人物与文字。
3. QA通过后再分离 `courtyard_base.png`、`courtyard_roof.png`，并建立对应碰撞轮廓；如果模型只能生成单张融合图，必须标记为“概念图”，不得假装可分层。
4. 不得覆盖旧APK资源；先进入独立候选目录，待原版Godot验证后再集成。
5. 未配置图像模型API密钥、未实际运行生成器或未产出PNG时，明确标记“尚未生成”。
