# 《苍岚》WorldX 专用视觉规范 / Canglan WorldX Style Lock v1

**用途**：供 WorldX 原生地图生成器的 `userPrompt`、`additionalConstraints` 和角色生成器的 `worldVisualContext` 使用。此文档不代表已经生成或验收任何新图片。

## 唯一目标画风

中国古风高精度手绘游戏美术，国漫概念插画的精细度；青灰瓦顶、木构、白墙、土墙、石板路、自然植被。偏斜俯视（约35–45°），可看到建筑正面和屋顶，画面结构与角色投影一致。细致的手绘线稿、清晰材质、自然光照、低饱和柔和配色、合理真实的尺度。游戏世界可交互、可拆分、可遮挡，而非一次性烘焙背景。

**严格排除**：像素风、8-bit、16-bit、低分辨率贴图、Q版大头小身、夸张卡通、纯90°俯视平面图、欧美奇幻建筑、现代物件、塑料材质、明显AI拼贴、错误透视、随机文字、游戏UI。

## 本轮唯一生产对象：苍岚村落标准四合院

独立透明背景 PNG（RGBA，真正透明，不是棋盘格或纯色背景），四合院整体建筑及可拆卸的独立构件：正房、左右厢房、院墙、院门、瓦顶、地基。屋檐与墙体分层，统一光源自画面左上。人物标准身高按门高约75%校准。无人物、无树木遮挡、无水印、无文字。

输出必须包含：
- `courtyard_base.png`：建筑完整体，透明背景
- `courtyard_roof.png`：屋顶遮挡层，透明背景
- `courtyard_collision.json`：入口、可行走范围和碰撞轮廓，坐标与PNG对应
- `manifest.json`：源图、生成模型、提示词版本、分辨率、许可、审查状态

## WorldX 兼容性说明

WorldX 上游 `generators/map/prompts/step1-map-generation.md` **硬编码90°俯视**，`generators/character/prompts/generate-sprite.md` **硬编码Q版像素风**。不能只在末尾追加“国风高清”就认为能消除冲突。必须针对《苍岚》创建专用 prompt 模板并在运行时替换对应模板；保留 WorldX 的区域、碰撞、地图数据处理逻辑。

**质量门禁**：风格审查不通过，不进入正式资源目录；不使用 WorldX 示例像素素材替代新生成素材；原版APK兼容性验证之前不宣称已发布到手机。


## v1.1 已由用户确认的视觉基准（2026-10-16）

**参考图**：WorldX + 硅基流动 Kolors 生成的首批四合院候选图（用户已查看）。用户明确认可该图的整体国风美术气质与景观光影，要求后续**不再换画风**，避免建筑、植被、人物互相割裂。

- **风格冻结**：保持这张四合院图的青灰瓦、深棕木构、温暖自然光、柔和绿树、细腻国风插画质感、斜俯视角和低饱和配色。此为后续素材统一目标，不允许随机切换为像素、扁平卡通、写实3D或另一套笔触。
- **树木与植被**：用户认可当前树木表现；后续可通过枝叶摆动、光影变化、四季颜色、轻微风场动画增强生命感。树木必须是独立游戏对象，不可仅烘焙在建筑原图内。
- **建筑精度**：用户指出本张建筑“有点模糊”；保留现有美术质感，但后续独立建筑需要更清晰的瓦片边缘、木梁结构、檐口、门窗细节。不要为了锐化而改变画风，也不要把插值放大当作高清。
- **结构要求**：墙体、屋顶、院门等必须可分层和交互；建筑不能只用一张合成背景图冒充正式可用素材。建筑清晰度 QA 与画风一致性 QA 分开验收。
- **统一一致性基线**：所有后续生成均要引用同一张经确认的风格参考图，并维持同一透视、光照方向、材质比例与人物尺度。**目前仓库内没有确认为原始图片的稳定风格参考资源路径；在找到并登记对应原图及SHA之前，不得宣称已建立机器可执行的参考图锁定。**
- **批次规则**：每次只处理一个素材或一种缺陷；先出候选、再审核、再入库，不多项目并发。

**状态**：用户已认可整体风格，但当前四合院图片仅为候选概念图，未通过建筑清晰度、可分层和游戏实机验收。
