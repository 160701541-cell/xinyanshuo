# WorldBox 0.51.4 非官方第三方MOD衍生实验 · v0.12

**项目性质：仅用于其他游戏 WorldBox 的非官方 MOD 衍生测试。它不是《苍岚·人生世界》原创游戏的开发、资源制作、版本热更新、签名或发行；严禁合并到公开仓库 main，或修改原游戏的源码、安卓包、官网及日志。**

## 本轮实质开发

1. 新增 `ObserverFrameGuardV12.cs`，直接编译进原创 WorldBox 观察器C#程序集。它仅保护我们自建的微观观察层：
   - 持续低于24 FPS约4秒，自动停止附加伪3D绘制/地图采样，WorldBox世界模拟**不会暂停或被修改**。
   - 持续恢复到38 FPS以上约6秒，自动恢复观察层，避免持续闪烁。
   - 帧率低时降低地图采样频率（0.8s→1.5s→3s）并减小绘图半径，帮助缓解高密度NPC、大地图绘图开销。
   - 针对额外地图候选：10x10与12x12可申请注册；16x16仅帧率足够时允许作为测试选项；20x20在没有真实设备RAM/热性能验证前仍不开放。**这些都是新世界尺寸选项注册候选，尚未在手机上证明可生成新地图。**
2. 修复v0.11可见性缺陷：按下“实验大地图”后，状态曾写到 `summary`，但被0.8秒采样循环覆盖。v0.12改用持久`mapStatus`，不会随普通地图采样消失。
3. 观察UI显示实际WorldBox地图大小与近似观察层FPS；在自动暂停时清晰显示暂停原因，减少安卓手机卡死风险。
4. 增加可运行的C#性能守护模拟测试，在GitHub Actions内直接模拟10FPS低帧率和100FPS高帧率，验证停止、自动恢复和地图开放阈值；真实安卓SDK编译将此守护器与观察器、实验地图库合并成同一个原创DLL。仍不替代实机负载测试。
5. 新版源代码及两条候选安装格式仍保留：传统Mono的 `Mods/` C#源码包，与新版Android IL2CPP NML的 `NMLMods/` 预编译DLL包，不可混用。

## 真正可用的限制

**用户最终要的是一个APK，点击即可进入完整《万界仙侠》。本轮仍无法提供这样的APK。** 当前会话无用户手机上的可用Android NML启动日志，无法确认上传的0.51.4“支持模组”APK实际是传统Mono加载路线还是新版IL2CPP/Android NML；没有可核实的APK重签名、完整游戏验收以及获得许可的二进制发布能力。不能把MOD测试ZIP冒充APK或谎称内容已经进入游戏。不能覆盖已经保存的世界。也不能通过普通无权限Android安装器在Android16自动访问其他APP受保护的 `Android/data` 目录。

**真实条件：** 只有确定安卓运行时已经加载正确的NML版本，才可以安全验证自研MOD在现有游戏中显示按钮；已写好的宏观世界/修仙数据、AI、王朝、天气、高清资源不能直接视作已完成的游戏系统。

### 与高通骁龙8至尊版的对应目标

- 世界基准Titanic 8x8地图块 = 512x512地形格；先测试12x12 = 768x768（2.25倍）。
- 16x16 = 1024x1024（4倍）是优先性能目标，仍需要设备中NPC、寻路、发热和剩余内存测试。
- 20x20 = 1280x1280（6.25倍）暂时只做容量规划，**不自动放开**。
- 用户只需保留此候选包，不再要求用户自己手动用MT管理器复制程序。

**不可声称的测试结果：** 自动化离线测试通过并非Android NML、WorldBox游戏内加载、大地图生成、触屏兼容、FPS和存档验收通过。
