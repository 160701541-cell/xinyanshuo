# WorldBox·万界仙侠 v0.20 — 中文化及第三方模组管理基础

**范围：第三方WorldBox 0.51.4非官方MOD实验，绝非《苍岚·人生世界》正式游戏。禁止合并main、触碰苍岚APK/PCK/官网或发布密钥。**

## 本次真实实现
- `localization/zh_cn_v20.json`：原版国家、外交、人口、种族、设置及MOD管理器等高频词条的简体中文映射；将原版Elf/Dwarf/Orc的显示文化称谓规划为灵族/山民/蛮族，尚未修改原版游戏实体。
- `mod-manager/batch_import_v20.py`：可执行的**离线批量ZIP导入暂存引擎**，支持中文状态报告、自动解压到隔离目录、清单ID/版本/依赖/互斥初步分析，阻止路径穿越、符号链接、加密ZIP、重复文件、压缩炸弹及已存在目录覆盖。静态匹配不等于运行时兼容。
- `test_v20_mod_manager.py`：七项安全、中文词典、冲突、依赖、版本及重复导入回归。
- 专属v20 GitHub Actions，继承v18修炼C#与安卓公开SDK编译测试。

## 尚未实现（必须明确）
- **没有完成原版全中文汉化**：WorldBox程序生成的王国名、人物名、城市名、其他第三方MOD文本，以及所有原版UI页面尚未接入翻译运行时；需要基于真实Android0.51.4字符串接口验证。
- **没有实现游戏内文件选择器/批量导入UI**：本轮的Python脚本是Work后续安卓端MOD管理器可复用的安全规则参考/私有预处理工具，不会自行出现在安卓游戏中。下一阶段需用Android Storage Access Framework（多选文件授权）、NML模组目录、安装启停/回滚、运行时兼容性日志和中文UI实际实现。
- 依赖/互斥分析仅能识别声明元数据，不可能静态证明所有其他MOD之间不会冲突；未知一律标未知。
- Work负责用户持有WorldBox APK的私有整合、签名、安卓16真机验收及最终交付。不得把编译通过写成用户已经安装。
