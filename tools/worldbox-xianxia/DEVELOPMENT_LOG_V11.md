# WorldBox第三方MOD衍生实验 v0.11 — 2026-10-20

**与《苍岚·人生世界》原创游戏开发完全无关，仅在公共仓库专用 worldbox/external-mod-lab-v11 分支进行其他游戏的MOD实验；正式游戏main/OTA未修改。**

## 用户明确目标
- 用户不懂技术，不愿再用MT管理器手动复制；需要真正下载安装即可玩的WorldBox整合APK。
- 手机芯片骁龙8至尊版；希望地图尽量巨大，并加入修仙、世俗王朝、妖兽、天气、雷劫、秘境、四界、高清放大、伪3D人物观察等此前定义的内容。

## 实际完成
1. 通过真实公开Android WorldBox程序集的PE metadata，读取到 MapSizeLibrary、MapSizeAsset、MapBox.setMapSize 等API名称；生成检查报告 `WORLDBOX_PUBLIC_MAP_TYPES.json`。
2. 新增 `GiantMapOptionsV11.cs`，以**实验性、用户双击确认**方式尝试把10/12/16/20区块尺寸注册到“新建世界尺寸库”，并保留失败回退信息。新增尺寸不自动生成地图，也不修改任何当前世界和存档。游戏UI能否显示及实际生成需实机验收。
3. 把上述功能与旧人物观察/四方向2.5D图块/FPS和地图当前尺寸显示合并到**同一个原创NML程序集**；在GitHub Actions官方Android参考DLL编译成功。
4. 同时输出用户上传APK说明匹配的传统Mono源码候选及官方较新LemonLoader/NML2.1的预编译候选；两者不能混用。
5. 添加 `world_size_planner.py` + `test_v11_maps.py`。以64格/区块计算：8x8=512²、12x12=768²、16x16=1024²、20x20=1280²、30x30=1920²。由于NPC模拟、CPU/内存和发热，20x20默认关闭；只有实机长期FPS及空闲内存证明安全才实验开启。
6. Github Actions真实运行 `39385514994`：两项工作均 success，其中36项Python单元测试通过；C#源码桩编译及公开安卓NML/WorldBox SDK真实引用编译成功；第三方文件公共仓库上传检查通过。用户手机加载仍DEVICE_PENDING。
7. 本地建立单个私有资源包 `WorldBox_万界仙侠_一体化MOD实验整合资源_v0.11_非APK.zip`（约25MB），汇总两条MOD候选、地图大小方案、v0.3本地AI+四界原型、v0.4图片及v0.5先前提供的两款战斗/政治模块。这是**非游戏安装包**，内容未一起在安卓内启用。
8. 不能把商业APK嵌入MOD压缩包、混用两条启动链或伪造“安装即玩”；该设备尚未接入本会话的Android实机调试/签名链，暂不能交付真正可玩的合体APK。用户无需再手动折腾MT。
