# WorldBox · 万界仙侠 非官方第三方 MOD 实验 v0.18 — 2026-10-20

**项目性质：其他游戏《WorldBox》的非官方MOD衍生测试。绝不属于《苍岚·人生世界》原创游戏研发，禁止触及其 main、正式源码、官网、签名、APK/PCK、热更新和开发日志。**

## 本次真正开发的游戏功能

1. 新增 `gameplay/CultivationV18.cs`，实现第一个可以点击操作的修仙原型：绑定选中WorldBox人物，点击「吐纳修炼」获得灵气；有2秒操作间隔；灵气达到门槛时境界自动突破；每位人物拥有独立记录（最多256个，死亡后清理）。境界表：凡人、炼气一～十三层、筑基、结丹、元婴、化神、炼虚、合体三个阶段、大乘、渡劫。
2. `XianxiaObserverV07.cs` UI实际增加「吐纳修炼」按钮、选中人物境界/当前灵气/所需灵气信息，吐纳时在游戏内更新。每15秒清理死亡或无效人物的运行时记录，避免每帧字典扫描。
3. 修仙模块已加入真正的安卓公开NML SDK编译项目和传统Mono源码候选包，不只是独立玩法设计书。
4. 新增 `tests/CultivationScenarioV18.cs`、`tests/CultivationScenarioV18.csproj` 可执行C#场景测试，以及 `test_v18_cultivation.py` 静态契约测试，检查两秒冷却、灵气获取、境界突破、多人物独立数据和WorldBox原本存档不被修改。
5. 更新v18独立Actions与Work APK交接文件。Work负责最终用户持有WorldBox安卓游戏的私有APK整合、签名及真实设备运行。

## 严格未完成项 / QA事实边界

- 当前修炼记录**只存在于内存**，进程退出会重置，未接入原版WorldBox存档；原版战斗属性与武器、门派、功法、妖兽、完整境界影响等均未实现。
- APK中的真实WorldBox 0.51.4 MOD加载器兼容仍需Work和手机验收。SDK通过不等于游戏加载成功。
- 2048×2048地图仍只是实验注册候选，未真实生成、保存、加载并证明稳定。
- 用户要求的一个下载即玩的整合APK由Work私有打包，公开GitHub只托管我们的原创源码与QA；不向公开仓库提交用户的商业游戏APK、私人日志、密钥、第三方Mod。
