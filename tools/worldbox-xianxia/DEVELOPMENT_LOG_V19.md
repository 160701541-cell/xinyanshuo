# WorldBox · 万界仙侠 外部非官方MOD实验 v0.19 — 2026-10-20

**项目隔离：本分支只针对其他游戏《WorldBox》的第三方非官方MOD衍生测试，不属于《苍岚·人生世界》原创游戏开发、发布或热更新；禁止修改或合并其main、正式源码、官网、APK/PCK、签名与日志。**

## 用户本轮确认的游戏世界规则

- **保留原版凡俗王朝与人类身份，不将人类整体修仙化。** 王朝经济、战争、文明继续按WorldBox原系统运行。
- 精灵、矮人、兽人等原版其他族裔，先通过世界观名称映射形成“青木灵裔”“地脉工族”“荒原战裔”；后续需视觉素材和WorldBox版本兼容接口，不能单靠重命名声称已换皮。
- 动物绝大多数保持凡兽；少部分概率觉醒，修炼成为妖兽，可依亲和和驯服规则成为灵兽。
- **筑基期可以起飞**。肉身飞行消耗个人灵气；御剑飞行更快，仍消耗个人灵气；飞舟依靠灵石而非个人灵力。未来仍需接入WorldBox空间移动和表现动画。
- **仙宗优先山脉与山顶建宗门**，宗门大阵以灵石启动、防御和恢复，战斗冲击会使阵法破损；修仙家族优先凡俗城池外围，为其提供护卫。宗门与家族不是凡俗王朝的同义词。

## 本轮真实代码

- `gameplay/XianxiaWorldRulesV19.cs` 新增独立可执行的规则模块：凡俗王朝/宗门/修仙家族类别、原版族裔语义映射，凡兽稀有觉醒→妖兽→灵兽驯服，筑基飞行判定和肉身/御剑/灵舟消耗、山地选址、大阵灵石消耗和阵法完整度、临城修仙家族防御。
- 本文件随 v19 安卓NML候选编译，并包含在传统Mono候选源包。**仍为纯C#规则原型，还没有接入WorldBox原版地图刷怪、移动坐标、原生存档和战斗/建筑API。**
- `tests/WorldRulesScenarioV19.csproj` 和 `WorldRulesScenarioV19.cs` 提供C#执行回归，验证灵气消耗、御剑加速、飞舟灵石、妖兽几率和转化、山门大阵消耗及仙族庇护王朝。
- 工作流与 `WORK_HANDOFF_APK_V13.md` 更新至v19，Work负责独立处理用户持有安装包的私有整合、签名、实机QA及最终单APK交付。

## 待落实和不应冒认

1. 不能声称规则文件已经使游戏里动物自行修炼、玩家真正飞行或宗门实际建在山顶；这些需要WorldBox目标版本API适配、触屏操作和实机验证。
2. 需要游戏世界生物识别、地图地形检测、持久状态、飞行控制和寻路、宗门建筑与阵法实际效果、灵石经济，以及素材授权审计。
3. 2048×2048地图仍是候选注册和观察API诊断，不是已经成功生成、稳定运行的安卓世界。
4. 中文字体缩放和v18主动吐纳仍随原候选程序集，是否在用户WorldBox 0.51.4实机加载尚待Work验收。
