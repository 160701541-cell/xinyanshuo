## 生成规则
1. 袍身：按上表 9 条横截面放样，椭圆截面（rx/rz 分离），段数 96。
2. 袖：按袖子 5 段放样，A-pose 下垂 42°，端面朝下。
3. 交领：顶点色按 `ctr = 0.05 + 0.72*(y-1.16)` 刷两条金边。
4. 肩缝：袍身顶环保留到 rx 0.21，袖根 x 0.10 塞进袍内，重叠 0.02。
5. 验收：一次出 0/45/90/180 四张，四张都过才算完成。
