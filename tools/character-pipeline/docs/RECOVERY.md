# rig/cloth.gd 事故与重建（2026-10-20）

## 事故
一次 `python` 批量替换里，待替换串取成了空串（切片起止位置反了），
`str.replace("", new)` 把新函数插到每个字符之间 → 文件从 302 行涨到 **235,853 行 / 6.1 MB**。
`/tmp` 的临时副本已被清理，没有可用备份。

## 恢复
按同一设计从零重写 `rig/cloth.gd`（302 行）：
- 取最大网格（SuperHero_Male，7281 顶点 / 12566 面）
- 按"三顶点最大权重骨"分 6 组（头/臂/腿/手/足/躯干）
- 腰线 32 向半径 → 软体裙（SoftBody3D，顶圈钉住，双腿胶囊碰撞）
- 顶点色：袍身、蔽膝、袖口金线
- 头顶 AABB（限制 |x|<0.13、|z|<0.16）→ 眼/眉/嘴三处贴片（face_decal.gdshader）
- 平滑法线：按顶点累加面法线（之前是平面法线，看起来像低多边形）

## 现在的状态
- ✅ 拆分、软体裙、贴片五官、四方位、head 特写模式
- ⚠️ 头发（原用 face.gdshader 按区域刷色）暂时关闭：会连脸一起刷黑，需要改成独立"发帽"网格
- ⚠️ 眼睛贴片位置偏高（压在眉上），需下移约 0.04 个 head_r

## 流程改进（避免再犯）
1. 改文件前先 `cp` 到 `/tmp/xxx.bak`
2. 每处 `replace` 用 `assert s.count(old) == 1` 校验
3. 先写 `/tmp/new.gd`，用 `godot --check-only` 过了再 `os.replace` 覆盖

## 第二轮：体型瘦身 + 侧开衩（两次回退，未达可用）
- Blender 体型脚本（blender 内临时 /tmp/bd.py）：躯干 x*0.86、胸背 y*0.90、腰 x*0.93、手臂 y/z*0.88。
  → 结果：手臂被压成"刀片"（手臂在 z≈1.35，按 z 缩放直接压扁），**已回退到 character_ea.glb**。
- 开衩：在 _skirt 三角生成时跳过靠近 ±x 的格子。
  → 结果：裙身出现大洞（露白），**已注释掉**。
- 结论：开衩不能靠"跳过格子"，必须先生成闭合面片再按衩口裁切；体型也不能按轴统一缩放，要按骨骼区域（肩/胸/腰/臂各自局部坐标系）做。

## 第三轮：查资料后的诊断（关键）
- 查 Godot 官方 SoftBody3D 文档与社区配方：边界顶点要 pin、网格要闭合、避免与碰撞体穿插。
- 对照实验（out/cloth_diag.png）：
  - `--static`（不跑物理）：裙身完整，无洞
  - 软体模拟：右侧被撕开
  → 洞是**物理造成的**，不是几何错误；碰撞体（大腿胶囊）与布料穿插是主因。
- 更根本的问题：现在的"袍"是 **人体壳沿法线外扩 1.4cm**，所以贴身像泳衣/潜水服。
  这就是"体型不适合这身衣服"的真实原因：衣服没有自己的体积。
- 正确做法（下一轮）：袍子用自己的轮廓（肩线外扩 8cm、腰线束进 2cm、下摆独立放样），
  不再从人体壳偏移生成；只有内衫才用薄壳。

## 第四轮：外袍改为独立体积（路线切换）
- 新增 `_loft_ell(rings)`：椭圆截面放样（rx/rz 分开），顶点色 + 两端封口留空。
- `_robe()` 轮廓：肩 1.44/rx0.245 → 胸 1.30/0.255 → 腰 1.16/0.225 → 束腰 0.185 → 下摆 0.40/rx0.425。
  外袍不再从人体壳偏移，因此有了自己的体积（不再是"泳衣"）。
- `_sleeve()`：沿 ±x 放样 5 段，半径 0.10→0.142 的喇叭袖。
- 现在两个已知 bug：
  1. 袖子半透明/重影：三角形绕序与双面渲染叠加，法线朝内。
  2. 袍身明暗是平的：法线只取径向，没有纵向斜率分量。
- 修法：袖子改用 st.generate_normals() + cull_back；袍身法线按相邻环 dy/dr 计算纵向分量。

## 第五轮：绕序/法线修完，袍身成立
- `_loft_ell` 法线加纵向分量 n=normalize(cos a, -dr/dy, sin a)
- 袍身与袖的三角绕序翻转 → CULL_BACK 生效，不再看穿
- 曝光修正：key 2.1→1.15，袍色 (0.085,0.255,0.250)、下摆 (0.045,0.150,0.155)
- 结果：袍身呈深青、上亮下暗的纵向渐变，轮廓是"袍"而不是"泳衣"
- 剩余：袖筒两端未封口 → 从袖口看进去像半透明（下一步加环封口）

## 第六轮：袖口封口 + 交领刷色
- `_sleeve_cap(side)`：袖末端口加 20 段扇形封口（深色内衬），消除"看穿内壁"的半透明感。
- 交领改为**袍身顶点色**（不再贴片，避免 z-fighting）：
  `d = acos(sin a)` 与 +z 的夹角；d<0.085 内衫色、0.085~0.115 金边。
- 现状：领口是一条竖直浅带（因为圆柱上等角带就是竖条），**要成"V"必须让中心角随高度变化**：
  `d_center = 0.05 + 0.55 * (y - 1.16)`，两侧各一条。
- 曝光/配色：key 1.15，袍 (0.085,0.255,0.250)，下摆 (0.045,0.150,0.155)，领内 (0.52,0.50,0.45)，领金 (0.40,0.30,0.11)。
- 袖子仍有轻微横向条带（端盖与筒身法线不连续），下一步统一用 generate_normals。

## 第七轮：交领 V + 垂绦（四方位暴露新问题）
- 交领：中心角 ctr = 0.04 + 0.70*(y-1.10)，金边带宽 0.06 rad；seg 44→96 才够细。
- 垂绦：两条朱色窄带从腰封垂下（z 0.262→0.300），正面可见。
- 四方位暴露：
  1. 侧视袖子是"大圆盘"——袖长 0.90m、末端半径 0.142，端面正对镜头，看起来像贴在头上。
     修法：袖长缩到 0.62，末端加"袖口下垂"（y 下降 0.06），端面朝下。
  2. 背面肩部有破面（内衫壳与袍身交叠处露出浅色）。
  3. 垂绦在侧视只有一条细线，因为它是平面片，需要给一点厚度或改成筒。
