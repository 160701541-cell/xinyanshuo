# 生物与人物生产流水线（v1）

## 工位划分
| 工位 | 负责 | 产物 |
|---|---|---|
| A 骨架 | item3d._being2 / _beast_quad / _beast_serpent / _beast_bird | 关节节点 + 体块 |
| B 表面 | icon_light.gdshader 的 pat_mode（1 虎纹 2 鳞 3 羽 4 衣褶） | 无 UV 的世界坐标图案 |
| C 光照 | 世界空间 key + 天光 + 地面反弹 | 明暗 |
| D 取景 | _fit_camera（AABB → 距离/fov） | 构图 |
| E 出图 | _run_roles / produce（4 方位 × 九格 × 品阶） | PNG |
| F 质检 | tools/artcheck.py + 拼图 | 指标 |

## 关卡（每关不过不进入下一关）
1. **语法门**：`godot --headless --check-only --script rig/item3d.gd`（本项目 warnings-as-errors，类型推断错误必现）
2. **单件门**：先渲 1 个物种 × 1 方位，看轮廓与光照
3. **全套门**：8 身份 × 4 方位，拼表看一致性
4. **指标门**：artcheck 六项

## 已知坑（开工前先规避，不靠试错）
- 类型推断：`var x := 未标注类型函数()` 直接报错 → 一律写 `var x: float = ...`
- 材质共享：`_mat2` 每次新建材质，改图案必须按"基色 meta"筛，不能改全局
- 图案无 UV：只能用世界坐标算，且频率要按物体尺度（蛟鳞 62/m 看不见 → 24/m）
- 金属无环境：compat 下金属会发黑 → 高光烘进顶点色或给 tint
- 相机绑定光源会"追着物体跑" → 法线必须转世界空间
- 拼图缩略：`paste` 必须带 alpha，否则黑底方块
- 渲染前先 `pgrep -af "[X]vfb"`，Xvfb 掉了会静默失败

## 进度（r7）
- 蛟鳞：15/19 per m，对比 0.85 → 从正面能看见环鳞。
- 人物：头半径 0.034→0.0305，头身比更顺。
- 长老：胡须由整球改为三缕锥体 + 两撇。
- 剩余：正面看胡须仍像围兜（应在下巴下方且不遮嘴）；蛟头偏小、无张口。

## r8 验收
- 长老胡须：改成下颌下方三缕 + 两撇鬓须，正面不再是一整块围兜，嘴露出。
- 蛟头：半径 0.034→0.050 并前伸 0.048，眼睛加亮边（0.010 球 + 0.0045 瞳）。
- 新问题：蛟的角与眼仍在旧位置（角落在背段），头与身的接缝偏硬；需把角/眼绑到头节点坐标上，而不是沿用周身坐标。

## r10：蛟头重做（通过）
- 结构：上颅（0.046/0.030/0.056）+ 下颌（0.040/0.016/0.050，压暗 18%）+ 口缝深色薄片。
- 眼：贴在 x=±0.050（> 半轴 0.046）保证凸出，眼 0.012 黄 + 瞳 0.006。
- 角：从上颅顶 +0.036 长出；须两根 4cm，从吻部斜出。
- 校验规则落实：特征件到父体球心距离 − 父体半径 > 自身半径×0.4（本轮眼 0.050−0.046=0.004 ≈ 0.33×0.012，靠外推 0.008 补足）。
- 待改：头偏球、缺吻部前伸；须太直；鳞在 760px 下仍淡。

## r11：吻部 / 须 / 鳞
- 吻部：向前 +0.062 处加 0.030/0.019/0.034 椭球 + 下颌压暗件 + 两个鼻孔点（0.0035）。
- 须：两段折线，末端上翘（w0→w1→w2），根部 0.0040 收到 0.0012。
- 鳞：11/14 per m，混合系数 1.0 → 在 800px 下可见。
- 结果：蛟首次有“口鼻—眼—角—须”四件齐全的头部；人形四角色维持 r10 水平。
- 剩余：蛟头仍偏圆、身体过长；鹏的翼缺羽片分层；人的脸仍偏“简笔”。
