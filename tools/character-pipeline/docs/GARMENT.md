# 服饰流水线 v1

## 总原则
衣服不从零建模，全部**长在人体网格上**：先有九组身体壳，再按部位生成衣片。
好处：换体型不改衣；换配色只改材质；每件衣服都能独立开关。

## 生成器（四类）
| 生成器 | 适用 | 做法 |
|---|---|---|
| `_shell(group, thick)` | 躯干、上臂、下臂 | 取该组三角面，沿顶点法线外推 thick（0.014–0.016m） |
| `_cut_shell(..., ymin)` | 上身（要在腰线截断） | 同壳，但低于腰线−0.02 的三角面丢弃，交给裙摆 |
| `_loft_skirt(ring, rows)` | 下摆、裙、袍身 | 取腰线 32 向半径，向下放样 rows 段，逐段外扩 1+0.55t |
| `_band(y, h, r)` | 腰封、领缘、袖口、下摆缘 | 32 边形环带，半径取腰线均值+0.02 |

## 部件库（一件衣服 = 若干件叠加）
1. 内衫（白，贴体征 0.006）
2. 外袍（青碧，0.014，腰线截断）
3. 袖（上臂+下臂壳 0.016）
4. 下摆（腰线放样，暗青）
5. 腰封（朱砂环带）
6. 交领（待做：沿胸口 V 形切线的两条布带）
7. 缘边（待做：领缘/袖口/下摆缘 三处金线带）
8. 蔽膝（待做：腰前垂下的长方布片）
9. 腰带垂绦（待做：两条细长带 + 玉坠）

## 已实现 / 未实现
- 已实现：1/2/3/4/5（见 out/garment_0.png、garment_35.png）
- 未实现：6 交领、7 缘边、8 蔽膝、9 垂绦

## 坑
- 腿壳不要单独渲染：会从裙摆里穿出来（已删，靠裙身包住）
- 躯干壳必须在腰线截断，否则骨盆部分从裙子里凸出来
- 环带用 32 边形会看到棱，正式版需 64 段或按曲率细分

## round 2：软体下摆 + 补四件
- 下摆改 SoftBody3D：32×7 网格，顶圈 32 点钉腰线，total_mass 2.2、linear_stiffness 0.62、pressure_coefficient 0.9、damping 0.06，两条腿各挂胶囊碰撞体，沉降 150 帧后截图。
- 新增：领缘金环、交领两条斜带、蔽膝（腰前垂片 + 两条金边）、垂绦两条。
- 结论：下摆的重力垂坠与开衩是解算出来的（cloth_cmp.png 对比成立）；但蔽膝/交领是**独立平面片**，不跟随布料表面 → 正面和布同色看不见，侧面又浮在布外。
- 下一轮改法：不再生成独立片，而是在裙子网格上按角度/高度给顶点色（前中线 ±12° = 蔽膝，边界两列 = 金边），这样永远贴着布。

## round 3：交领改刷色
- 删掉浮在体外的两条金带；改为躯干壳顶点色：u=atan2(x,-z)（前中为 0），v=y-腰线，
  half=0.26+(0.46-v)*1.75；|u|<half-0.055 深色内衬，|half-0.055..half| 金边。
- 结果：交领第一次真正贴在胸前，随衣动。但 V 开口偏大、内衬面积过大；且**脸没接回来**（character.glb 的脸是独立 mesh Face/Face.001，只取了最大网格）。
- 下一轮：① 把 Face 网格一起加入（同一骨架，按 group 0 渲染）② V 开口收窄到 half=0.20+(0.46-v)*1.25 ③ 袖口金线刷在手臂壳末端。

## round 4：收窄交领 + 接回脸
- half 改为 0.18 + 1.15*(0.46-v)，V 口明显收窄。
- 把 character.glb 的 Face/Face.001 两个网格按原 transform 重新加回（材质用 SKIN）。
- 发现：character.glb 只有 1 个材质（Matte jade），脸网格没有眼睛/嘴的独立材质 → 接回来仍是“光蛋”。
- 发现：金边出现断续（顶点色依赖三角形，躯干三角面太大 → 一条边只覆盖到几个顶点）。
- 下一轮：① 躯干壳沿交领带做局部分段细分（把 triangles 拆 2~3 次）② 五官用同一套刷色逻辑画（眼/眉/嘴），因为模型没有五官材质

## round 5：细分 + 五官刷色
- `_subdiv(vv,nn,cc,ii)`：1→4 中点细分，颜色/法线按中点插值；躯干壳 3 次、头壳 2 次。
- `_paint_face`：以头包围盒为坐标（u=x/rx, v=y/ry, w=z/rz，w<-0.2 才算正面），
  眼 v∈[0.02,0.16] au∈[0.22,0.50] 深色；眉 v∈[0.22,0.28] au∈[0.18,0.54] 更黑；嘴 v∈[-0.52,-0.44] au<0.30 朱色。
- 结果：五官第一次出现在脸上（怒眉 + 小嘴），但是**纯色块**：没有眼白、没有瞳孔、眉是直带。
- 金边仍呈块状：细分 3 次后仍不够，因为顶点色只能在三角形顶点取样，窄带要么加细分到 4~5 次，要么改用贴图。
- 结论：顶点色适合**大块分区**（衣身/蔽膝），不适合**窄线**（金边）。窄线要么上贴图，要么用独立几何条带。

## 关键发现（用户问“放大几百倍画不上去吗”）
- 放大渲染只提高**像素**，不提高**取样点**：颜色按顶点插值，顶点只有几千个，放到再大也是把色块放大。
- 但检查 GLB 属性发现：character.glb 的三个网格都带 **TEXCOORD_0~3** 以及 **COLOR_0/COLOR_1**，只是没有贴图（images 0 / textures 0）。
- 也就是说：**这个模型本来就能上贴图**，不需要重建 UV。五官、刺绣、金边都可以直接画在 1024/2048 的贴图上。
- 下一步：① 渲染一张 UV 布局图，定位脸部所在的 UV 区块 ② 用 PIL 在该区块画眼白/瞳孔/眉/唇/鬓 ③ 头部材质换成贴图，衣身继续用顶点色分区。

## 五官改为逐像素着色器（解决“放大画不上”）
- rig/face.gdshader：varying 传模型空间坐标，fragment 里用 head_c/head_r 归一化成 (u,v)，
  再画：眼白（椭圆 mix 白）、瞳孔（小椭圆 ink）、眉（扁椭圆 hair）、唇（扁椭圆 lip）。
- 头部壳材质改用 ShaderMaterial（ShaderMaterial 没有 cull_mode 属性，cull 写在 shader 的 render_mode 里）。
- 结果：眼白 + 瞳孔 + 眉 + 唇全部出现，分辨率由屏幕像素决定 —— **放大几百倍就真的变细**。
- 分工定案：五官/细纹 → 逐像素 shader；衣身分区 → 顶点色；刺绣/金边窄线 → 贴图。

## round 6：头发 + 袖口 + 四方位
- face.gdshader 增加头发：hairline = 0.42 - 0.10*cos(q.x*2.6)，q.y > hairline 或 |q.x| > 0.86 → hair。
- 袖口：_paint_sleeve 按 |x| 分三带（<0.775 袍色 / 0.775-0.800 金 / >0.800 深色内衬），臂壳细分 2 次。
- 出四方位：out/cloth_{0,90,180,270}.png → out/turn_v1.png。
- 已知缺陷：① 后脑勺没有头发（hairline 只按 x 判定，后侧 wz>0 区域仍是皮肤）② 侧面五官是正面投影（眼睛跑到脸侧边）③ 交领金边仍块状。
- 修法：头发改为按“到头顶中心的角度”判定（含后侧）；脸部五官改用朝向点积做面向遮罩（只有正面才画），侧面用耳/鬓角遮住。

## round 8：五官中式化（结论：骨相不可改）
- 实际改动：眼改细长上挑（rot ±0.20 后 ell 0.20×0.082）、瞳 0.058×0.062、斜挑细眉 0.165×0.034、小唇 0.135×0.045、鼻影、肤色 (0.86,0.72,0.56)。
- 结果：脸仍是“西式深眼窝 + 方下颌”，shader 只能改皮肤图案，改不了眉骨/眼窝/下颌/鼻梁。
- 底模：Quaternius SuperHero_Male（英式超级英雄比例，T-pose，69 骨）。
- 结论：要“像中国人”，必须换底模（纤细体型 + 平眉骨 + 低鼻梁 + 圆下颌），或对底模做雕刻形变；shader 参数可原样复用。

## round 9：眼睛改用贴片（关键修正）
- 原因：底模眼窝是凹的，逐像素画在曲面上的眼睛只会露出“月牙”，且对齐靠猜。
- 做法：`_eyes()` 在两眼位置各放一片 QuadMesh（尺寸 head_r.x*0.52 × head_r.y*0.26，位置 z = head_c.z + head_r.z*1.02），材质 rig/eye.gdshader：
  - UV 归一化到 [-1,1]，x 按左右镜像；
  - 横向椭圆做眼白，上方 smoothstep 切掉上眼睑，再叠瞳孔与睑线；
  - render_mode unshaded, blend_mix, cull_disabled, depth_draw_never。
- 好处：眼睛不再受网格起伏影响，位置/大小/形状全是参数，改一个数字就变。
- 现状：眼白偏大偏圆，还需要拉长；眉毛仍由脸部 shader 画，压在眉骨上偏硬。
