# 业力是账，道心才是别人眼里的你

## 一、为什么不是"业力=善恶值"

用户指出的问题：魔修自己未必觉得有业力，但架不住别人喜欢除魔卫道；玩家误入歧途后**不能为所欲为**，只能近朱者赤近墨者黑。

所以拆成两层：
- **业力**：天道的账，影响突破（已有）；
- **道心（bias −100…+100）**：你在别人眼里的样子，影响谁能跟你说话。

## 二、四种势力，四套算法

| 立场 | 代表人物 | 怎么看你 |
|---|---|---|
| 正道`righteous` | 青云仙门、万剑宗 | 看道心 + 业力，业力≥30 直接扣分；带"除魔卫道"标签且你 bias<−25 → **见你即斩** |
| 魔道`demonic` | 玄阴教、血河宗、归墟 | 你手上越脏越亲近，结盟再 +20 |
| 唯利`pragmatic` | 灵山药市、百花谷 | 只看钱与货，不看道心 |
| 中立`neutral` | 太虚观（隐世）、天机阁（两面三刀） | 不结盟不敌对，除非你踩门口 |

标签还有：`除魔卫道`、`唯利是图`、`两面三刀`、`隐世不出`、`魔道同盟`。

**两面三刀**单独一套逻辑：明面永远客气，但每回合按你的业力累积"把柄"（exposure）；
把柄 >60 才翻脸扣分——所以黑白通吃是可能的，只要别让人捏住。

## 三、近朱者赤，近墨者黑

- 杀无辜凡人：道心 −8；杀该杀之人：+4；杀修士：−1（师出有名则 0）；
- 与魔道结盟：道心 −6，正道那边"已经有人记下你了"；
- 与正道结交：道心 +4。

结盟有门槛：死敌（score ≤ −40）**不听你说话**，警惕（<0）也结不了。
所以误入歧途之后，你能结盟的只剩反派——这正是"只能"的意思。

## 四、世界尺度

修仙界横跨 **6 国**（大宁、玄京、越境、西戎、云离、赤霄），**12 个势力**，其中：
- 大宁是超级大国，唯一能压住境内宗门；
- 玄阴教跨玄京、越境两国；归墟 reach=3（横跨数国），传说级，不露面；
- 多数宗门的山门不在任何王朝的县治里，凡界的官管不到他们。
