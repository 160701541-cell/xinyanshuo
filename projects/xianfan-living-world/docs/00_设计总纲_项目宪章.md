# 《仙凡共生》独立文字世界模拟游戏｜设计总纲与项目宪章

> **文档版本**：GDD v0.1 · 2026-10-21  
> **项目定位**：独立新游戏；正式名称「仙凡共生」仅为**内部暂定代号**。  
> **状态**：设计稿，**未实施、未测试、未发布**。  
> **隔离声明**：不直接修改《苍岚·人生世界》或 WorldBox《万界仙侠 AI 整合版》的源码、发行渠道和数据。

## 0. 北极星

**我们不预先写好众生的命运，只制定众生能够改变命运的世界规律。**

玩家在一局结束后回望，处处都是自己的故事；下一次开局，哪怕出生在同一县、拥有同样身份，也不保证遇到上一局的人，更不会复刻上一局的结局。不是无限随机事件表，而是**初始条件、独立动机、世界规则、有限信息和偶然扰动**共同引发的因果链。

世界不围绕玩家暂停。NPC不是等待触发的任务节点；他们出生、劳作、相识、成婚、离别、衰老、病死，也可能入仕、经商、拜入仙门、反叛或选择归隐。世界不会替玩家保留每一次机缘，但也不会把「错过」变成没有后路的惩罚。

## 1. 产品目标与不可妥协的原则

1. **世界先于故事**：小说式回忆由真实事件、关系和历史生成，不把固定剧本伪装成模拟。
2. **众生是主体**：NPC有自己的时间、工作、目标、知识、边界、财产和社会关系，并非好感度容器。
3. **仙凡同一世界**：凡俗经济、政务、修仙宗门、灵力资源、武力和寿命共享地理、人口、法律、事件系统，互相改变。
4. **同处一地不等于同段人生**：世界种子、初始人口、天气、价格、判断及后续行为的微小差异，会沿因果网络传播。
5. **精密数据，克制呈现**：底层允许房间级位置、家庭和库存；界面只呈现玩家当前关心的信息，避免传统 MUD 的逐格刷屏。
6. **没有主角豁免**：机缘可被别人先发现，官位会被罢免，恋人有拒绝与离开的权利，玩家可能死亡。
7. **可解释、可复现、可审计**：同一初始状态、世界种子及同一行动序列须尽可能重演；重要结果可追查因果。
8. **可独立运行**：单机离线首先成立；AI语言模型可辅助叙述与对话，不能代替权威世界规则；外部API不是必要条件。
9. **情感不是奖励路线**：信任、欣赏、依恋、欲望、承诺与法律婚姻分开建模。任何援助、赎籍、礼金或权势不等于亲密同意。
10. **可玩而非参数展示**：每个深层系统都需要清晰的玩家操作、可见的反馈、自然的后果以及可理解的成本。

## 2. 体验支柱

### 2.1 一局游戏是一部自然生长的史书

玩家可以是农家少年、官宦子弟、女商人、捕快、游侠、宗门杂役，也可以在同一世界里几经身份更替。没有「成为皇帝」「飞升成仙」的唯一终点。每次抉择打开一批可能，也关闭另一批可能。

### 2.2 世俗生活足够真实，不沦为修仙背景板

粮食、土地、运输、赋税、医疗、婚姻、宗族、教育、法律、职业、商会、阶层流动，都有真实的资源流和制度约束。凡人即使终生没有灵根，人生仍有完整玩法与价值。

### 2.3 修仙不是另一个游戏菜单

灵脉所在山地属于真实郡县或独立管辖区域。宗门需要粮食、工匠、药材、弟子、劳力与商道；凡俗政权会尝试争取修士庇护，也会限制或交易资源。修士的长寿与强大能力，会改变家族延续和政治平衡。

### 2.4 人与人之间的复杂性最值得反复回望

相识是在哪里、为何相识、谁先伸手、有没有负债或权势差、彼此理解过什么、做出过怎样的选择，比「好感度达到80即可结婚」更重要。同一种婚姻形式可能包含完全不同的情感，同一段关系也可能在几十年中改变。

## 3. 世界结构：所有故事拥有同一套地理与时间

空间层级：天下 → 国家/势力版图 → 州府/山域 → 县乡/宗门领地 → 街道/道路 → 建筑/洞府 → 房间/场景 → 可交互物件。

每个实体拥有稳定 ID、所属区域、可追踪位置、可访问规则；地理地图与室内场景是**同一个世界的不同精度视图**，不是两份独立地图。

### 3.1 多种移动共享旅行模型

- 步行：附近可以精确至道路段、门口、院子、房间；可手动探索，也可自动导航。
- 骑马/车船：在路线网中移动，受到道路、货重、天气、治安和时间影响。
- 轻功/御剑/遁术：沿连续空间中的移动轨迹前进，拥有速度、消耗、高度、可见性、天气风险、禁飞区和安全落点。
- 传送：依赖有效阵法、授权、燃料和锚点，不是免费点击任意地图位置。
- 洞天/仙界：通过可解释的空间入口/通道/界门连接，保持统一时间规则或显式声明时差规则。

**反割裂规则**：移动方式改变旅行尺度，不改变目的地的物理存在。飞行抵达客栈后，客栈仍有原来的主人、库存、房间和发生过的事情。

### 3.2 玩家看见的是自己的信息，而非上帝视角真相

界面区分「已确认事实」「听闻」「猜测」「失效情报」。NPC也只能依据自己的记忆、消息来源和观察行动。历史档案有证据、版本和可能的篡改，不能默认玩家知道整张社会关系图。

## 4. 时间与错过

**权威时间**是存档的世界时钟。默认单机模式在关闭游戏时暂停；休眠、闭关、行船和自选时间加速可推进世界。离线继续推进若将来实现，必须由玩家明确选择，且有上限、预警与中止规则。

- 世俗人的几十年是完整一生；修士的几十年也可能只是一次闭关。
- 大事件需要时窗：宗门收徒、饥荒救济、临终探望、战役、婚礼都可能错过。
- **不补演**：不把逝者复活给玩家重试，不无限延期招募考核。
- **不封死**：错过原机缘后可以调查遗迹、求证真相、寻找新的机缘；新的路径必须从现存世界条件中产生。
- 重要事件留有可验证的记录；不等于全部事件都能被任何角色获知。

## 5. 初始世界与重复可玩性

新开局可以选择大框架（时代、社会技术、灵气浓度、难度、是否永久死亡），但不固定具体人的命运。世界创建时生成自然条件、王朝与制度、城市与道路、家庭与人物、市场与资源、宗门与灵脉，然后**让世界运行一段「出生前历史」**，形成可信的旧怨、旧债、家谱和遗产。

随机性必须有来源：气候波动、个体差异、视野差异、有限概率的遭遇和执行误差。禁止用「命运值」隐藏强制规定谁注定飞升。系统应该允许大部分人普通度日、少数人显著改变局势。

**可复现性**：相同 seed + 规则版本 + 初始条件 + 有序操作与随机数流，应能在测试环境回放到相同结果；存档记录规则版本、种子、事件序列和随机源。对「同局的小差异大结果」开展扰动实验，观察统计分布而非只挑选传奇截图。

## 6. 玩家自由度与后果

玩家不是万能权限账户。能否开店、当官、结婚、加入门派、处置财产、处罚罪犯，取决于所在世界的法律、身份、财力、信誉、制度和行为后果。

行动原则：**允许尝试 → 条件检查 → 实际执行 → 世界状态变化 → 其他人作出反应 → 历史留下痕迹**。剧情不是按钮结果，而是多个人连续行动后的复杂后果。

暴力、胁迫、拐卖、徇私、腐败等可能作为社会问题、罪行和冲突出现；游戏不得把伤害、控制或利用权力关系自动包装成爱情奖励，必须反映受害者意愿、后果与社会制度（详见人物关系分册）。

## 7. 信息架构：不让玩家每天读上千条重复日志

固定五类入口，名称可在原型测试后修改：

1. **世界**：分层地图、路线、当前场景与导航。
2. **人物**：身份、技能、身体、携带物品、已知关系。
3. **行动**：对话、观察、工作、经营、修行、战斗，按情境展示。
4. **势力**：家族、官府、商会、帮派和宗门的实际权限界面。
5. **纪事**：个人日记、传闻、人物生平、家谱、王朝年表和事件索引。

场景文本采用「第一眼摘要 + 可展开细节 + 变化通知」。熟悉路段允许快速行走或自动寻路，重大事件中断自动旅行；日志默认汇总重复通知。地图随时可知道当前位置及目标路线，不必在房间之间连续点击「东、东、北、西」。

## 8. 为什么不是直接复刻 MUD

MUD最有启发的是**实体与房间的组织纪律、空间连通、人与物的真实可访问性**；局限在于逐房间移动成本、纯命令交互、刷屏、旧式NPC随机游走和不适合现代移动设备的界面。我们吸收其精度标准，但产品层使用现代响应式UI、上下文行动和多尺度导航。具体运行时选择待技术原型验证，不承诺必须使用FluffOS。

## 9. 先验收一个完整的县，而不是许诺无限天下

首个垂直切片：一县城、两村落、一条跨县商路、一座宗门；**约1000名有稳定身份和家庭/职业记录的人口**，其中玩家附近几十名精细执行日程，远处使用分层调度。

必须跑通：出生身份 → 家庭与职业 → 出行与建筑探索 → 粮食生产/交易/库存 → 官府税收 → 两名NPC之间的自发关系变化 → 宗门试炼/修炼 → 御剑返回 → 时间跃迁后的历史回顾。

这只是首版的设计目标，不代表已经编写或通过测试。

## 10. 设计决策记录（ADR）

- **ADR-001**：世界规则和事件为事实来源；语言模型仅生成可核验的表达层。
- **ADR-002**：人物、婚恋、婚姻、性、自主意愿、亲子及财产为相互关联但不同的状态。
- **ADR-003**：空间采用区域拓扑 + 路线距离 + 场景层级 + 飞行高度，不用单一房间格子代表所有尺度。
- **ADR-004**：默认单机离线，未启动时不自动消耗玩家现实时间。
- **ADR-005**：每个扩展玩法必须列明对现有世界库存、权利、关系、时间和历史的具体影响。
- **ADR-006**：所有新增子系统通过共享实体ID、事件/事务接口连接，禁止一套功能一套孤立存档。
