# 2026-10-21 — 临安县v0.3地图即场景专项

## 用户反馈 / P0
v0.2的场景、地图、附近人物被拆成不同卡片，用户需要切换列表「挪」到房间，反而比老MUD更割裂；主要问题是场景空间逻辑和交互语法，而不仅是颜色。

## 本轮真实源码调整
1. 场景面板成为主地图：街道、建筑入口、人物、物件在同一场景坐标层；移除旧地图独立tab和附近人物列表。
2. 建筑新增后院、粮仓、县衙内署、客房和宗门药圃等真实可进入房间；以 `links` 作为唯一位置连接真相。
3. 地图点建筑直接进入；县域图点地点选择路线，自动循路；无需用户不断翻页点步行。
4. 修士御剑与徒步共用实体地点，御剑消耗灵力且室内不能起降。
5. NPC标记由真实人物及地点作息生成；可在场景中点击NPC后交谈，初遇记入故人簿。
6. 使用SQLite? **不是**。当前数据持久化仍是WebView IndexedDB；保留其数据库名；为schema1老存档加入schema2房间迁移。
7. Android `versionCode=3`，`versionName=0.3.0`；签名配置沿用v0.2试验密钥。
