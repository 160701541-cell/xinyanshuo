# 家族：借《修仙家族模拟器》的结构，不借它的图

TapTap 那款《修仙家族模拟器》值得借的是**结构**——族人是一张张卡，卡上写着灵根、寿元、婚配，玩家看的是“这一代人怎么活下去”。它的图不能借，我们手上已有验过的 CC0 头像，正好够用。

## 一、族人卡（美术方向）

- 卷轴底色 + 单张人物卡：**圆形头像（金边）+ 姓名 + 灵根标签 + 性别/年龄/余寿/境界 + 婚配**，右侧一个动作按钮。
- 卡不用竖排大字，也不做花哨边框；一眼能扫完一列人是这套玩法的核心体验。
- 头像沿用 `assets/people/han_male.png` / `han_female.png`（CC0），卡底色跟着境界走是下一步。

预览：`docs/preview/family-cards.png`

## 二、规则（`family.mjs`，family-0.1.0）

| 项 | 规则 |
|---|---|
| 族人 | 从世界里**收真人**（`joinFamily`），不是凭空造卡 |
| 婚配 | 异性、16 岁以上、双方未婚；成亲后两人都入族，声望 +2 |
| 生育 | 必须已成亲；女方 16–45 岁；孩子直接进世界人口与族谱 |
| 血脉 | 孩子灵根从父母抽：双修士里，18% 比父母更强、44% 随强的一方、26% 退一档、其余无灵根；两个凡人只生凡人 |
| 寿元 | 凡人 62 · 炼气 110 · 筑基 180 · 金丹 320（±9% 个体差），`ageFamily()` 过年时结算老死 |
| 家业 | 田亩 ×0.6 + 在族修士 ×12 为年入，族人口 ×3 为口粮；入不敷出就卖地（不低于 20 亩） |
| 声望 | 成亲 +2、生出有灵根的孩子 +4、每名在族修士每年 +1 |

## 三、实测

- 顾氏开局：收两名凡人 → 成亲 → 生 3 子（皆无灵根，符合遗传规则）→ 过一年，3 人长岁，家业 +39 银。
- 名字不重：同代重名会顺延字辈，族谱里不会出现两个“崔知微”。

## 四、验收

- `node --test tests/*.test.mjs` → **188/188**
- 新增 6 项：收真人、联姻约束、生育需成亲、凡人父母不生灵根/双修士出好苗、寿元与增岁、年景结算不为负。

## 五、还没做

- 族学、族规、族产经营（铺面/灵田）只是田亩与银两，没有具体产业。
- 没有“招婿/过继/分家”与家族分裂；也没有族中矛盾与夺权。
- 头像不分境界与性别以外的差异，孩子成年后也不会换装。
- 没有实机截图：本机无浏览器，预览图是同源数据离线渲染。
