# 从名单到街上的活人

## 一、他们现在有住处、有作息

`attachPeople(w)` 一次性把 12 门 × 8 人 = **96 名修士**落进世界，每人带：

- `home`：落脚点。青云/灵山两门在县境内的山门；其余按 id 哈希分到客栈、客栈二号、西街、东市、南门五处，不会全挤一家；
- `bond`：对你的好感（帮过他 +12）；
- `helped`：你帮过几次。

作息 `whereOf(person,hour)`：夜里（<6 或 ≥21）回落脚点；白天四成人出门，落在东市、西街、南门、灵山药市，其余待在屋里。**按人哈希定死**，所以同一个人每天的行踪稳定，不会一刷新就换地方。

实测（96 人）：东市白天 15 人、西街 21、南门 19、客栈 13。

## 二、他们对你的态度，是"他自己的道行 + 你做过的事 + 交情"

`personAttitude(w,person)`：

- 道行 ≥25：看你的行径（护人加分，滥杀扣分）；
- 道行 ≤−25：反着看（你越狠他越认）；
- 中间：只按名声松松地看；
- 再叠 `bond`：帮过他一次，态度实打实地往上走，理由从"他不太关心你"变成"记着你帮过他"。

## 三、同门未必同心

`bondBetween(a,b)`：同一门里，善人与恶人固定为 **−0.8**（互看不顺眼）；其余按两人 id 哈希出一个 −0.6…+0.6 的亲疏。所以血河宗的柳夜夜（端方 +52）与钱岚临（恶名昭彰 −45）不会一起请你喝酒。

## 四、界面上

仙门页新增「街上的人」：按你**当前所在位置**列出在此的修士（姓名、门派、脾气、境界、他怎么看你），每人一个「相助」按钮——点一下好感 +12、行径 +1，他会记住。

## 五、验收

- `node --test tests/*.test.mjs` → **143/143**
- 新增：96 人落地与行踪确定性、帮人涨好感、同门恩怨。

## 六、还没做

- 他们不会主动找你说话，也不会自己走远路（只在县城几处打转）。
- 帮过的人不会在别处替你说话（"他替你美言"还没有）。
- 同门恩怨只到数值，没有事件（不会因为你和钱岚临走得近，柳夜夜就疏远你）。
