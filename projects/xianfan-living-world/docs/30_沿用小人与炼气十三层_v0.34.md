# 不再另画小人：把苍岚验过的素材接回来，境界也接回炼气十三层

## 一、小人：换回之前测试过的那套 CC0

之前那套程序化 SVG 小人是我自己画的，跟你们验过的不是一批。现在换成仓库里已有的素材（`/root/repo/hd2d-assets`）：

| 用途 | 文件 | 来源 | 授权 |
|---|---|---|---|
| 官差/捕快/军士 | `assets/people/hero_walk.png` | OpenGameArt「Samurai Sprites」by sebshady，裁 3×4 帧、只重上色衣服 | CC0 |
| 农户/渔民/脚夫 | `assets/people/farmer_walk.png` | 同上 | CC0 |
| 商贩/掌柜/匠人 | `assets/people/merchant_walk.png` | 同上 | CC0 |
| 山民/修士/游侠 | `assets/people/woodsman_walk.png` | 同上 | CC0 |
| 将领/修士头像 | `assets/people/han_male.png` / `han_female.png` | OpenGameArt「Ancient Chinese Characters Pack 1」by nessava | CC0 |

- 走图规格：48×48、3 列 ×4 行（下/左/右/上），每向 3 帧，`stepOf()` 按 170ms 循环。
- 职业→图的规则在 `people.mjs` 的 `RULES` 里；认不出来的落到山民图，不再临时画。
- 将领与修士在世界图上是**圆形头像**（金边），其余是走路小人，符合“大世界里除了将领和修士是头像”。
- 程序化 SVG 那套没删，只是降级成“素材没加载出来时的兜底”。

## 二、境界：炼气 1–13 层 + 筑基/金丹

`cultivation.mjs` 新增：

| 项 | 内容 |
|---|---|
| 层数 | 炼气一层 → 炼气十三层（13 级），往上才是筑基、金丹、元婴 |
| 修为门槛 | 40 / 70 / 110 / 160 / 220 / 300 / 400 / 520 / 680 / 880 / 1120 / 1420 / 1780 |
| 吐纳 | 每世界小时的收益 = 灵根系数 × (1 + 灵气密度) × 经脉负荷折扣；同时扣体力、涨经脉负荷 |
| 经脉 | 到 100 就吐纳不动，必须歇息养脉；层间突破要求经脉 ≤ 92 |
| 筑基 | 要炼满十三层，掷骰（基础 55%，嗑丹 +25%，业力最高扣 60%），失败折修为 200 并伤经脉 |

灵气密度：临安县城 0.18 / 松林 0.26 / 青云山门 1.0 / 灵山 1.35。
