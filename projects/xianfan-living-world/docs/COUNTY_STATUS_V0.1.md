# 临安县13,680人实验｜实施状态与边界 v0.1

**日期**：2026-10-21。**分支**：`xianfan/independent-living-county-v0.1`。**托管**：公开 `160701541-cell/xinyanshuo`，独立目录；非主线发布。

## 固定人口门槛

用户明确指出：正常县城及其周边人口应**在1万人以上**，只有地广人稀等特殊地理条件才可合理例外。因此首个县境样本设定为**初始13,680人 / 18个定位分区 / 3,431户**。人口是真实生成的档案记录，不是UI虚写的数字。

**明确区分三种规模**：
- 户籍规模：每人有唯一ID/家庭/职业/住址；13,680可审计。
- 活动模拟：地区经济按日结算，少部分可见NPC按职业与时辰确定所在地；不是全部人时时逐步寻路。
- UI显示：仅显示玩家当前场景少数人物；画面不同时呈现上万人。

不应为了性能把户籍人口删到1000，也不应把13,680普通居民伪称13,680个独立大语言模型。

## 已有代码

`prototype/core.mjs`：可复现随机种子；世界/村落/山门生成；户籍家庭与职业；基于地方位置的基础日程；个体出生/死亡；季节农粮与价格、税库；商贸交易；县衙赈粮；步行和御剑；事件日志；JSON存档与状态不变量。

`prototype/app.mjs`：移动端场景、交互地图、人物、社会、纪事导航；身份体验开关；用户操作只调用核心规则。

`prototype/standalone.html`：集成HTML/CSS/JS的单文件离线演示，避免普通手机用户配置本地服务器。
