# v0.5 实机反馈驱动更新｜连续移动 + 山河地图 + 地点详情

> 项目独立隔离：只在 `xianfan/independent-living-county-v0.1` 的 `projects/xianfan-living-world/` 更新。此模块不是《苍岚》的3D引擎、签名PCK，也不是WorldBox MOD。

## 用户2026-10-21实机问题

1. 第四级道路一点击便结算时间和位置，缺少旅程过程；州县移动也应逐帧计算时间。
2. 点击县衙应先弹窗：介绍、在场人物与是否前往，不应直接切场景。
3. 城门、防御墙、道路、房屋、院落、室内房间缺少清晰视觉层次与连续可辨的地理关系。
4. 州/天下地名极小、空白且不可读，没有山川、河流、海拔、仙门、官道、城防及材质细节。
5. 放大应连续经过分级而非强制按钮换图，高层应保留低层的重要信息。

## v0.5 已实施（源码与单元测试可核验；手机真机仍待验收）

- `spatial.mjs` 新增 `beginRoadJourney/tickRoadJourney/visualRoadPosition/cancelRoadJourney`：路线入队后**不提前移动、不预付游戏时间**。帧计时器在每一次移动过程中推进世界时间及道路位置，支持中途暂停、存档恢复；到达门口才执行建筑进入。
- 县域移动新增 `beginRegionJourney/tickRegionJourney`：跨镇步行和御剑有过程中持续流逝的时间；飞剑灵力随已飞旅程逐步消耗，不在点击时瞬间扣光；旅程结束前不传送角色。
- `app.mjs`：地点与建筑首次点击只打开浮层介绍、可核对的在场工作NPC、门口距离与「步行前往/进入」；按钮才开始行程。地图缩放采用滚轮/双指手势触发语义层级自动切换，仍可用顶部定位按钮或层级直达。
- `atlas.mjs`：独立 SVG 矢量地图，县城可见城墙/门楼/塔楼/院落/屋瓦纹理/石板道路/河流/农田；县域有粮田/渡口/山脉/山门/河流/连通官道、城防图。**县域缩略城池从与街区相同的道路与建筑坐标生成**。州府和天下有地理轮廓、山系、河道及可读标签，其他州郡的地理标注为静态示意，不假称拥有模拟人口。
- 不使用世界图片覆盖命中区域：地图场景直接由可交互 SVG 元素组成。已实现原型级图标工厂 `tools/make_map_icons.py`，从同源 SVG `<symbol>` 生成具来源与SHA256的8个独立图标。当前没有接通WorldX接口，因此没有宣称使用WorldX素材。
- 建筑内划分县衙堂案、粮行仓库、铁铺炉膛、客栈桌案与宗门地坪，门/物品/人物在室内画布有位置；不是室外道路材质直接复制。
- `tests/world.test.mjs` 增加移动过程、停止时间守恒、门口触达后入室、县域时间推进与地图地物测试。

## P0尚未完成 / 不得误报

- 仍是单机浏览器WebView APK，尚未有Android真机验收记录。
- 三级以上**不是完全连续的全天下GIS大地图数据**：当前只有临安县局部路网是可实际点选通行；州与天下为可缩放可查看的地理种子和示意，无法支持任意山地的真实通行/任意县城传送。
- 区域旅程显示的是进度与路径位置，仍非数万公里地面逐格模拟；地图坐标和道路单位目前是原型比例尺。
- 13,680常驻居民仍只有基础人口档案、职业/时间位置函数；没有实现全人口日常在真实地图上的连续实体寻路、所有住宅精确房间、真正跨村商队。
- 屋顶、门、瓦纹、道具现在是自制矢量符号；不是WorldX真高精地图或实景房屋模型。
- 同包名测试签名仅面向这款独立新游戏；正式发行应切换受保护证书。
