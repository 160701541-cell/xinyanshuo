# v0.6 连续地图整改 | 2026-10-21

## 用户实机问题
1. 松林村放大后错误地进入县城街道。
2. 缺少独立角色状态HUD；人物无地图头像与移动状态。
3. 皇城、首都、其他国家、修仙宗门地理位置未组织。
4. 地图缩放误触层级切换，不能真正连续滑动缩放。
5. 普通人显示根本不能使用的御剑操作。
6. 地图缺少实际阻挡、建筑入口与连续米制定位。

## 本轮真实提交
- 新增 `overworld.mjs` / `web/overworld.js`：米制绝对坐标、地理图层、建筑碰撞/城墙/城门、分段路径、行程时钟、NPC地图位置、旧存档位置迁移。
- 新增 `overworld-ui.mjs` / `web/overworld-ui.js` 与 CSS：连续 Canvas 地图、惯性禁用的拖动/双指缩放、POI详情卡与建筑门交互、头像、个人HUD。
- 图层包括丘陵、河道、道路、城池及程序房屋；京城/邻国/其他宗门是透明标注的地理占位，不表示已开放。
- 手动点击“新局”前保留存档，升级 Android versionCode 和版本名后才允许尝试覆盖安装。

## 技术约束
- `player.mapPos`（米）是唯一玩家位置权威；相机 `mapCamera` 与其完全独立。不得在缩放时根据scope重写位置。
- 进门只允许抵达外门 `door` 35m 内；建筑/墙体已实体碰撞；远景坐标系不用离散四级地图切换。
- 每秒推进真实地图行程和模拟时间；方向越过墙面必须通过路径搜索或返回不可通行。
- 玩家在地图上观察不到的NPC不该全部绘制；本期只有部分NPC具有短程活动状态，不能写全员活动。
- 地理世界在数据量和性能上采用LOD/区域流式生成路线，当前已实施的近景并不等于全世界米级实物模型。
