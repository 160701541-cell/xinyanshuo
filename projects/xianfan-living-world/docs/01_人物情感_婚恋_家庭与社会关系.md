# 人物、情感、婚恋、家庭与社会关系模拟｜专项设计 V0.1

> 本分册是《仙凡共生》的**核心机制**，不是附带的恋爱模块。下列人物和事件均为系统验证用假设示例，**不是固定剧情**。

## 1. 设计总原则：我们模拟关系，不模拟好感度奖券

一个人帮助另一人，可能换来感激，也可能让对方觉得羞愧、亏欠、受控制，甚至提高警惕。同样一句话，对不同经历、身份、性格、所处场合的人，意义完全不同。

因此，禁止「送礼+10，达到80结婚」「赎身=获得伴侣」「取得监护权=可发展亲密关系」「官位高=对方接受」等机制。**爱情、亲密接触、婚姻、同居、性行为、财务依附、亲子关系、监护关系，分别建模，不能互相自动解锁。**

设计追求的是：重逢时玩家记得**怎样认识的、为什么走近、在哪里失去信任、是谁先改变主意**。有些关系终生停留在知己、亲属、同袍或师徒；也有真心爱过却最终分开的关系。

## 2. 人物不是单一“性格标签”

### 2.1 人物持久化档案

每名精细人物至少有以下组别：

| 维度 | 内容 | 影响 |
|---|---|---|
| 身份 | ID、姓名、性别、年龄、籍贯、家族、阶层、婚姻/监护/职务状态 | 法律和社会机会 |
| 生活条件 | 健康、居所、财产、收入、债务、职业、技能、日程 | 是否有余力选择 |
| 长期倾向 | 谨慎/冲动、独立/依赖、守诺、同情、权力欲、风险偏好、价值观 | 决策权重，不是行为定式 |
| 需求和愿望 | 安全、尊严、爱、亲属责任、事业、财富、修行、自由 | 行动目标随人生变化 |
| 知识与信念 | 亲眼见过、听闻、误解、证据可靠度、信念更新时间 | 杜绝全知NPC |
| 社会位置 | 社会声誉、出身限制、名誉风险、宗门/官府/行会约束 | 行动成本与社会后果 |
| 关系与记忆 | 相识起点、关键共同经历、承诺、矛盾、信任修复、隐秘 | 人际历史可追溯 |
| 人身边界 | 明示意愿、禁忌、接受的接近程度、是否存在依附或权力压力 | 关系行动准入 |

**性格会成长而非按百分比乱跳。**长期经历造成渐进变化；重大创伤或深刻感悟可能有突变，但系统必须记录发生原因。人物不应完全可预测，亦不可用一枚骰子替代整个判断过程。

### 2.2 人物拥有自己的目标，不以玩家为中心

目标由个人需求、资源、关系责任和现有机会生成。可同时存在矛盾目标：一人既想照顾父母，又想入仙门；既爱一个人，又不愿放弃官职。NPC会犹豫、拖延、求助、反悔；其行动也可能失败。

同一人物对不同人会展示不同的一面：对长辈恭敬、对下属严苛、对友人坦诚，不等于存在三套虚假的「人设」。行为由内心倾向与场合共同约束。

## 3. 关系不是一条进度条

人物关系是一个**有方向、非对称、持续变化的社会关系图**。甲信任乙，乙未必信任甲。允许爱与怨、尊重与恐惧、感激与戒备同时存在。

### 3.1 推荐关系维度

| 变量 | 含义 | 常见误读 |
|---|---|---|
| 熟悉度 familiarity | 相处时间、对彼此生活的了解 | 熟悉≠喜欢 |
| 信任 trust | 相信对方可靠、守密、守诺 | 礼物≠信任 |
| 尊重 respect | 认可能力、人格、原则 | 敬畏≠亲近 |
| 温情 affection | 喜欢与关怀 | 感激≠爱情 |
| 吸引 attraction | 个体主观吸引，随人生及处境变化 | 不能决定同意 |
| 安全感 safety | 相处时是否不受威胁 | 恐惧依附≠亲密 |
| 依赖 dependence | 经济、居住、社会或精神依赖 | 依赖≠自愿 |
| 义务 obligation | 亲族、契约、报恩、师徒、法律责任 | 义务≠爱 |
| 怨恨 resentment | 未化解伤害和利益冲突 | 道歉≠自动清零 |
| 价值契合 value_alignment | 对责任、金钱、修行、子女等分歧程度 | 相投≠必在一起 |

关系状态还应包含**叙事证据**，如「第一次相识事件ID」「共同经历」「未履行的承诺」「误解」「已知秘密」「最近联系」「社会公开程度」。相互关系是两条有方向的边；社会公共关系（夫妻、师徒、雇佣、血亲）由独立约束对象定义。

### 3.2 关系标签是结果，不是按钮

「邻居」「朋友」「爱慕」「恋人」「夫妻」「前伴侣」「义亲」「师徒」「仇敌」等可以并存或转变，但有些性质不同：

- 血缘与亲子是生命历史事实，不因感情变淡消失。
- 婚姻是受时代和辖地制度约束的社会/法律状态，可能不等于相爱。
- 相爱是人物双方可能共同形成的情感状态，不自动包含婚姻。
- 亲密行为必须依靠**当下、明确、可撤回的自愿同意**；不是好感阈值的产物。
- 一人暗恋另一人只是单向状态；对方没有义务回应。

## 4. 相识方式必须进入人的一生，而不是独立的前缀文案

**相识场景是世界事件**，至少记录时间、地点、双方身份、第三方、具体缘由、权力差、是否自愿、各自的认知以及事件之后发生的实际改变。

| 起点（均为可能性，不是剧本） | 必须在系统里留下的事实 | 会衍生的不同人生 |
|---|---|---|
| 邻里/同窗/同业 | 住处、学业/工作交集、共同熟人 | 长久陪伴、竞争、疏远、合作 |
| 赶集/旅途偶遇 | 同一时间和地点、出行原因 | 失联、再会、误会、短暂同行 |
| 危险中救助 | 伤势、风险、援助成本、后续需求 | 感激、羞耻、依赖、独立离开 |
| 路边收留/救济 | 是否成年、是否受监护、居住与供养关系 | 亲情、独立发展、离家；**不可把收养当恋爱养成** |
| 媒妁议亲/家族结盟 | 双方意愿、父母条件、聘礼嫁妆、户籍与财产权 | 相敬、逐渐相爱、互不相爱、拒婚/解除婚约 |
| 赎籍/脱离被剥削机构 | 本人年龄、是否成年、法律身份、欠债及实际自由 | 重建生活、择业、离开恩人；**赎付≠购买爱情** |
| 偷情/私奔 | 双方自愿、原有承诺、家族法度、交通与生计 | 新生活、矛盾、失去信任、法律/亲族纠纷 |
| 官民/主仆/师徒上下级 | 职权、财产依赖、惩戒权、师门戒律 | 尊重、权力依赖、利益冲突；亲密存在显著权力风险 |
| 强迫、拘禁、胁迫 | 强制事实、伤害、控制手段的结果、见证和证据 | 逃离、求助、审判、创伤、反抗；**绝不建模为浪漫攻略路线** |
| 仇敌和解 | 原因、伤害、责任、赔偿与持久行为改变 | 可修复、无法修复、表面和解或长期对立 |

表格里的每一项都是**社会条件与后果模板**，不是给 NPC 钉死的分支结局。例如「明媒正娶」仅说明相识和婚约形成方式；婚后是真情、互敬、冷淡还是冲突，由彼此具体经历继续决定。

## 5. 对用户提出的复杂情境的正式处理

### 5.1 「捡来的」：必须区分救助、收养、同住与平等交往

如果救助的是未成年人，形成的是救助、监护或收养关系，涉及责任、教育、成长、自主权和日后独立，**不应转化为恋爱养成**。如果救助的是成年人，也必须区分帮助与控制：提供住处的人没有情感上的所有权。成年人可以建立平等友谊、合作或双方自愿的关系，但不能因经济寄居、债务或依赖而默认同意。

### 5.2 「明媒正娶」：婚姻制度与个体情感分离

家族可能重视门第、田产、仕途、聘礼、盟约；人物可能重视自由、责任、经济保障或个人爱慕。系统分别记录媒人、议婚、双方意愿、订婚、婚礼、婚书、财产、户籍和居住安排。婚后可以亲近，也可以只是合作经营一家；若感情发生改变，需要有长期的共同生活因果，而非「结婚完成 → 爱情100」。

### 5.3 「花魁赎身」：不把脱离困境当成可兑换的亲密关系

涉及性剥削或社会污名的背景时，角色只能为成年人，相关历史以**非露骨叙事**处理。玩家可能资助一名受剥削者脱离原机构，但对方成为自由的人，仍有职业、居所、亲友、尊严和独立决定权。她可以感谢玩家，也可以不愿保持联系；她对关系的判断受实际经历和安全感影响。不得设计成「付费赎出 → 强制加入后宫」。

### 5.4 「强迫」：允许世界有黑暗面，但不粉饰强制

在可信社会模拟中，威逼、控制、强迫婚姻、性暴力或剥夺自由可能被作为**伤害和犯罪事实**记录，并引出受害者主体行动、证人、调查、司法、逃离、关系破裂与长期后果。不得将恐惧、屈从、求生策略误判为真诚同意；不提供诱骗、胁迫的操作教学，也不制作可供玩家反复刷取的露骨伤害场景。涉及敏感题材提供内容过滤及跳过、只保留事件因果，不以耸动描写取乐。

### 5.5 「偷情私奔」：恋爱不是只考虑两个人的一条直线

当双方均为能自愿决定的成年人时，私奔可能来自真情、求生、对家族压迫的反抗，也可能是短视冲动；结果受原有婚约、法律、家人、子女、钱粮、交通和风险影响。人物可能彼此真诚又伤害第三人，既有爱情又背负愧疚。婚约破裂后的财产、抚养责任和社会反应必须进入真实世界状态。

## 6. 情绪不是剧情按钮，而是对生活的解释

每个人同时具有短期情绪（高兴、恐惧、悲伤、羞愧、愤怒、疲劳）和长期倾向（安全感、对某人的信任、对未来的希望、创伤后对情境的警惕）。单次事件先触发感受，再经记忆、思考、交流影响长时态度。

例如赠送昂贵礼物可能产生：

- 平等朋友：欣喜与感激。
- 清贫但自尊强的人：感激与压力并存。
- 刚遭背叛的人：猜忌对方有所图谋。
- 处于上下级依附关系的人：担心拒绝会失去工作。

**同一行为不能拥有通用固定数值回报**，也不能直接展示 NPC 内心全部真实参数。游戏可向玩家呈现表情、措辞、行为和日后选择，玩家必须根据这些有限线索理解对方。

## 7. 关系演化的决策过程（示意，非数值定案）

一次关系相关行动至少经过：

1. **意图生成**：人物基于当前目标和情绪提出行动候选（探望、倾诉、保持距离、求助、拒绝、离开、提亲）。
2. **可行性**：实际位置、时间、社会约束、资源、公开/私密环境、关系史、权力关系。
3. **知识判断**：人物知道哪些事实？可能误解哪些事实？
4. **自愿与边界门禁**：涉及亲密的互动，必须是有能力作决定的成年人，且不存在被迫等无效同意的情形；必要时直接拒绝。
5. **有限理性选择**：收益、风险、道德观、义务、情绪、个性影响权重，留下有控制的随机性。
6. **世界执行**：只在行动真实完成时修改合法事实，记录地点、时间、见证和结果。
7. **双方分别更新**：行动者、接受者、旁观者拥有不同的记忆和评价；影响数日到数十年。

禁止简单使用 `romance_score >= 80 && gift_count >= 10` 决定亲密。可以使用隐藏参数辅助计算，但必须被**事实条件、当下同意与角色自主决策**约束。

## 8. 法律婚姻、社会婚俗与感情本身相互区别

婚姻不是跨国家与朝代完全一致的按钮。不同制度可以选择单配偶、多配偶或不同继承与离婚规范，但**不能把制度允许直接等同于每个人都愿意**。人物有文化认同，也可能反抗所属文化。

需要支撑：

- 相识与议婚：谁介绍、婚约是否合法、谁真正愿意。
- 婚礼与户籍：见证、礼仪、婚书、家族关系及社会承认。
- 财产与住处：田地、嫁妆、聘财、工资、债务、共有财产、继承。
- 日常生活：同行、做饭、育儿、协商、家庭劳务、彼此独处。
- 冲突：经济问题、仕途迁徙、修炼闭关、疾病、家庭干预、价值变化。
- 分居与分离：感情消退、离婚、守寡、再婚、抚养安排，依据世界制度执行。
- 亲子与家谱：出生/收养/继承，儿童拥有独立身份与成长路径；未成年人**不参与任何性亲密模拟**。

身体亲密如需要呈现，采用**成年人间自愿、非露骨、淡出处理**，重点放在选择、交流、信任及之后的生活后果，而不是CG、计次和奖励。生育规则与亲密场景分离，不能把人物仅当繁殖资源。

## 9. 世俗与修仙共同影响关系

- **寿元不对称**：凡人配偶会衰老，修士未必。长生者可能见证亲友几代人的生活；不能自动以「凡人碍事」抹去关系。
- **宗门戒律与身份**：师徒、宗主与弟子、传功与依附有权力界限。修士可解除职权后发展关系，但仍需考虑历史压力与自愿。
- **政治婚姻**：一个家族可能以联姻稳固商路或联盟；人物可能接受、协商或拒绝，产生有成本的后果。
- **势力与名誉**：丑闻会影响官府仕途、商人信用和宗门声望，但传播必须有见闻和信息链，而不是全图瞬间同步。
- **修行与距离**：闭关十年不是跳过一页对话；对应的人会经历十年的工作、家庭和情感变化。承诺可能被守住，也可能失效。
- **自由与资源**：有钱有势能提供机会，也能形成压力；以地位购买关心、强制控制他人都不能直接改变对方的真实意愿。

## 10. 微观世界示例：同一组人物，不同人生

> 这是**反事实测试样例**，不是固定支线。只有相同因果条件成立时才会发生相似结果。

**初始条件**：临安县女医者苏晚晴，二十四岁，擅长医药，正在供养病中的母亲；商人顾砚之，二十七岁，经营药材运输；苏晚晴还有去州府开药堂的愿望。二人均有朋友、财产、独立决策和生活日程。

**世界甲**：春季雨水正常，药材车队如期到达。顾砚之与苏晚晴因一次普通药材交易相识；多次合作互相信任，但苏晚晴选择赴州府行医。两人保有往来，却未发展爱情。三年后苏晚晴另与同行志趣相投，成婚或独身均可能发生；顾砚之的商路也不会因玩家没有介入而消失。

**世界乙**：一场洪水冲毁桥梁。药材缺货，苏晚晴必须选择昂贵替代药、转移患者或寻求运输帮助。顾砚之也面临亏损风险；他可能出手相助，也可能因债务无法伸手。若合作发生，双方的关系从共同解决危机开始，但能否成为恋人仍取决于后续的日常相处、愿望、尊重和**双方的实际选择**。

**世界丙**：玩家是县衙官员，试图通过职权迫使苏晚晴留下。系统应记录不当权力施压，她可能求助同僚、亲族、上级或选择迁离；不能把她的沉默、表面服从计为爱情。玩家行为可能反过来影响医馆、税收、地方名誉与官员考核。

这三局里最值得记录的，不是作者预设的三套结局，而是「桥什么时候被毁、谁知道药材短缺、谁有能力援助、谁作了什么选择、谁因此付出代价」。

## 11. 玩家看见的关系界面

**不要显示“此人爱你72/100，赠礼可提升”**。更符合世界观的设计：

- 人物页：姓名、当前公开身份、职业、年龄范围（信息未知时不强行揭示）、最近见面地点。
- 「你们的经历」：按时间追踪第一次相识、合作、重大分歧、承诺及各自留下的证据。
- 「你对她的理解」：玩家已知偏好与价值观，明确区分亲眼见证和推测。
- 情境行动：探望、邀约、表达心意、道歉、商谈婚约、保持距离、帮助处理实际难题等，只出现当下可行的选项。
- 公开身份：已婚、订婚、师徒、官职、所属宗门等应区分公开与私密信息，不应泄露NPC所有秘密。
- 回忆方式：重要经历可收藏为「我的人生片段」；关系破裂也不是从日志中删除对方。

AI可负责人物语气和细致对话，但须被「此人真实知道什么、真正想要什么、已经发生过什么、当前能否行动」四重事实条件限制，不能为了迎合玩家改写人物自主意愿。

## 12. 时间跨度与代际情感

一段关系留下的痕迹不仅是伴侣状态，还包括产业、共同修建的房屋、留下的书信、师承、救助的家庭、抚养的后人和口耳相传的故事。离开世界的角色仍可能通过后代、遗产与地方记忆影响后续玩家。

但不可机械保证每个人都被纪念。贫民也可能没有墓志；尘封往事可以通过实物、见证人或旧账发现，不能由系统凭空补记。真相应存于权威事件账本，角色所知依照社会传播独立生成。

## 13. 可测验的系统验收清单

1. 两人初次相遇的确切时间、地点、原因可追溯；不需要玩家在场。
2. 单向好感不自动转化为双向恋人关系；一方拒绝后保持拒绝结果。
3. 重复赠礼不会突破同意、人格边界或法律限制。
4. 对被救助者、被赎籍者不自动创建伴侣、随从所有权；其自由可被实际行使。
5. 未成年人及监护关系不会触发任何亲密内容。
6. 官民、雇佣等权力差能影响NPC对行为的理解，识别强制与屈从不等于同意。
7. 法律婚姻、相互爱情、共同居住、财产、亲子状态可彼此独立变化。
8. 情感升温可以由多次可信相处形成，亦可能因价值分歧长期止步于友情。
9. NPC会主动拒绝、离开、改行、重新成婚、寻求帮助，行为具备路径与资源条件。
10. 对共同事件，双方记忆可以不同；事实账本不能被语言模型篡改。
11. 闭关十年后，配偶、友人、长辈各自推进人生，没有暂停等待玩家。
12. 同一世界种子与相同行动可重演；更换天气或贸易延迟可引发新的关系轨迹。
13. 对胁迫、虐待、被剥削等敏感题材可启用过滤或摘要，不产生露骨场景。
14. 重大关系事件影响住房、身份、财务、继承、法律及社会评价，而非仅改一串文案。
15. 玩家死亡或换代后，已存在的NPC关系历史和私人自主权不会被清空。

## 14. 尚需通过原型验证的开放问题

- NPC心理状态究竟用多维连续参数、少量离散动机，还是混合模型？必须用可解释性和计算成本评估。
- 对话模型能否在本地设备稳定保持人物说话方式、已知事实与长期记忆一致？先不依赖大模型即可验证行为规则。
- 不同王朝的婚制、继承、女性财产权、社会自由度如何参数化，避免同质化和现代观念粗暴套用？
- 玩家控制多世人物时，是否能访问前世已知但本世不知的秘密？默认不能直接继承全知视角，除非留下书信/遗产等传承媒介。
- 敏感话题的可控呈现级别、年龄分级与地区法规须在发布前评审。

**结论**：我们要做的不是「恋爱剧情越多越好」，而是让一段关系的出生、延续、伤害、修复和消逝都受到同一世界规则约束；真实感来自双向人格和共同历史，而不是亲密行为奖励。
