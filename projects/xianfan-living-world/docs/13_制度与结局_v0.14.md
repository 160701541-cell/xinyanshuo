# 制度、吏治与结局（v0.14）

> 一句话：制度定贪腐与执行力，贪腐定税能不能收上来，收不上来就赈不了灾、发不出饷，最后落到一个结局上。

## 一、六条杠杆

| 制度 | 选项 | 主要代价 |
|---|---|---|
| 监察 | 不设 / 按察司 / 按察+连坐 | 连坐压贪最狠，但掉合法性、得罪人 |
| 律法 | 宽简 / 律令 / 严刑 | 严刑提效率、涨民怨、掉合法性 |
| 选官 | 察举 / 科举 / 世袭 | 科举压贪提效，阻力最大（6） |
| 田制 | 私田 / 均田 / 官田 | 均田降民怨但减税、阻力大；官田易生贪 |
| 军制 | 征兵 / 募兵 / 军户 | 募兵强兵但吃税；军户稳定但助长贪腐 |
| 税制 | 轻赋 / 常赋 / 重赋 | 重赋进钱，直接抬民怨、掉合法性 |

每条选项只改**目标值**，实际贪腐/执行力每天只向目标靠近 18%——改制不会当日见效。改制还有**阻力**：阻力越高，合法性掉得越多、官员越会阳奉阴违。

## 二、环环相扣

```
制度 → 贪腐 / 执行力 → 税入 → 府库 → 赈济与军饷 → 民怨 → 合法性 → 结局
```

- 贪腐直接进 `market`：税入按 `(1−贪腐)` 抽成；并且**贪腐本身每天 +18×贪腐 的民怨**（税被吞，百姓只看到结果）。
- 朝堂办事折扣再乘一层制度效率：`(技能−贪墨) × (0.6×执行力 + 0.4×(1−贪腐))`。
- 合法性随民怨下跌，民怨低时缓慢回升。

## 三、五种结局（`outcomeOf`）

| 结局 | 条件 |
|---|---|
| 盛世 | 合法性 ≥80、贪腐 ≤10%、民怨 ≤20 |
| 中兴 | 合法性 ≥65、贪腐 ≤16% |
| 苟安 | 其余情况 |
| 腐败崩解 | 贪腐 ≥35% 且民怨 ≥50 |
| 民变 | 民怨 ≥85 |
| 府库崩溃 | 府库为负 |

## 四、实测对照（24 日，晴旱交替，同一份人口与府库）

| 政体 | 贪腐 | 民怨 | 府库 | 结局 |
|---|---|---|---|---|
| 廉政（连坐+科举） | 0.1% | 53 | 7,515,593 | 苟安 |
| 腐败（不设监察+世袭+重赋） | 35.8% | 100 | 7,354,794 | 民变 |

注意民怨 53 仍来自旱年粮价——**清廉政体也挡不住天灾**，只是不会 concurrently 崩。

## 五、未做

- 制度只有六条，没有官职编制、俸禄、考成、回避、丁忧这些细目。
- 没有派系与党争，阻力是一个数，不是一群会反击的人。
- 结局是即时判定，没有“亡国后的下一局”。
- 未上安卓实机。
