> **工程边界**：仅写入公开仓库的仙凡独立分支；不修改《苍岚·人生世界》main、Godot原APK/RSA/PCK，也不修改WorldBox MOD。文本世界可以吸收苍岚理念，但不能把不同游戏的存档、人口与发布状态混为一谈。

## 1. 设计目标与叙事铁律

1. 一人一生，一界众生；主角没有剧情免死、无限背包、无限运气、必得机缘。
2. **先有凡人社会，再有修仙社会**：出生家庭、粮食、地租、户籍、道路、行政、贸易、家族和军队能够独立运作；修行是稀缺且有代价的社会流动路径。
3. 国家、宗门、家族、行会、散修、妖兽不是静态背景：都拥有资源、产权、领地、人物和行动目标。正道/魔道门派标签不等于个人道德判决。
4. 世界时间只在玩家指令结算时推进；推进的游戏时段里其他地区也进行可复算的统计模拟。无自动化执行器时，不宣称聊天之外正在实时运行。
5. **玩家知识≠主持人全局真相**：玩家看到的是已知、推测、传闻；隐藏根性、情报来源、暗线及未触发人物动机保存在GM私有状态，不公开在HUD。
6. 每次数字变化有账本交易或规则事件；没读取真实存档不能补造结果，文本描述不能越过规则引擎直接授予物品/境界。
7. NPC固有ID、生卒、家庭、出场记录、信誉、债权债务、记忆稳定。已发生事实不可为了迎合新剧情逆改。
8. 本文件规定**世界中允许有什么**与**应如何计算**，不保证分支内旧版本已经实现这些系统。

## 3. 天地结构：一个下界、众多灵境、上位界面

### 3.1 凡界（初始主舞台）
凡俗居民与低中阶修士生活在同一世界大陆。凡界不是“全无灵气”，灵气强度沿矿脉、河谷、山脉、地火等地理结构变化。皇权依靠土地财政、军政体系、官修、护国供奉与禁制自保；宗门依靠灵地、功法、丹器、招徒、世俗供养与势力外交存续。两者既可能合作也可能冲突。

### 3.2 灵境/洞天
可在同一世界中由阵法、裂隙、秘境、洞府进入；本质为有资源预算和法则约束的独立空间，不能随意免费传送或刷新灵宝。入口、位置、开启时间、争夺、消耗与外部时间流速需建档。

### 3.3 上位灵界（远期）
比下界更高灵气浓度、更复杂灵族/妖族政体和天地法则；并不直接把下界的“青云山”换一张贴图就叫灵界。跨界需空间节点、法则条件与穿界成本；落脚风险、语言/族群/灵气环境差异真实存在。**现有分支尚未实现可游玩的独立灵界**。

### 3.4 仙界（远期）
飞升后仍有阶序、组织、资源税、规则冲突和寿元/天劫相关机制；不是开启无敌模式。设真仙、金仙、太乙、大罗、道祖为**未来设计谱系（需独立平衡，不代表现有代码已经支持）**。**尚未实现**。

### 3.5 幽冥/地府（独创远期）
死者不自动保留完整意识。神魂残留、转世、鬼修和冥司属于罕见且需要因果、法术、地域与资源条件的规则。不得因加入地府就使死亡账本失效。**尚未实现**。

## 5. 修炼路线：凡人也有上升通道

**正统灵修（大境界）**：凡人 → 炼气（1—13层，正式游戏参数）→ 筑基（初/中/后/圆满）→ 结丹（初/中/后/圆满）→ 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 飞升劫（事件，不作为可刷的常规等级）→ 真仙 → 金仙 → 太乙 → 大罗 → 道祖（后五阶仅世界观远期谱系）。

**武道/炼体**：锻皮 → 炼筋 → 淬骨 → 换血 → 通脉 → 先天 → 宗师 → 大宗师 → 陆地神仙。此列为本游戏自创玩法路径，**不宣称是《凡人修仙传》原著境界**；体修与法修可兼修，但人体负荷、资源、寿元和职业成本均需叠加结算。

**妖修**：启灵 → 聚灵 → 凝丹 → 化形 → 妖婴 → 妖尊 → 后续妖道劫数。并非凡人灵修的机械换名；受血脉、栖息地、种族寿命及智识发展约束。

### 5.1 参考寿元（世界观参数，不是原作定数）
凡人80—120年；炼气约120年；筑基约240年；结丹约520年；元婴约1100年；化神约2200年；炼虚约4500年；合体约9000年；大乘约18000年。寿元是**平衡初始上限参考**，须因种族、伤势、资质、药毒、血脉和寿元秘法变化；不保证人人能活到上限。仙阶不预定无穷寿元。具体生命机制不能用这些目标值直接改写已创建人物的死亡时间。

### 5.2 灵根、体质与资质
- 人的灵根属性由金木水火土以及风、雷、冰等可能的变异向量表示；“单、双、三、四、五”表示属性构成数量及纯度，天灵根、异灵根等需分开定义标签与权重，不能同时重复抽取相互矛盾的分类。
- 灵根在出生事件时使用持久化的确定性种子/随机状态一次锁定，支持血缘倾向但**不保证遗传**；玩家检测之前HUD仅“未检测”。禁止为了剧情好看重抽。
- 无根性者可走武道/工商业/政务/军政/医术等重要人生道路，禁止把其设定为“没有意义的NPC”。
- 身体资质独立包含经脉容量、神识、悟性、体质、抗药性、伤势与隐疾；稀有根性≠必定筑基。

### 5.3 修行计算的权威链
可修行=持有可学功法＋满足根性/境界/体质条件＋可用地点＋时间。修为增长受相性、灵气浓度、周天功法效率、心境、药物或灵石投入、经脉负荷影响。必要物品从同一库存真实扣除。瓶颈需完成准备、机缘和风险检定；失败可造成反噬、寿命损耗、修为退化或死亡（按明确规则记录）。闭关期间其他NPC照常按世界时钟结算。突破概率不可临时瞎编，必须有算法版本和种子记录。

### 5.4 飞行
御器/御剑能力必须具有具体术法、装备与可用灵力；筑基是本作正常开启正式御器飞行的候选门槛。炼气不因“修士”标签自动飞行。城市禁空、大阵、室内、伤势、负重、距离与神识都可限制飞行；飞舟消耗灵石或燃料且载具有所有权和库存。

## 6. 凡界政治、宗门与修真社会

- **凡俗权力**：皇帝/官府/宗族/军营的合法性源于制度、土地、民心、财政、军队和组织；修士很强，但不等于获得县令任命权。
- **仙门权力**：传承、护山阵、灵石、灵田、药圃、丹炉、法器、外门内门、师徒与宗门贡献构成硬约束；弟子仍需吃住/供给，不因入门而免工资与后勤。
- **阶层关系**：凡人村民、帮工、手艺人、散修、宗门杂役、外门、内门、亲传、执事、长老、掌门等身份及其权限由社会规则和任命决定，境界不是职位。
- **修行市场**：灵石面额、兑换汇率、材料品质、鉴定、税费、传承价格、拍卖和流通风险并行；不能把灵石简单当铜钱自动无限兑换。
- **势力并非善恶判词**：web/dao.js的立场用于预测利益和声誉，不是道德全知。杀生与复仇涉及证据、官法、族仇、门规、业力等多种不同系统；不得将“某人是魔修”自动等同于无因可杀。
- **强者限制**：不同界面有灵气压制、天地法则、势力守卫和空间通行成本。低阶人物可以通过人情、组织与外交影响高阶事件，但不赠予无因战力。

## 7. 物品、产业链与工序

统一物品链：自然资源节点 → 采集/开采 → 玩家或NPC背包 → 运输 → 仓储 → 加工 → 半成品 → 成品 → 贸易/使用/维修/报废。物品定义不可变模板ID和可变实例ID/所有者/数量/重量/品质/耐久/批次/来源事件。制作必须有图纸、技能、工位、耗时、能耗、材料与失败产物。

**修行物品分类**：
- 灵石：下、中、上、极品；出矿、鉴别、净化、流通与储能损耗，交换比非固定神价。
- 灵植：种子、幼苗、成熟株、药龄、地块、再生、枯死与药性；采尽可用量不代表整个物种灭绝。
- 丹药：草药＋辅料＋炉具＋火候＋时间 → 成品或药渣，丹毒/抗药性有累计。
- 符箓：纸/皮、灵墨、符笔、刻写技能、法力封存、使用次数。
- 法器法宝：矿材、器胚、阵纹、祭炼、维修、折损；死亡遗物不自动传送到玩家包里，先看现场可达性及持有者。
- 功法/玉简：师承、秘籍真伪、残篇缺陷、功法契合、阅览地点与借阅权。
- 灵宠/妖兽材料：真实兽群、栖息地、成年体型、掉落取决于击杀/解剖/拾取等可核对行动。

## 8. 生态、医药与妖兽

树林、灵草、野兽、妖兽、矿脉、灵脉和水土先于玩家存在。自然生成节点允许按地图生态种子/周期产生，**但不得直接往人类仓库里无因增物品**。林木有树龄和成活率；草药有药龄、季候、病虫害和采收窗口；矿脉有地下储量与露头速度；兽群要觅食、繁殖、迁徙、战斗和死亡。高阶妖兽出现在凡人集市应有可追查的突发原因。宗门采矿、凡人烧炭、灵石争夺会影响生态与民生。

## 9. 机缘、秘境与因果

洞府、灵谷、古战场、妖兽巢、地火窟等采用稳定seed+入口坐标+开放条件+遭遇表+库存+探索记忆。秘境宝物可被NPC先行取走；一次性资源不因重复进入而刷新。夺宝、伏击、反杀、交易、师恩、契约和宗门追责都生成跨年月的真实后果。死亡可能是故事终点，转世、夺舍、鬼修须通过极罕见专门规则，不能免费重置。

## 10. NPC自治、家庭与社会记忆

每个实际出场NPC有ID、姓名、年龄、出生地、性别、家庭、财产、婚育、职业、技能、伤病、根性隐藏值、合法知识范围、态度、意图、时空位置、事件参与记录。NPC局部精确模拟/远景聚合模拟在账本上只算一次人口。见过谁、欠谁、与谁结仇等长期记忆不因离开屏幕丢失；传闻附可信度与来源，NPC不能获得未发生的情报。婚育在合法社会关系、年龄、妊娠/生育与养育条件下结算，不能凭空添加数十代子孙。

## 12. ChatGPT文字战役执行规范

- 只在用户输入了行动且成功结算后推进时间；无意义的“查看状态/背包/地图/日志”零时间。
- 游戏旁白与NPC对白按人物知识和时空生成，不提前披露NPC的隐藏动机或玩家未测灵根。
- 采用chat内可点开的交互表格显示当前状态、背包、人物、地图、家族、线索，最后放**主持连续性备忘**；每回合只呈现新表，旧表不声称可实时更新。
- 存档分三层：权威可复算state+事件账本；玩家已知的NPC、情报、线索索引；仅GM可见的隐藏信息及可能剧情方向。未知动机不能混入事实。
- 回合事件应记录ID、游戏时间、人物ID、起止地点、检定公式与seed、物品/金钱/伤势前后值、NPC记忆更新、是否验证。
- 严禁让LLM单凭叙事改写真实库存、灵根、境界、时间、亲缘与死者身份。
- 游戏进行中的隐藏设定、将来分支构思只做待激活候选，不得替玩家决定。
- 当前会话恢复时优先读取最新游戏档案；本说明和原始文档都是规则来源，**不能取代真实存档**。
