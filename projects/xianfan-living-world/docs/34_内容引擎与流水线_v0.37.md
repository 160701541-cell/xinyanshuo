# 流水线：玩法是数据，不是一个个 if

前面几十个版本都是“加一个玩法 = 写一段代码 + 加一个按钮 + 补一条测试”。这轮把这套反过来：**加玩法 = 往 `content/` 里加一条数据**，引擎负责校验、触发、记账、出文档。

## 一、引擎做了什么（`engine.mjs`，engine-0.1.0）

| 概念 | 写法 | 说明 |
|---|---|---|
| 条件 | `{path:'w.player.silver', op:'gte', value:100}` | 支持 all / any / not 组合；`ctx.xxx` 取调用时上下文 |
| 运算符 | truthy/falsy/eq/ne/gte/lte/gt/lt/has/includes/mod | 未知运算符直接校验失败，不会静默不触发 |
| 后果 | `{do:'add', path:'price', by:6}`、`{do:'note', text:'…'}`、`{do:'flag'}` | 加减、赋值、记事、标记；未知效果校验失败 |
| 钩子 | `daily` / `travel` / `kill` | 一天最多爆 6 条，免得刷屏 |
| 频率 | `once` / `cooldown: N天` | 引擎统一记 `w.engine.fired`，写存档跟着走 |
| 卡片 | `{fields:[{key,label,when}], actions:[…]}` | 界面只摆行，不自己挑字段 |

## 二、怎么加一条新玩法（现在是三步，不再改代码）

1. 在 `content/rules.mjs` 里加一个对象（写 `id/hook/when/then`）；
2. 跑 `node tools/content-lint.mjs`：校验 + 连过 180 天试跑；
3. 跑测试、`node tools/build-web.mjs` 出包。

`tools/content-lint.mjs` 会自动生成 **[内容清单](33_内容清单.md)**（规则表 + 卡片模板），文档也是产物，不用手写。

## 三、这一版实际接进去的 10 条规则

旱年粮价、流民劫道（一次性触发 + 之后每十天）、宗门抽灵力、东市赶集、族产见底卖地、疫气入城、州府记名、路上遇乡人、业力缠身警示。全部只有数据，没有新增一行 UI 代码。

## 四、接线

- 地图循环里：跨天跑 `daily`，到达目的地跑 `travel`；两处都不超过三行代码。
- 触发的记事直接进 `w.history`，所以「纪事」页不用改就能看到。
- `build-web` 会自动把 `content/*.mjs` 编译进 `web/content/*.js`——新增内容文件不用改构建脚本。

## 五、验收

- `node tools/content-lint.mjs` → `10 条规则 / 3 张卡片 / 试跑 180 天触发 15 次`
- `node --test tests/*.test.mjs` → **195/195**
- 新增 7 项引擎用例：全量校验、未知运算符/效果被拦、条件组合、效果与模板、once/cooldown、钩子隔离、卡片按条件出字段。

## 六、还没做

- 规则还没有权重与互斥（现在按数组顺序，最多 6 条）；
- 没有“玩家可见的因果说明”（为什么触发这条），只有纪事文案；
- 卡片模板还没接管现有的 POI 卡与人物卡渲染，目前是引擎侧能力 + 测试；
- 内容没有版本迁移：改规则 id 会让老存档的 `fired` 记录对不上。
