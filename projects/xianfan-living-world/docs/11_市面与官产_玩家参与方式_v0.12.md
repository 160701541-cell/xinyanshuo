# 市面、官产与玩家的具体玩法（v0.12）

## 一、循环本身

每过一天，世界自动走一圈：
**天气 × 收成 → 供给 → 价格 → 民怨 → 税收入库 → 府库 → 军费与赈济 → 能否打得起仗**

玩家不在这条链外面，而在链上占一个位置：你的身份决定你能拉动哪一段。

## 二、三种身份，三种玩法

| 身份 | 你能做的 | 你看得见的代价 |
|---|---|---|
| 皇帝 | 定税、禁榷盐铁、下旨征发、拨赈济、修驿传 | 民怨、府库、军费；执行有折扣与贪腐 |
| 县吏 / 掌柜 | 开仓平粜、官府收购、定市价、放贷、招商 | 官仓余量、当月税入、粮价与民怨 |
| 小兵 / 平民 | 买卖、囤积、扛役、逃荒、从军 | 自家口粮、物价、征发令 |

同一件事，三种人做起来不一样：皇帝只能拍“禁榷盐铁”，具体收多少、按什么价卖给谁，是县吏与行会去执行，中间被贪腐抽一道（`corruption`）。这就是“各司其职”落到玩法上，而不是一句设定。

## 三、可操作的动作（已实现）

`market.mjs`：

- `releaseGrain(w, dan)` 开仓平粜：官仓减少、粮价下落、民怨缓。
- `buyToGranary(w, dan)` 官府收购：府库出钱、官仓变实、市价上行。
- `setTax(w, rate)` 定税 0–35%：税入立刻进府库，也在攒民怨。
- `setMonopoly(w, 'salt'|'iron', on)` 禁榷：每日进钱、抬价、抬民怨。
- `buildPost(w)` 修驿传：一次性花钱，长期抬供给、平物价。
- `tickMarket(w,{weather,harvest})` 每日结算：价格、民怨、税入、流民。

界面在「治理」页：五样物价与基准比、官仓、民怨、府库、税率，六个按钮直接动手。

## 四、数值示例（Node 实测）

- 连续十日：前七日晴、后三日旱，粮价 12 → 15.1，民怨 29。
- 开仓 8000 斗：粮价 15.1 → 9.8，民怨 29 → 0，官仓少 8000 斗。
- 官府收粮 5000 斗：花 4.9 万文，粮价回抬到 11。
- 禁榷盐：盐价 40 → 44.9，当日府库多进钱，民怨上涨。
- 民怨 ≥70：户口出走，记“流民”；≥85 记“民变”。

## 五、还没做

- 没有商人个体与商路（价格是全县一张表，不是逐店逐人）。
- 没有土地买卖、佃租、借贷违约链。
- 国有资产只有官仓与盐铁，没有矿场、船队、军械坊的独立账。
- 玩家身份切换仍是调试入口；正史里要考试/军功/世袭。
- 未上安卓实机。
