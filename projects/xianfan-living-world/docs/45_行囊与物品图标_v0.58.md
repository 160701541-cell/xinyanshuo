# 一眼看得出是什么：14 张物品图 + 格子化行囊

用户拿《深空当铺》的物品栏做参照：深色格子、每格一个认得出的物件、点开有价格与重量。

## 一、物品图标（`content/itemart.mjs`，itemart-0.2.0）

- 24×24 字符画，14 种：干粮、清水、兽肉、草药、刀剑、皮甲、铁矿、木料、石料、丹药、妖丹、兽皮、骨牙、符箓。
- 每种一张调色板（主体/暗部/高光/木土/点缀），统一 1px 描边，和地图、卡面同一支笔。
- 名字对图标：`itemIconId()` 先查中文别名（妖丹→core、精血→pill、妖皮→skin、朱果→herb、黄纸→talisman…），认不出来落干粮，不再落到石头。

## 二、行囊（原生）

- 深色底、4 列格子，每格：96px 图标 + 名称（带品阶，如「妖皮·下品」）+ 件数。
- 点一格：单价、重量、行囊总件数/总重/总估价、用途说明。
- 顶部显示「行囊 · N 件 · 值 X」；存读档带行囊（`bag` 字段，`id|品阶:件数;`）。

## 三、东西怎么进来

| 行为 | 进账 |
|---|---|
| 讨伐妖兽 | 妖皮/兽骨/兽肉按品阶掉落，境界越高妖丹、精血概率越大 |
| 伐木 | 木料 ×2 |
| 割草（体力低时） | 草药 ×1 |

## 四、验收

- `node --test tests/*.test.mjs` → **260/260**（新增 4 项：14 张图尺寸、中文别名、未知名兜底、SVG 非空）。
- CI：`native-apk` 在导出后用 rsvg 把 SVG 转 96px PNG 打进 assets/items（安卓不解码 SVG）。
- 预览：`docs/preview/bag-grid.png`（同源数据离线合成）。

## 五、还没做

- 行囊没有容量上限与超重惩罚；也没有堆叠上限、没有丢弃/交易入口（估价只显示，不能卖）。
- 图标只有 14 种，功法、兵器种类、防具细分还没有各自的图。
- 网页端尚未接同一套图标（先保原生包）。
