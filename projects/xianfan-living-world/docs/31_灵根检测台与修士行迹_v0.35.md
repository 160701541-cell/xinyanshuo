# 灵根得自己去测，修士得各走各的路

## 一、灵根检测台（沿用苍岚老规矩）

旧项目里的设定是：**没亲自去检测台测过，HUD 上就不显示灵根**。这一版把它接回来了：

- 检测点只有两处：**灵山药市**、**青云山门**（有灵脉、有法器）。在临安县城测不了，会提示去这两处。
- 测之前 `practiceReport().root === '未测'`，吐纳会被拦下（“你还没测过灵根”）。
- 测过之后才显示根性，并且**不能反复测**——一次定终身，和旧存档里“由种子与身份 ID 决定”的口径一致。
- 无灵根的人测出来照样修不了，这是设定的一部分，不是 bug。

## 二、修士不再都下山赶集

之前 96 名修士白天只有“出门/在家”两态，地点在四处里按 hash 取。现在按人分配行迹：

| 行迹 | 占比 | 去哪 | 说明 |
|---|---|---|---|
| 采药 | 30% | 灵山药市 / 松林村 | 带药锄，早出晚归 |
| 巡山 | 25% | 青云山门 / 灵山 | 绕峰、看护山门 |
| 游历 | 30% | 东市 / 西街 / 南门 / 客栈 | 下山见世面、采买 |
| 坐镇 | 15% | 自家洞府或落脚点 | 不出门 |

- 行迹按 `hashStr('role:'+id)` 定死，刷新、读档、换日都不变，玩家能记住“谁在哪儿”。
- 出门比例从 42% 提到 70%（坐镇的不算），街上更有人气。
- 实测抽样（9/13/18 时）：上午灵山 22 人、南门 12 人；傍晚各自回客栈/南门/东市。

## 三、验收

- `node --test tests/*.test.mjs` → **182/182**
- 新增断言：未测灵根不能吐纳、县城测不了、青云能测、不能重复测、报告显示“未测”。

## 四、还没做

- 检测台没有独立的场景/法器外观，只是地点的规则；要“走过去看见石台”还得等室内场景。
- 行迹没有“正在做的事”文字（现在只有地点），也没有采到药/巡山遇妖的产出与遭遇。
- 修士之间不互相拜访，也不会因为同门被害改行程。
