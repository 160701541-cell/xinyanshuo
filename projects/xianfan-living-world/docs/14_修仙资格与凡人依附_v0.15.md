# 修仙：灵根是天生的，供奉是钱买的（v0.15）

> 仙凡悬隔不是“凡人没天赋”，是**灵根稀有 + 灵气限位 + 资源世袭**三件事叠在一起。

## 一、灵根：资格本身就是抽签

| 灵根 | 概率 | 修炼速度 | 说明 |
|---|---|---|---|
| 天灵根 | 0.06% | ×5.0 | 百年一见，宗门抢人 |
| 单灵根 | 0.6% | ×3.0 | |
| 双灵根 | 3% | ×2.0 | |
| 三灵根 | 9% | ×1.4 | |
| 四灵根 | 18% | ×1.0 | |
| 五灵根 | 32% | ×0.7 | 能修，一辈子炼气 |
| 无灵根 | 37.3% | — | **绝大多数人，皇族也不例外** |

实测抽样 4000 人：无灵根约 36%，天灵根 0.15%（样本波动，长期趋近 0.06%）。

## 二、灵气：修士在哪儿，是地理决定的

| 地方 | 灵气 | 每万人修士数 |
|---|---|---|
| 临安县城 | 0.18 | 0.10 |
| 松林村 | 0.26 | 0.20 |
| 青云山门 | 1.00 | 3.00 |
| 灵山 | 1.35 | 5.47 |

县城修士密度不到山门的 1/30。**一个小县城没几个修士**不是设定，是这条公式的结果。

## 三、供奉：没有灵根也能灭宗门

`hireRetainer` 用府库的钱供养修士，价格 = 境界战力 × 300 文。

- 筑基（28）≈ 8,400 文/人
- 金丹（180）≈ 54,000 文/人
- 元婴（1200）≈ 360,000 文/人

青云山门战力 = 金丹（180）× 64 道众 × 0.6 ≈ 6,900。要灭它，供奉总战力需 ≥ 8,300——**大约 7 名元婴，或二十余名金丹**。

这就是你说的那件事：皇族自己一个灵根都没有，但他能养二十个金丹。**灭门看的是钱袋，不是灵根。**
