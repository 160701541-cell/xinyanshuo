# 2026-10-21 · v0.3手机实机问题 → v0.4地图交互修正

## 原用户指出的实机P0缺陷

1. 走在东市，但地面道路和房间都是同样的格子背景，缺乏街巷、墙、门、建筑结构之分。
2. 14:24等时间系统栏压住标题；需要真正适配安卓系统状态栏。
3. 深夜大量NPC站在街上并标记「在家休息」，活动逻辑与场景事实矛盾。
4. 点击地图空白道路不能行走，北边没法继续前进，无法自由往返。
5. 地图像一组地点按钮，不具备连续地理空间；不能从天下层级一路放大到县和街巷；进建筑后才应该转为室内场景。
6. UI太像测试后台、没达到成熟MUD的清晰度，地图不是主要操作界面。

## 本轮落地与验收证据

- `spatial.mjs` 包含道路格点、路网BFS、人物道路坐标、步行与入室入口，19个Node规则测试全部通过（**仅本地Node，无设备QA**）。
- `app.mjs` 将街道大图作为主要操作面板，支持直接点击道路、拖动地图、双指缩放、地图层级、点击建筑自动入内、室内结构独立。
- `style.css` 重排为独立全屏地图组件（避免反复滚动上百行地点卡片）；人物位于地图坐标，资料仅在点人物后出现。
- `CountyActivity.java` 使用父级FrameLayout承受systemBars inset，防止Android15/16强制edge-to-edge覆盖头部。此修复**尚需安卓16实机截图验证**。
- 计划构建版本0.4.0/versionCode4，包名与v0.3不变，保留公共演示证书。

## 下一轮不可回避的P0

- **县域道路连续化**：县城到村庄不能只有虚线与跳点，必须将官道、乡路、桥、渡口做成可选择任意路段行走的物理路网；支持跨区域连续坐标，无缝加载并按道路实际距离行走。
- **住房真正落到地图**：13,680个居民必须逐步关联到房屋、房间、田地与工作岗位；室内有人须有进入路径、停留时段、退出记录。
- **NPC行走可观察**：普通人的通勤需要通过同一个道路寻路器，而不是场景切换时计算静态替身、远距传送。个体工作、睡眠与实际坐标必须一致。
- **经济与生活**：赶集、摆摊、买卖、纳税、家庭餐食、店铺补货会改变真实库存与NPC动机，不应只是场景装饰。
- **高层地图**：不能把现在「天下」示意当成完整大世界；后续应建立可生成州县的世界地图瓦片、坐标、投影、地形与道路数据库，县域数据逐层接入。
- **真实UI质量**：手机目标分辨率、字体最小触控尺寸、地图缩放后标签密度、输入拦截、顶栏状态栏、地图定位与不卡顿；画面品质与MUD对照的可读性继续做实机迭代。

## 禁止误报

本轮不是13,680人全量高精日程系统，不是大宁全国/天下完整实体地图，不是每座房屋都可进入。不能把「Node单元测试通过」写成「Android实机地图验收通过」。
