# 图标不再一张张画：按名字查表，查不到就画脸

卡片上原来只有文字。现在每张卡左边有一个 16×16 的像素图标——**不是画出来的，是流水线查出来的**。

## 一、怎么判断“这是什么东西”

`content/icons.mjs` 里三件事：

1. **13 张 16×16 字符画**：`inn / kitchen / office / grain / forge / herb / school / temple / gate / dock / well / field / generic`，每张用 `0`（背景）`1`（主色）`2`（深色）`3`（亮色）`4`（点缀）写字；
2. **5 套配色**：建筑（朱漆木）、水（青）、草木、商（赭）、工（铁灰）；
3. **`iconIdFor(name)`**：先整名精确命中 → 再按“包含且最长”匹配别名 → 都不中落 `generic`。

所以：`望江客栈` → `inn`；`官厨 / 厨房 / 后厨` → `kitchen`；`县衙` → `office`；`铁匠铺` → `forge`；`灵山栈` 这种没见过的名字 → `generic`（不会崩，也不会画错成客栈）。

## 二、人物也能画

`personIcon(person)` 按 `job` 与 `sex` 现画一张 16×16 头肩像：衣色分官/商/农/修士/杂役五档，女性加发髻、男性戴巾。所以**没有立绘的 NPC 也有脸**，且和建筑图标同一套渲染（`drawIcon` 画 canvas，`iconSVG` 出图给文档）。

## 三、卡片怎么拿到图标

`cardView()` 里加了一句：

```js
const icon = t.kind === 'person'
  ? personIcon(local.person || local)
  : iconFor(local.iconName || local.name || '');
```

模板只需要声明 `icon: 'by-name' | 'by-job'`，界面把 `iconSVG(view.icon, 56)` 塞进卡片左上角（`image-rendering: pixelated`，56 是 16 的整数倍，边不会糊）。

预览：`docs/preview/icon-cards.png`
