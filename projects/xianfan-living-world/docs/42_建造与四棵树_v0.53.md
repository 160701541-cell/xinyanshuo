# 从砍树开始：建造、合成树、科技树、兵种树、功法树、锻造

## 一、开局的第一件事不是打架，是凑材料

- 伐木：一趟 1.5 时辰，+3 木，体力 −8
- 割草：一趟 45 分钟，+5 稻草，体力 −5
- 偷草：一次 +12，但四成概率被田主逮住，罚 20 银、业力 +2
- 帮村长干活：**没有工钱，但管饭管住**——气血 +30、体力 +60，捎回 8 捆稻草

茅屋 = **10 木 + 50 草**。按上面的产出去凑，正好是“砍四趟树、打五回短工、再割两趟草”的量。
