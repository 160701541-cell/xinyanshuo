# 一张地图，两个世界；一套业力，决定谁敢滥杀

## 一、凡界和修仙界不是两张图

之前做成了两张同尺寸的地图，那是错的。现在只有**一张世界图**：1296 块地铺满 729 万平方公里，
每块地自己带一个 `domain`：

- `mortal`：县、田、山林、湖泊——凡界的编户齐民；
- `cultivation`：灵脉、药山、妖兽域、灵泉、宗门领地——灵气浓的地方才成修仙界。

域的划分由灵气场 `qi` 决定，阈值 `DOMAIN_QI=0.68`，实测**修仙界占 19.1%，凡界 80.9%**。
所以修仙界是**散落在凡界里的口袋**：临安县城周围是凡界，往东走几十里才进灵脉。
`realmView(world,domain)` 只是把另一界留白，坐标不动——不是另一张地图。

## 二、业力：杀修士与杀凡人不是一个价

| 情形 | 业力 | 掉落 |
|---|---|---|
| 杀修士（同类相争） | +2（杀宗门弟子再 +2） | 灵石 2–8×境界、35% 丹药、18% 法器、25% 符箓 |
| 杀无辜凡人 | **+14**（有人看见再 +3） | 只有几串铜钱 |
| 有理由杀凡人（亲眷/友人被杀、护人、受辱、执法） | +1 | 同上 |
| 杀该杀之人（通缉、恶名） | **−3**（除害） | 同上 |

这就是"杀几百个无辜修士，比杀几百个该杀的凡人强"：修士那一刀有货，凡人那一刀只赔。

## 三、业力怎么咬人

段位：清净(0–9) → 微染(10–29) → 业力缠身(30–59) → 业力深重(60–119) → 天怒(≥120)。

突破成功率 = 基础成功率 ×(1 + 段位惩罚)，惩罚依次 0 / −8% / −24% / −42% / −62%；
≥60 附带**心魔**，≥120 附带**天劫**；突破失败再 +6 业力——越怕越难，越难越怕。
