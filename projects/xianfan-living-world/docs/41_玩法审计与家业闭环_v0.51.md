# 玩法审计：修炼、钱、家、房、人、王、宗

这一轮先审，再补。审计脚本按玩家视角跑，结果如下。

## 一、审计结果（修复前）

| 问题 | 实测 | 判定 |
|---|---|---|
| 能不能修炼 | 县城 `detectRoot` 直接拒绝（要灵山/青云），`practice` 报“未测灵根” | 能修，但**开局没有引导**，玩家不知道要去哪 |
| 钱从哪来 | 委托能接（139 文一张），但没有“每天能做的活”；`contractsFor` 的 `reward` 是对象，直接读会拿到 `[object Object]` | **断**：没有稳定现金流 |
| 家在哪儿 | `player.home` 不存在；客栈住店也没有接口 | **断**：无住处、无恢复手段 |
| 房子怎么修 | 建筑全是布局时生成的，玩家不能盖 | **断**：无建造 |
| 建筑/场景怎么来 | `buildings.mjs` 固定生成 + 卡牌 `scenes.mjs` 按名字出图，玩家不参与 | 只能看，不能改 |
| 怎么招募 | `recruitCapacity` 要身份解锁，未入道时上限 0 | **断**：开局招不了人 |
| 自立为王 | 没有任何接口 | **断** |
| 自建宗门 | 没有任何接口 | **断** |

## 二、这轮补的：`life.mjs`（家业）

一条从“活着”到“有一方”的链路：

| 环节 | 接口 | 代价 / 条件 |
|---|---|---|
| 住店 | `stayInn(w, days)` | 30 银/天，回气血 45、体力 60 |
| 置宅 | `buyHouse(w, 'room'|'house'|'yard')` | 420 / 1500 / 6000 银 |
| 加盖 | `upgradeHome(w)` | 900 / 3600 银，上限三级 |
| 打工 | `workDay(w, job)` | 脚夫 12、账房 18、采药 20、护院 25 银/日 |
| 卖货 | `sellGoods(w, id, n)` | 按标价六成回收 |
| 养人 | `hire(w, n)` | 45 银/人；上限 = 住处等级（2 / 6 / 14 / 30） |
| 立宗 | `foundSect(w, name)` | 筑基、3000 银、50 灵石 |
| 收徒 | `takeDisciple(w, n)` | 120 银/人，弟子每年缴 3 银 |
| 称王 | `takeThrone(w, title)` | 县令、60 兵、名望 120、20000 银 |

新增 7 项测试（住店回血、打工与体力、宅子与招人上限、加盖、立宗三条件、称王四条件、卖货六成）。

## 三、仍然缺的（下一轮）

- 修炼的引导：开局应当在县衙或东市给一句“往西 40 里是灵山”，而不是让玩家撞墙。
- 建造是“买现成的”，不是“选地块、伐木、请工匠、看着盖起来”。
- 宗门只有人数与缴银，没有山门、护山大阵、招收弟子的资格筛选。
- 称王后没有税制、吏治、军队与叛乱；`tickLife` 的税收只是 0.02 的粗算。
- 家业与战争、家族、商队之间还没打通（打仗抢来的地不能算自己的）。
