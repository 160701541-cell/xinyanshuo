# 卡牌背景：按名字判断“这是什么”，再拼一张场景

上一版把图标塞在卡片左上角，只有 16×16，太像徽章、不像画。这一版改成**整张卡片的右侧背景**：宽 46%，铺满卡片高度，文字压在同一张卡上。

## 一、怎么判断

`content/scenes.mjs` 沿用 `iconIdFor` 的思路，但目标是整张场景：

1. 12 个场景构造器：`inn / kitchen / office / forge / herb / gate / dock / field / school / temple / house / generic`；
2. 每个构造器用积木拼 64×40 的像素画：`roof()` 出上窄下宽的瓦顶 + 屋脊 + 檐口 + 翘角，`window()` 出窗棂，`banner()` 出幌子，`lantern()` 出灯笼，`person()` 出三两个小人；
3. `sceneIdFor(name)`：整名 → 最长包含 → `generic`。

举例：`望江客栈` → `inn`（两层楼、腰檐、金匾、两只灯笼、两幅幌子）；`官厨` → `kitchen`（灶台、大铁锅、灶火、蒸汽、烟囱、挂着的干货）；`临安县衙` → `office`（堂屋、匾额、门钉、两杆旗、阶前差役）；`铁匠铺` → `forge`；`灵山药圃` → `herb`；`南门` → `gate`；`渡口` → `dock`。

## 二、卡片怎么用

- `cardView()` 返回 `scene`；**人物卡不画场景**，只给头像（人不像房子，硬套场景会假）。
- 界面把场景出成 SVG data-URI，铺在 `.sheet-art`（右侧 46%，`background-size:cover`，`image-rendering:pixelated`）。
- 文字区带一层纸色渐变，和画接缝处自然过渡。
