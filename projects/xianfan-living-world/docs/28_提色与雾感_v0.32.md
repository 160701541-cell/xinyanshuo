# 为什么之前“雾蒙蒙”：不是没画清楚，是颜色本身就是灰的

## 一、病灶

旧色板几乎全是**低饱和的灰土色**：

| 用途 | 旧值 | HSL 饱和 |
|---|---|---|
| 民居屋顶 | `#8a7d68` | 13% |
| 商铺屋顶 | `#7d6b52` | 21% |
| 夯土院墙 | `#b3a288` | 24% |
| 街面 | `#c9bda0` | 21% |
| 草地 | `#a9b184` | 25% |

单看每一块都能接受，但整张地图铺开全是 15–25% 饱和度的灰绿灰黄，
眼睛收到的就是一层雾。**这不是对比度不够，也不是描边太细，是色相全部挤在灰黄区间。**

## 二、改法

1. **按材质分屋顶**：官府青瓦 `#54687e`、粮行灰瓦 `#78684e`、民居木瓦 `#8a6242`、商铺赭瓦 `#a86c33`、茅草 `#c99a45`。
   民居屋面按确定性种子在「青瓦 / 木瓦 / 茅草」之间分配（殷实人家青瓦，寻常人家茅草），一排房子不再是一模一样的色块。
2. **地面分四档海拔色**并整体提饱和：`#8fc09a`（湿地青）→ `#9fbb60`（平原嫩绿）→ `#b3bb5c`（丘陵黄绿）→ `#96a05e`（高地褐绿）。
3. **城外铺田块**：175 米格子、确定性噪声决定有无，四种田色（`#c6c84c`/`#b0c246`/`#d8c85e`/`#9fbe52`），城内 820 米内不铺。
4. **水系换色**：河道 `#4f93b8` + 高光 `#8fd0e0` + 两岸湿土 `#7f9c6c`，不再是灰绿蓝。
5. **树的明暗分开**：`#3f7f3a` 主体 + `#6fa854` 受光面。
6. **兵种衣色**：步卒 `#4f6ea8`、刀手 `#a2703f`、弓手 `#71903f`、弩手 `#5f7f4a`、轻骑 `#b25b3e`、修士 `#7f6fd0`；
   阵营色仍然保留为**士兵底衬**（左蓝右红），兵种色画在身上，战场上两者都能分辨。

## 三、验收

- 平均饱和度（HSV 的 S 分量，300×300 采样）：**0.199 → 0.350，+76%**。
- 对比图：`docs/preview/palette-compare.png`（左旧右新）。
- 测试 163/163 全绿（色板只影响渲染，不改任何数值逻辑）。
- 同一份 `ART` 色板同时供游戏画布与预览工具使用，避免预览好看、游戏难看。

## 四、还没做

- 没有昼夜/天气调色（黄昏、雨天、雾天应该是真的滤镜，而不是把色板调灰）。
- 屋顶只有两坡两向，没有真正的瓦垄与苔痕。
- 没有真机截图：本机无浏览器，对比图与游戏共用同一份色板与布局数据离线渲染。
