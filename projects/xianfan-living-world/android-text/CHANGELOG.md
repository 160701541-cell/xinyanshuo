# CHANGELOG

## 仙凡共生 · 宗门世俗生理与衣食经济（2026-10-26，研发分支）
- 修正宗门人口结构：不再把宗门视作一群无需饮食的仙人。从原有336位具名县域居民中，依法识别18位山门实际雇工/役仆及4位求道见习（见习暂不享受雇工免费口粮）；保持各自原有身份ID、职业和未验证灵根，另有12位先前已登记的修行者样本（其中8位住山门）。
- 正式接入`scripts/sect_living.gd`：炼气者、未辟谷者及凡人均需实际饮食、卫生和住宿；筑基（境界>=14）必须有真实服药或认证辟谷术才能免基本进食和通常生理需求。服用辟谷丹须自己持有实物，生效3个世界日；辟谷术每天消耗本人灵力，不够则恢复普通需要。
- 个人喜好与辟谷资格独立：已辟谷者仍可选择享用灵米灵果羹等真食物；膳食只改变生活体验/心情，不能直接捏造修为进阶。灵田消耗地力/泉水，灵果来自可登记果树，烹调耗真实米果泉水并把厨师实名写进历史。
- 县城→山门粮食继续走原有真实库存、付费脚夫、运输延迟；山门凡人由山门粮库供膳，原家乡账本停止给相同雇工重复发工资和配餐。每日工资由山门自己付，没钱形成欠薪，连续七天欠薪的雇工会真实离职而非被当作永久背景数据。
- 已有真实丹方的丹房学徒，在技能达标并满足原料和工期时可炼制有数量、有时效的辟谷丹；申请领取仍需资格、山门核准、实物药库扣除。旧存档不擅自授予未知的丹方知识。
- 剧情库由32话题666变体增加至40话题874变体，新增凡人雇工/役仆独立话语风格、辟谷、如厕卫生、师门阶层、仙凡贸易与灵膳等；本人辟谷状态从权威人物生理账本查询，不能由AI自称。
- 灵兽宴席仅作为锁定配方列于`data/sect_living_v1.json`，**未开启烹饪**：必须先有真实灵兽实体、合法猎获或宰养、实物加工、运输与厨师，不能将活的野生灵兽数量直接当肉食。
- 新增`tests/test_sect_living.gd`与独立GitHub Actions质量闸门，校验双重口粮扣减、筑基辟谷资格、丹方技能及材料守恒、厨师真实身份与人员去向。
- 范围说明：当前仍是JSON结构化剧情数据、世界主存档和JSONL永久事实历史，不是已完成SQLite迁移。筑基及更高完整突破、宗门供求长期平衡、奴契/赎身法律、灵兽实体狩猎和手机GPU本地大模型性能仍未完成实机验收；绝不以此批代码标称“整个仙凡世界完成”。
