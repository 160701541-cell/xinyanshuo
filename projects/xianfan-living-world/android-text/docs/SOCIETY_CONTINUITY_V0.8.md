# 仙凡·苍岚 v0.8 — 自主社会第二阶段：跨区商路、亲属互助与市场供需

## 背景

上一版拥有24名有职业与日程的NPC，以及区域粮/鱼/木/药/器材和钱库。过去的局限是：两地区没有实际贸易联系、买粮价格固定、家人之间也没有真实资源援助，NPC说话并不能反映职业经历。本期继续推进「玩家只是社会成员」，而非增加装饰性剧情。

## 本次实质实现

- **同账交易**：所有消费者和玩家使用同一个 `regional_price` 规则，按粮鱼库存实时给出价格。以供需余量决定波动；不允许NPC说一句话就修改价格、产出财产。
- **跨区货运**：两条物理商路，石桥村鱼货送县城，县城器物送村中。只有原仓有货、目的钱库有钱才可发车。发货时起点仓库扣库存，货存NPC脚夫的 `cargo`，经8游戏小时走官道抵达；交割时扣目的地钱库、增源地钱库、入目的地实际库存；如果无法付款则在途中发起8小时回程，货到原仓后才重新计入。
- **同户互助**：按地区为24位具名居民分配同住户，记录而不臆造夫妻关系；晚间若同户居民缺粮，且亲友确有多余口粮，则真实扣除一方的一份并增加另一方一份，写入可见社会事件。
- **个人目标变化**：NPC每夜依据自身粮食、财富、职业、押运货物和工作经历调整愿望；这只是事实驱动的生活意愿，不是结婚生子或修仙突破的伪功能。
- **玩家亲身参与**：玩家可从石桥村家中步行12分钟到街口，检查牌价，像居民一样买粮、卖鱼、打零工，与有真实职业的公共NPC聊天，再步行12分钟回家。跨区没有瞬移。
- **内存与AI**：把目标NPC与最多6个附近NPC、最近4条社会事件及必要货价送进本地8B；其他NPC长期经历无损保留在独立本地记忆库；避免24份全员状态都进入每轮上下文。
- **原始历史**：居民的每日活动快照归入单独的永久NPC生活档案，仍保留身份、职业、习惯等稳定信息。区域最近事件是有限UI滚动窗口，不冒充完整历史账本。

## 真实性与性能边界

- 宏观生产目前依赖两个区域的集体农业账本与24名具名NPC，而不是已经逐个模拟1.8万城民。
- 商路当前只有两条可计算货线，且没有贸易税、损耗、强盗、驿站住宿、道路封锁和物流合同。不应宣称已经实现完整的贸易网络。
- 同户援助 ≠ 婚恋婚育；结婚、出生、死亡、财产继承需要专属事件与资产转移规则。
- 当前NPC基础角色由职业日程驱动，还没有实现每个NPC独立调用8B制定长期策略；大量NPC同时调用模型将不适合12GB真实RAM的安卓设备。
- 关闭手机后世界不会持续在后台计算。重启时在30天上限内按确定性时钟补算；手机实际长时散热、RAM和离线补算耗时必须实机验收。

## 自动化验收（Godot headless + Android ARM64 APK）

1. 市场正常/缺粮/粮仓过量时，牌价按库存递增或递减。
2. 同户真正从有余者移一份口粮给缺粮者；货物/钱无凭空增加。
3. 商队8时出发，起点库存扣除并加入具体NPC货物；16时抵达完成现金转账和货物交割。
4. 收货地没钱时回程，货物不会消失或瞬时回仓。
5. 一次性模拟12天与分两批补算得到字节一致的结果，货物库存不为负数，NPC与钱库现金总额守恒。
6. 玩家自由输入去街口/查价/问村民可用；附近角色身份及真实货运能在弹窗查看。
7. CI还应验证此前NPC永久记忆、修炼不造假、AI模型下载与推理库打包未退化。

## 后续关键工程

村社和县城财政细分至**家庭资产、店铺、农田、工坊、仓库、工单**；多阶段配方与物流，NPC行业之间相互依赖。之后再做生命生命周期、关系网络、婚育继承、治理与宗门。需要有守恒账本、可追溯历史和设备性能测试，而不是仅生成文字。
