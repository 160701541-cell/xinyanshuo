# 《仙凡·苍岚》安卓本地大模型下载（v0.4）

## 目标

APK仅安装引擎与ARM64原生推理扩展；模型权重由玩家在游戏内主动下载。支持多档量化 GGUF（Q4_K_M），选中后写入 `user://xianfan_local_model_selection.json`，依托 NobodyWho 缓存权重文件，之后可离线加载。纯规则和独立 API 模式仍可以使用。

**说明：** 体积来自公开模型清单，内存建议是保守经验值，不是经过特定安卓设备测定的系统要求。实际 RAM 占用随运行时缓存、上下文长度、安卓系统留存内存和GPU驱动变化。8B/14B 特别可能因为内存不足被系统杀死；不应将它们视为主流手机稳定支持的型号。

## 已实现的 UI 与流程

1. 「设置」→「配置AI服务」→ 「内置模型」。
2. 点击模型选择器可选 0.6B / 1.7B / 4B / 8B / 14B。展示文件大小、内存及剩余空间建议。
3. 玩家可以编辑 GGUF 地址（`hf://` 或 `https://`）；不得自动代入不可靠镜像。
4. 点击 **下载/加载选中的本地模型** 后才开始下载；选择「保存设置」绝不触发数GB传输。
5. 对于 8B/14B 需要额外高风险确认。若正在使用旧模型，先点「卸载已运行的模型」，再下载新的。
6. 下载或加载过程实时显示持续时间，**当前原生库没有已核验的字节进度回调，不能展示假的下载百分比**。失败时将简化信息写入可复制的反馈日志。
7. 加载成功后同一设备断网可运行；上下文、NPC对话历史仍保存在游戏规则层，不允许模型改动物品/灵根/境界。

## 验收边界

GitHub Actions 确认 GDScript、NPC 对话连续性、模型选项及用户确认流程可以在 Godot headless 环境工作，并打包 Android ARM64 原生库。**CI 不在Android实体机中执行8B/14B下载、GPU/CPU推理、剩余内存压力或中断恢复，因此不要宣称大模型已在手机验证成功。**

可选模型来源：Qwen 官方 GGUF `Qwen/Qwen3-{1.7B,4B,8B,14B}-GGUF`。各模型许可证与再分发限制按各自仓库确认。NobodyWho 核心插件按其 EUPL-1.2 许可证要求分发。不可默认承诺任意定制GGUF都能被安卓原生后端加载。
