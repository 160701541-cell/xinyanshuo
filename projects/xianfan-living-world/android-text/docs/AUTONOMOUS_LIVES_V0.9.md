# 仙凡·苍岚 v0.9 — 无需玩家批准的NPC人生与命运

## 已实际新增

上一版已有24位具名居民、逐小时劳作、家庭口粮援助、供需价格及村县两条真实商路。本版把NPC的人生经历推进到真正会发生**技艺成长、师徒出师、自然变老、健康衰减、死亡和财产继承**。这些变化由世界时间和规则计算，玩家未在现场也会发生。

### 技艺、拜师、改行（职业不是永远不变的标签）

- 所有具名职业NPC新增 `skills` 真实技能经验账本，每次成功劳动记一份职业经验；无法凭AI闲聊创造技能。
- 学徒先在本地找同地同业、已经至少有3次真实工艺劳动经验的匠人。学习必须双方都活着、同处工作地点；在合格的工作时段累计24次受教工时后自动出师，真正改变`job`，此后使用匠人生产配方与对应工资。
- 拜师、出师和首次20次工艺熟练会产生不可重写、带稳定NPC ID和世界时刻的人生里程碑；每条里程碑还写入各自的独立本地记忆文件，以供8B聊天检索。
- NPC每日生活愿望仍受实际钱财、饥饿、职业等约束；不是AI随口设定一位“某某大师”就算出师。

### 时间、衰老和死亡

- 一岁按游戏360日计算；`age_anchor_day`防止分批模拟重复加龄。到十年整岁生日时记重要里程碑。
- 每个具名NPC由稳定编号决定预期寿限（约73–89岁）；老年定期健康下降。长期贫病导致健康归零，也会按规则死亡。
- 死亡是不可重复的状态转换：`alive=false`、记录死亡日、关闭务工与社交，不得从场景刷新、闲聊或重新加载存档中复活。
- 遗产不是凭空消失或增长：铜钱和口粮优先完整转交实际同户的在世成员；若无人可继承，完整归入出身地公共钱库和仓库。遗留者的个人资产随后清零。
- 已故NPC永久保留身份ID和履历；人物界面可查看“故人”与生前经历，但不能继续当面交谈，本地8B不会替死者生成新的现场台词。
- 死亡也会成为可检索的**真实规则事件**，不会被不可靠的模型生成的故事替代。

### 存档、迁移与性能

- 原存档仍使用 `society` 已有账本；新增的 `alive`、`skills`、`training`、`age_anchor_day`、`life_span`、`biography` 采用懒迁移，缺字段补默认值，不丢弃旧人物的物品、存款、关系和职业。
- UI显示职业经验、师傅、出师进度、已故日期，以及真实人生履历。里程碑以 `society_chronicle_cursor` 防重播方式归档到各NPC私人本地记忆文件。
- 世界仍为每小时低频演算一次，一般劳动不触发LLM推理。模型只承担需要语言交流、人生转折或重要故事演绎的任务，适配12GB物理内存手机。
- 不关机在前台按独立时钟继续运行；Android应用被系统挂起时停止实际代码，打开时只按设定上限补算，不声称后台进程一直跑。
- 回归测试覆盖账本守恒、职业改变、寿命状态不可重置、遗产实物完整转交、跨存档记忆检索、合并模拟与分批补算相同结果，以及原有大模型加载入口未退化。

## 重要未完成和伦理边界

- 当前只有24位具名职业NPC；其余县人口是区域汇总，并非各有完整人生。没有接入完整死亡人口统计、墓葬、疾病流行、乡村治理、税务和法律。
- “同户”是劳动生活共同体，不等于亲缘或夫妻，不得把系统自动配对解释为婚姻/恋爱关系。
- **婚姻、孕育、孩子出生、成长和家庭继承链尚未开发**；本版不会伪造婚恋与后代。没有人口代际循环时，世界运行一百年后具名人口确实可能减少，仍须下一阶段填充世代更替。
- 农夫、匠人和其他职业的升级是初版真实规则；尚没有完整职业培训市场、资格证、科举、宗门功法传承、社会阶层及晋升体系。
- AI不会凭文字改变NPC寿命、财富、资质、天赋或灵根；这些只能由权威规则写入。

## 下一个可验收里程碑

1. **世代人口系统**：婚恋关系经双方独立意愿和规则承诺成立，才可能共同养育与出生，孩子有稳定实体ID与正确亲缘关系，成年参加职业社会，遗产继承到亲属。
2. **可追溯的家庭经济**：农田、店铺、居所、职业工单与共同仓库，每个经济变化有对手方和来源。
3. **多级NPC智能代理**：短期生活优先规则，季度人生计划交给本地8B进行受限提案，AI只能挑可执行且受资源约束的目标。
4. **远景国度和修仙宗门**：仍遵守同一人口、生产、战斗、生命周期与历史存档引擎，不能另外创造一套纯文字假状态。
