# 《仙凡·苍岚》自运转经济统计（GDP 增加值账本 v1）

## 这次不是把“所有交易金额之和”冒充GDP

游戏中的 **GDP（地区生产总值）** 必须是**一定期间内新增产出的价值**，制造业需要扣除从其他行业采购并消耗的中间产品。当前社会模拟仅覆盖一部分真实结算产出，因此界面明确标注**“已模拟经济的部分GDP”**，不得宣称这是临安县真实完整GDP，更不能拿它除以整个背景人口假装准确的人均GDP。

### 两个地区，固定与当期价格并行

地区：石桥村、临安县城；当前商品：粮、木、鱼、药、器。

| 计量 | 算法 | 说明 |
|---|---|---|
| 实际毛产出 | Σ生产数量×固定基期价格 | 适用于各游戏年份同比比较 |
| 中间投入 | Σ投入数量×固定基期价格 | 木匠使用木料2份必须扣除 |
| 实际增加值 | 实际毛产出－中间投入 | 三产业合计为当前覆盖的GDP |
| 名义增加值 | 当期报价×产出－当期报价×中间消耗 | 价格变动带来与实际值的差异 |
| 成交额 | 真实发生的粮食/鱼货/商队交易金额 | 是货物流转，**不是GDP** |
| 区域财政余额 | 地区现有钱库余额 | 资产存量，不是年度产值 |
| 库存 | 真实粮木鱼药器数量 | 资产存量，不是年度产值 |
| 背景人口 | 区域汇总人口账本 | 当前职业产出没有覆盖全体人口，不对其计算“县域人均GDP” |

例如先生产木料2份、固定价格每份3文，原料生产增加值6文。工坊用这两份木料生产器具1件、固定价格8文，工坊增加值=8－6=2文。最终**本区域新增价值=8文，不是6+8=14文**。如果器具再次从甲卖到乙，不再增加GDP；运输如确实形成新的服务产出，才允许单独记录可核查的新增服务价值。

### 实际接入的规则生产

- 区域集体农田每次收获，按*已扣除田力和仓容限制*的真实粮食数量入账。
- 24名基础具名居民的农林渔药、匠人工坊与已支付的公共服务工时。
- 多职业具名居民库中日结实际交付的粮/木/鱼/器以及受真实财库支付约束的行政和服务工作。
- 玩家像普通村民在街口/东市做零工，确实增产两份粮食时记实际GDP；工资从公库划出不另加一次GDP。
- 玩家买粮、卖鱼、居民买口粮和商队交割，都分别列为真实成交额，**GDP变化为零**。
- 自己吃药恢复体力还不等于对外提供医疗服务；在没有可验证患者与治疗产出时，暂不把“使用了一份药”计入GDP。

### 存档与时间

文件：`scripts/economy_accounts.gd`，与原来的`society`同一权威本地JSON存档。

结构：
- 两地区：`economy_accounts.regions.村` 和 `城`。
- 每地区保存累计、最近90个日记账、最近36个月、最近160个年度汇总。
- 游戏一个月按30日，一年360日，与NPC年龄系统同一历法。
- 累计中保留最重要的统计，滚动期间仅用于手机友好显示。
- 最近120条生产/贸易经济审计摘要用于反馈与QA，大量早期微事件不永久保留在GDP报表中；NPC原始经历仍归人物独立历史档案。
- 老存档缺GDP结构时从当前世界时刻启用统计，初值为0，**绝不猜测或回填曾经未被精确记账的旧生产数值**。

### 手机里怎么查看

进入 **经济** 页：可以直接看到当前位置所处地区的本日、本月、本年GDP、名义/实际新增价值、三产业增值、贸易成交额、财政余额、库存和统计边界。

在 **世界** 页点击“查看本地GDP、财政、物价与产业报表”，可对比石桥村和临安县城，查看最近12个月的生产和成交额轨迹；输入“查看GDP”或“经济统计”也能调出报表。

### 仍未支持的内容（禁止宣传成已完成）

- 全县所有背景人口的逐行业、全口径国民经济核算。
- 精细企业利润、家庭消费/投资、库存价值重估、增值税、政府税收与预算体系。
- 正式财政收支表、劳动力失业率、全量人口真实工资收入分布。
- 完整医药、炼丹、宗门产业、灵石独立货币结算及统一兑换体系。
- GDP/人口的完整地域覆盖与精确人均GDP、居民CPI等正式指标。

完整经济世界的下一阶段需要把每个生产部门的材料树、工资、仓储、产权、税务、投资和人口统计都纳入权威结算。一个模块化的价值增加账本只是地基，不能代替这些复杂制度。

### QA要求

1. 木料2份价值6文，加工成器具1件价值8文，计入GDP仅8文；制造业增加值2文。
2. 任意成交金额不使GDP增长；现金守恒、资源不为负。
3. 不允许生产负数量，不允许无效产业插入假GDP。
4. 日、月、年分期与累计账本一致；手机关闭游戏后加载的数值精确保持。
5. 区域集体农田、不同岗位的具名NPC和玩家劳动真实进入统计，但只统计已经运行的经济活动。
6. 外部AI叙事无法绕过规则直接修改GDP；给出错误口径时显示或记录风险。
