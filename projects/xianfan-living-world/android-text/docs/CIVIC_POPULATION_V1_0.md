# 《仙凡·苍岚》v1.0 — 世界百业身份与多层人口（真实落地范围）

## 原则与回答的根本问题

过去的24名职业NPC仅是用于验证职业日程、现金守恒和贸易的首批具名样本，不应代表一个县、乃至整个仙凡社会的人口或职业范围。如今游戏中区分了**真实具名独立NPC**与**地区背景人口账本**：

- 原有24名NPC仍保留身份、原始积累和经济记录，不改编号、不抹除死亡和家族旧事。
- 新增**336名具名居民**，由168个独立登记职业各派出两名代表；每个人都有持久ID、姓名、年龄、出生/居住地、社会阶层、所属组织、工作地点、金钱、口粮、实际劳动次数、健康、基本技能、个人愿望及存档。
- 最终具名社会样本至少360人，此外玩家一家3位具名亲属仍保持其既有角色规则及状态；不能把背景19,100人写成逐个独立模拟的NPC。
- **职业≠身份≠组织≠修为**：同样是匠人，社会身份可能是匠户或商籍；同样是修仙外围杂役，不意味着已经引气入体或有法力。无法识别的灵根只能记为“待鉴定”，不得虚构突破。

## 如何运行而非只生成名字

每人有实际存档及每日结算：已经领工的市井职业消耗时间才得工时，工资必须来自原本存在的区域钱库；农桑、水业、山林需要真实区域生态存量才能入仓；匠作须先扣除材料；地方市集的粮食买卖须从仓库真实减粮并结算货币；无业、流民、乞食等社会身份**不自动获得工资**，符合条件时可从有粮的公仓领一份真实援助（账本扣粮）。

劳动、钱财、食物、饥饿、健康、个人想法与部分职业熟练度逐日更新，不依赖玩家触发、远程API或每帧对336人调用8B。本地AI只对玩家眼前具体人物及重要剧情进行推理，输入至多7位现场相关NPC，避免把360名身份证档案都塞进上下文。

- **表现层**：《世界》页增加“百业人物名册”，按14行业筛选，每页6人，点击进入人物弹窗，查看职业、阶层、组织、灵根待鉴定、现住处、所持资产和经历。
- **模拟层**：原24名主体仍按小时精细结算；新增336人按日结算经济与人生。当地在场人物按当前游戏小时计算位置，不需要每个人在每帧运行完整AI。
- **记忆层**：336人身份和职业记录是权威世界存档；重要社会事件存于长期 `civic_chronicle`，再按每次至多12条的磁盘写入预算归档到个人本地JSONL；普通日常压缩为可核验的职业、口粮、资产和工作次数，避免无限堆每日重复日志。
- **地区背景人口**：石桥村约1,100与县域约18,000是粗粒度人数背景，当前**没有**把这19,100个人制造成了逐个实名行为主体。将来在探索、招募、搬迁、出生时需要确保从统一人口与家庭账本安全展开真实个体。

## QA及实机边界

GitHub Godot自动化测试验证原始24人不丢、168职业编号唯一、14行业、336实名人物身份、阶层区分、当日劳动、真实库存买粮、救济扣粮、跨会话读档、离线分段补算一致性、全部具名现金守恒、页面分页接口、8B提示词人物数量上限。同时执行原有NPC独立终生记忆和本地模型下载/对话测试。

**限制不能掩盖**：
1. 168种职业已配置，但目前只由粮、鱼、木、器、医疗及服务等几种抽象生产/服务结算模板驱动；**不是**每种职业均已拥有专属工作工单、工具、材料配方、开店账簿与行业晋升玩法。
2. 人物有所属组织和身份，但官府法令、宗门修炼、黑市、婚姻生育、宗门战争、跨州飞升等深层机制仍需专门研发。
3. 自主社会模拟运行与完整安卓12GB设备多日高负载实测是两回事。APK打包成功也不代表全部性能已经过真实手机验收。
4. 地区汇总人口不应在视图中冒充全员有独立记忆的真实NPC。若用户要求逐个模拟数万居民，必须先完成低频实体化、地理分区、家庭迁移与存档预算的完整工程。
