# 《仙凡·苍岚》玩家只是世界其中一员：真实生活世界架构与P0验收

## 根本原则

世界不围绕玩家刷新。玩家不点击按钮时，日夜、NPC工作、市场收支、粮食消费与生态更新仍由**独立时钟+确定性规则**前进。玩家只是与NPC一样参加可计算社会账本的独立实体。大语言模型负责个人言语、长远意向和剧情提案，不能成为基础世界循环、生命状态、财产或价格变动的唯一权威。

## 已落地 P0：24名独立职业者 + 2个区域

新文件：`scripts/society_sim.gd`。世界模拟按整小时运行，保存明确的NPC ID、姓名、年龄、家庭归属、职业、资产、口粮、精力、健康、性格、个人愿望、工作记录、位置和社会关系。职业样本包含：
- 农夫（田力转化为可计数粮仓库存）；
- 渔夫（河湾野鱼存量转化为市场鱼存量）；
- 樵夫（有限林木采伐）；
- 采药人（有上限的野药采集）；
- 匠人（消耗两份真实木材转化为一件器具）；
- 商贩（市场服务、交易时工资与库存有来源）；
- 脚夫（依日程往返官道与临安集市）；
- 教书人/学徒（有独立日程，无凭空授予修为）；
- 巡卒（巡逻工时与俸钱）、医者（处理有限药材与体力）。

凌晨在家休息；白天赴工作地点，工作产出和俸钱均入账；傍晚用钱买粮、吃饭和走亲访友。库存不足时不得交易；库银不足时不得发工资。自然资源按区域容量恢复，不允许无限采集。村社和县郊的未具名集体农田按**抽象化的区域批处理**生产粮食，但受田力与仓容约束，不假装逐一模拟县城成千上万的农户。

玩家已可在真实市集执行“买粗粮”“卖鱼”“做零工”。背包与区域仓库、个人钱币与地区公共钱库共同变动，不能虚增铜钱。玩家并非不能参与的旁观者。

这些NPC通过 `npc` 注册表接入现有人物弹窗；可查看当天职业、正在做的工作、当前地点和个人钱财。NPC与玩家对话时，本地AI读取其**真实**状态，而不是让模型先编一份履历。

## 时间与后台

- 默认 1倍=现实5秒推进游戏1分钟；玩家不行动，世界时钟也继续运行。
- HUD能切换暂停、1倍、5倍和20倍；玩家主动行动依然按玩法消耗对应分钟。
- Godot依 `_process(delta)` 累积真实时间，每过一个游戏小时给社会层触发一次职业/生态/交易周期，不按每帧给每个NPC运行LLM。
- 每10个游戏分钟自动存档；Android离开前台时立即保存。
- **Android系统会暂停后台进程**。应用重新打开/恢复时依据上次时间戳做`catch-up`演算，最多补30个游戏日，超过上限的时间不伪称已经计算。可以暂停世界时钟阻止继续变化。无法保证手机关机时真正执行代码。
- 社会资料保存在本地JSON存档，NPC人生长记忆保存为独立JSONL。系统运行不依赖外部API，不需要让每个NPC载入自己的8B模型。

## 真正大世界的后续三层

**L0（玩家眼前）**：具体NPC和物品一对一结算；每个人有身份、目标、互动规则和可追溯记忆。

**L1（同县、同城）**：数百到数千具名社会角色以低频小时制、批量工单和触发事件结算。具体NPC有永久ID，重要人物可无损迁移到玩家眼前，不改变已发生历史。

**L2（附近国家宗门）**：县区/宗门汇总账本，按日、旬、月运行：生产、赋税、粮运、宗门资源、争斗、灾害、人口增减和商路。社会结果反向影响玩家所在县市的货价、招募、粮仓和安全。

**L3（远方世界）**：按年、季的宏观演算；仅对涉及玩家、商路、战争等关键事情使用细粒度事件。玩家旅行抵达时，从确定性登记簿展开必要的具名实体，而不是临时随机创建无历史的工具NPC。

> 重要：现阶段**只实现P0 24名职业NPC加小规模地区账本**，不是已经实现县城万人人生演算、完整王朝更替、仙凡四界、宗门产业链、死亡继承和万人大战。

## 中期功能排序（后续优先）

1. 彻底独立的实体/地点/物品/职业/家庭/宗门ID。NPC与玩家共用同一任务、修行、技能、死亡和背包规则，而非各做一套假演算。
2. 完整材料加工树与物流体系：投入、库存、产出、运输时间、仓储损耗与市场供需浮动。农民有农田、商贩有摊位、铁匠有铁矿/煤/熔炉。
3. 家族成员生命周期：出生、成长、恋爱、婚配、生子、伤病、衰老、死亡及资产继承；NPC自主结交与仇怨。
4. 凡人王朝：县乡村组织、官吏、田租、赋税、天灾、贸易、官府执法、叛乱、道路建设；财政真实可算。
5. 修仙社会：灵根、功法、境界、宗门招徒、师徒授业、秘境探索、妖兽生态、丹器符阵产业、寿元和死亡。
6. AI仅在交谈、人生转折、重要事件与长期规划时调用；低级生产周期纯规则运行。支持 NPC 重要记忆与结构化偏好的无损归档。
7. 玩家死后不重置社会：世界存档仍保留，只是切换观察者或另立角色；人口与历史持续。

## 高标准QA

- 不操作10个游戏日，NPC仍独立换班、种田、捕鱼、购买口粮、储备财富或因短缺改变健康。
- 相同种子、相同时刻，逐小时模拟与一次性快速演算结果完全一致；可反复复现Bug。
- 任何时间仓库、野生资源、现金、健康和人口不能是负数；NPC工资必须从真实的钱库划转。
- 玩家赚到的每1文都有交易对手或公共钱库扣除；不会凭空生成灵石、修为或身份。
- 1000人/万级人口不能逐帧同时调用AI；记录CPU耗时、存档增长、LLM占比、设备RAM、发热，系统负载大时自动降低远方频率。
- 每次升级迁移旧游戏存档、NPC人格和记忆；绝不因世界引擎迭代清空原来的第一世。
