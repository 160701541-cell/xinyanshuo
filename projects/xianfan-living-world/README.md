# 仙凡共生｜临安县 0.5（独立游戏 / Android 预览分支）

> **必须隔离**：与《苍岚·人生世界》Godot正式更新、WorldBox MOD项目无关联；本目录使用独立包名 `com.xinyanshuo.xianfan.county`，严禁修改原游戏主分支的安装包、签名、热更新、世界设定或项目数据。

## v0.5 — 连续移动与地图深度迭代（候选测试版）

本轮以 **2026-10-21 用户的四张真实手机截图** 为失败基线。

- 街巷选择道路后先启动行程，不一次性移动/提前结算时间。World clock 随帧流逝，玩家标记连续移动，达到建筑入口后才进入场景；支持中断/续存。
- 点击建筑/县衙只打开**原位浮层**：建筑说明、已有世界数据筛出的实际在场职员、入口距离和「前往/进入」按钮，防止误触直接传送。
- 县域官道、御剑进度同样在移动中计时及消耗；仅完成行程后改变所处地域。
- 由统一 `spatial.mjs` 建筑与道路坐标生成县域缩略城防图、街区道路和建筑本体；铺装、河流、田块、城门、屋檐、院落不再同质空白。
- 新增州省/天下河流、山脉、城关、宗门、地理示意层（未开放区域不具真实人口模拟）；双指和滚轮可自动跨语义地图级别切换；文字对比和字号加强。
- 首版原创可复现的SVG地图图标工厂 `tools/make_map_icons.py` 生成8种图标及SHA256清单。无WorldX接入时不伪称使用。
- 自动QA扩展为25项；手机浏览器最终视觉验收仍待用户实机验证。

详细变更、真实限制和后续P0见 `docs/06_实机反馈_连续时间与山河图层_v0.5.md`。

## 2026-10-21 用户实机反馈 / 修复目标

v0.3实机失败：道路只是背景、街道上站满「在家休息」的NPC、北边道路走不过去、建筑内外结构同质、地图仅用标签切换而非可通行空间；status bar覆盖页面顶部。

**v0.5实现**：

- 独立 `spatial.mjs` 街巷道路格网；街道节点 10格点、交叉口真实连通；`roadPath()` BFS路线，可从南北东西任一路段点击往返，沿路行走产生耗时、事件和玩家精确位置；拖拽、双指缩放、滚轮缩放，地图层级「天下→青州→县域→街巷」。
- 市街道路、院墙、宅院、客栈、粮行、铁铺、县衙绘制在同一坐标系；**点击建筑本体**自动走到门口再进入建筑内部；点击「出门」返回入口道路。室内单独绘制围墙、器物、房间及真实人物，不再把房间地图做成与街上相同的背景。
- 夜间人物不再以「在家休息」标签站在大街上。原居家记录继续保存在人物档案中；街头只显示符合时间与户外职业的既有真实NPC，夜间上限2名巡更者；白天显示如巡街、挑担、叫卖等，不新增虚构人偶。
- 修正 targetSdk35 Android系统状态栏的父容器Insets处理，避免网页内容顶到系统状态栏。
- 单机持久化：原13,680条NPC数据、人口账本、交易/财政、旧schema1/2存档保持兼容，新增加道路定位字段。测试增至19项。

## 明确的剩余限制（不可误报）

- 只有临安县**局部市街**具备可点击的格点道路与建筑门口；县域采用区域路网；州府和天下当前仅为层级地图示意，**不代表已生成全球海量连续路网**。
- 院落外形目前仅少数建筑有可进入的内部房间；部分民居/茶肆/药铺是待实现的场景轮廓，不得称所有建筑可进入。
- 13,680人为持久户籍个体；NPC不会同步实时全量寻路，街上动态属于规则驱动、时间变化的少量活动样本，**还未达到全人口自主行为/真实家居地址/工作班表**。
- 不存在高精美术；SVG制图是用于验证地图空间逻辑的交互图层。视觉品质与用户实机触控、长时间存档均未通过实机验收。
- 世界以游戏时间推进为准，未开启现实时间离线自动快进。
- APK采用稳定的公开演示签名（仅供内部覆盖测试，不能用于商业发行），同包名同密钥且versionCode 4，可以从0.2/0.3安装覆盖，但需通过Android设备实际验证。
