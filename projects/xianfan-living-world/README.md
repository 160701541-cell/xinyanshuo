## 本次交付：临安县及周边，13,680人

- **源文档**：`docs/00...03` 为2026-10-21设计总纲、关系伦理、经济/政治/修仙世界规则、QA执行标准；完整初稿按原稿存档。

### 当前能试什么

1. 世界生成：在同一县城、山门、郊外及周边村庄的**18个区域/建筑入口**间探索；建立**13,680条持久个人记录**（实体ID、年龄、职业、家庭、住处、性格线索与灵根字段）；超过3,000个独立户籍家庭。
2. 社会运转：推进1天/30天会修改粮仓、粮价、县库、人口出生死亡、季节与纪事；县令/宗门制度未完成，县吏与修士为明确标记的**调试身份**。
3. 个人/经济：粮行购买米粮会真实减少商铺库存和玩家银钱；县吏在县衙可以签发有库存/县库约束的赈济；人物见面留有初遇记录（**不是刷好感**）。
4. 出行：相邻场所步行，御剑跨区按路程扣灵力并推进世界时间，室内禁止落剑；没有把御剑变成不停点击几十个房间。
5. 存档：浏览器IndexedDB离线存档（显式点击“存档”），同种子同操作可回放，重新开局是另一份不预设结局的世界。

**现阶段并未完成**：13,680名居民独立实时AI认知/每人的复杂职业事务、完整商品供应链、官制与科举、真实武道/修炼与战斗、情感/婚姻决策、灵根突破、世界历史百年高速跳跃、APK手机适配验收。人口13,680是**真实个体档案+按地区汇总的经济结算**，不能误当13,680套同时在线的复杂Agent。地图是交互位置示意，**不是**完整街巷建筑室内高清地图。原型UI结构是可交互试验，不代表正式美术/UI验收通过。

### 为什么在这个仓库开独立分支？

用户明确指定“文档在公开仓库开一个新的分支并明确标识”。因此采用 `xianfan/independent-living-county-v0.1` 分支并在 `projects/xianfan-living-world/` 文件夹存放独立项目，全程**不修改既有《苍岚》生产游戏文件、不更新网站发布清单、不触碰WorldBox实验分支**。

### 质量与复现

当前已通过Node内核8项自动化测试：人口唯一ID、世界种子、交易守恒、县衙权限与库存、移动规则、交谈记录、一年人口状态与存档、相同操作确定性。**Android浏览器、Android WebView及APK均未通过实机验收；不得写“已手机实测”。**
